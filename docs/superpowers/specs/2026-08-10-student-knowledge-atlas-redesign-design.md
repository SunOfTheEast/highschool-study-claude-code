# StudyForge 学生知识图谱页重设计

**日期：** 2026-08-10  
**状态：** 已确认视觉方向，待实施计划  
**范围：** `apps/pi-teaching-web` 桌面端 `/knowledge`

## 一、为什么要改

现有知识关系页虽然满足 M1d 的数据边界，但视觉上更像一个关系调试器：左侧是很长的标签
目录，中间把各种节点机械地排成一圈，右侧再重复一遍关联项。它同时占用了三个栏位，却没有
把最重要的两件事讲清楚：

1. 当前知识点与哪些知识结构相连；
2. 沿着这些联系，可以打开哪些题卡、笔记或原始资料。

问题不在配色，而在信息职责没有分开。关系、内容入口和检索目录同时挤在画布周围，导致主次
弱、节点像卡片墙、关联清单重复，学生既不容易形成“知识地图”的直觉，也不容易直接进入学习。

## 二、设计结论

图谱页采用同一套双焦点界面：

- **中央知识地图**回答“它和什么相连”；
- **右侧活页**回答“沿着这些联系，我现在能读什么、练什么”；
- 选中标签时自然进入知识点视角；选中题卡或笔记时自然进入资产视角。

页面不新增独立的 `mode` 状态。视觉预览里的“知识点视角 / 题目视角”切换只用于并排演示
两个真实状态；正式产品由当前 `focus` 的类型决定视角，避免出现“切到题目视角却不知道该选
哪道题”的第二套状态机。

这份设计细化并替代
`2026-08-09-m1d-student-interface-and-knowledge-relations-design.md` 的 11.2、11.3 节布局与
局部呈现方式；11.1 的数据边界、空态和故障隔离继续有效。

## 三、页面结构

### 3.1 页头

页头保留一个明确标题“知识之间，怎么连起来”，并把检索收进标题右侧。搜索范围同时包含：

- 语义标签；
- 题卡标题；
- 笔记标题。

结果按“知识点”和“学习内容”分组。选中结果后直接更新当前 `focus` 与 URL query。旧的左侧
常驻标签长列表删除；检索是入口，不再成为占据整列空间的目录。

学习资料页入口和页面名称统一使用学生熟悉的“知识图谱”；它仍从学习资料进入，不提升为一级
导航。代码与接口可沿用 semantic relation 命名，不因展示名称改变数据契约。

### 3.2 主体

主体是约 7:3 的两栏布局：

- 左侧为占主导的知识地图；
- 右侧为当前焦点对应的内容活页。

两栏在普通桌面窗口内必须同时可读。页面不再出现第三栏，也不再用一圈同尺寸卡片填满中央
区域。

### 3.3 底部说明

只保留与当前状态有关的极简图例。共现关系必须继续明确说明：它只表示标签共同出现在资产
中，不代表先修、相似、因果或教学上的优先级。

## 四、两种真实焦点

### 4.1 标签焦点：先看概念联系，再进入资产

以“参变量分离”为例：

- 中央焦点是“参变量分离”；
- 地图优先展示与它共同出现的标签，例如恒成立、最值、定义域、对数、绝对值；
- 共现权重只影响确定性的显示顺序和远近，不改变关系语义；
- 右侧活页列出直接挂有该标签的题卡与笔记，先列 core，再列 related；
- 每项显示真实标题、资产类型和精确关系，不生成不存在于数据里的教学理由；
- 点击资产后，该资产成为新的中央焦点。

若该标签尚无标签邻居，地图可以展示少量直接资产作为入口，但右侧仍承担完整资产列表，中央
不退化成题卡墙。

### 4.2 资产焦点：看这份内容位于哪里，再寻找邻近内容

以题卡“对任意 `x > 0`，`ln x <= ax^2`”为例：

- 中央焦点是题卡本身；
- 地图展示它的 core 标签、related 标签以及确实存在的直接来源；
- core 标签比 related 标签更靠近焦点；Material 只在该资产直接引用它时出现；
- 右侧顶部保留“打开内容”和“带着这道题/这份笔记问老师”；
- 右侧随后列出由现有标签机械召回的少量邻近题卡或笔记。

邻近资产的文案必须反映可验证事实：

- 共享 core 标签时写“核心标签相同”，并列出共享标签；
- core 标签不同但共享其他标签时写“核心标签不同，共享……”，让学生自行或与老师进行比较；
- 不把标签重合直接写成“相似题”“最佳下一题”或“路线对照”；
- 不由前端编造“为什么适合你”的自然语言解释。

这样仍能支持连续练习和比较探索，但不会把扁平标签推断成系统并不拥有的教学关系。
邻近资产默认最多展示 6 项；需要继续扩展时，应点击共享标签回到标签焦点，而不是在资产活页
里铺开整个题库。

## 五、地图视觉

### 5.1 画布

地图沿用 StudyForge 的纸张主题，但从“卡片关系图”改成“桌面知识图册”：

- 画布使用很淡的方格纸纹理；
- 普通标签是文字、类别小字和一个标记点，不再各自包成卡片；
- 当前焦点是一张居中的纸签，用朱砂细线和轻微外框强调；
- core、related、co-occurrence、source 使用克制且稳定的线型差异；
- 对照含义只能出现在数据能证明时，不能只靠颜色或位置暗示。

### 5.2 布局

继续使用纯 CSS/SVG 的确定性布局，不引入 force solver 或重型图可视化依赖。布局使用固定槽位
而不是把所有节点等角度排成圆环：

- 焦点固定在中央；
- 最重要的关系进入内圈槽位；
- 次要关系进入外圈槽位；
- 同一输入必须产生同一位置；
- 画布展示焦点加至多 8 个邻居；完整内容留在右侧活页。

节点标题过长时允许两行，但不能缩成难以阅读的小字；资产焦点使用短标题或题面首句，完整标题
仍可在右侧读取。

### 5.3 右侧活页

右侧不再叫“关系检查器”。它是一张带朱砂顶线和装订边的内容活页：

- 标签焦点下标题为该标签，主体是相关题卡和笔记；
- 资产焦点下标题说明“沿着这份内容”，主体是操作、直接关系与邻近资产；
- 各项用细横线分隔，不堆叠独立卡片；
- 列表允许纵向滚动，但页头和主要操作应先被看见；
- 完整关联仍然可达，不因中央画布的 8 个节点上限而丢失。

这里的“完整关联”指当前焦点的 canonical 标签、资产和来源关系；资产之间临时派生的标签近邻
不是持久关系，可以按上述 6 项上限展示。

## 六、数据与派生边界

本次不增加持久化 schema，也不引入模型调用。页面继续只消费：

- `SemanticRelation[]`；
- `LearningAssetLibrarySnapshot`；
- `LearningMaterial[]`。

允许在客户端 view model 中派生两类只读结果：

1. 标签焦点下，按共现权重排序的标签邻居与按 core/related 排序的直接资产；
2. 资产焦点下，按共享 core 标签数、共享标签总数和稳定键排序的邻近资产。

这些派生结果只是检索投影，不写回资产，不生成新边，也不成为 Agent 上下文。对象记忆、能力
判断、偏好、分桶和教师内部判断继续完全排除。

来源关系只沿当前资产的直接 `asset-source` 展示；不得枚举资料目录猜测来源。旧的
`legacy-unpinned` 边界继续保持。

## 七、交互

- 点击标签：以该标签重新居中，更新 URL focus；
- 点击题卡或笔记：以该资产重新居中，更新 URL focus；
- 点击 Material：沿用现有资料阅读路由打开对应资料，并继续显示关系中已有的 revision 与
  locator；本轮不扩展 Material 路由契约；
- 点击“打开内容”：进入对应阅读或作答页；
- 点击“问老师”：只携带当前资产，不把整张图注入教师上下文；
- 浏览器前进、后退和刷新后，焦点仍由 URL 恢复；
- 搜索清空不改变当前焦点。

页面不提供拖拽、手工连线、坐标持久化、图谱编辑、多选批处理或全局鸟瞰。当前目标是让学生
读懂一个局部并继续学习，不是成为知识图谱管理器。

## 八、状态与失败

### 空图

没有带标签资产时，继续展示真实空态并返回学习资料页，不自动造标签或示例节点。

### 焦点失效

URL 指向已删除或不存在的焦点时，回退到第一个真实标签；完全没有标签时进入空态。不得展示
内部 key 或解析错误。

### 关系接口失败

只影响知识图谱页。错误使用学生可理解的说明与重试/返回资料入口，不暴露 API 名、异常类、
路径或内部 ID，也不能拖垮首页、资料页和课程页。

### 长列表

中央地图始终有上限；右侧列表保持完整且可滚动。搜索和 focus 切换不得触发模型推理，也不应
重新解析题卡正文。

## 九、验收标准

### 语义

- 标签焦点的地图优先展示真实 `tag-neighbor`，右侧列出全部直接资产；
- 资产焦点的中央地图只展示真实标签与直接来源；右侧近邻明确标为共享标签派生；
- 邻近资产只能基于共享标签派生，并用可验证措辞说明；
- 共现不被写成先修、相似、因果或最佳路线；
- 教师记忆与内部判断不进入页面或测试快照。

### 功能

- 搜索可以找到标签、题卡和笔记并切换 focus；
- 标签、资产和 Material 的点击路径正确；
- 打开内容、问老师、URL 恢复和返回资料均保持可用；
- 超过画布上限的关系仍可在右侧找到；
- 空态、失效 focus 和接口失败均不泄露内部信息。

### 视觉

- 1024px 及常用 macOS 桌面窗口下，知识地图和右侧活页同时可读；
- 页面没有左侧长标签栏，也没有三列调试器观感；
- 普通节点不再呈现为一圈同尺寸卡片；
- 当前焦点、概念关系和内容入口具有清楚的三级层次；
- 长标题不遮挡节点、连线、活页操作或页面边缘；
- 现有纸张、朱砂、墨色与宋体气质保持一致，不引入通用 SaaS 卡片风格。

### 性能

- 路由进入与焦点切换只处理已有 relation projection 和资产 summary；
- 不读取题卡正文，不调用 Agent，不加载重型图形库；
- 519 张题卡规模下，图谱页的交互不应阻塞首页或其他路由。

## 十、明确不做

- 不新增标签维度、先修关系、相似度分数或教师编排字段；
- 不用模型生成右侧推荐理由；
- 不把“下一题”选择权伪装成前端确定结论；
- 不做全局知识网络、力导向动画、拖拽编辑或关系持久化；
- 不顺带改造资产 schema、记忆系统或 Agent Skill；
- 不为移动端另做布局，本轮只保证桌面端与窄桌面窗口的基本回流。
