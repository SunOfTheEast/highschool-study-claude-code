# StudyForge M1d：学生界面与知识关系设计

**状态：** 已实现并通过 M1d 发布门；真实备课时延作为独立性能风险保留

**日期：** 2026-08-09

**实现基线：** M1c 当前主线 `42c6377`

**视觉参考：** `apps/pi-teaching-web/preview/`

## 一、结论

M1d 不再增加学习事实、记忆层或 Agent 工具。它把 M0—M1c 已经成立的课程、自由学习、
学习资产、原始资料、学习足迹与语义关系整理成一个学生愿意长期使用的桌面端产品。

本期采用“共享视觉语法，保留页面自身形状”的方式：复用 Kimi 原型中的纸张、墨线、朱砂、
字体、留白和五金件，但不把所有页面压成同一种卡片模板，也不以 mock 数据、`localStorage`
或前端推断代替当前 Runtime 与 canonical 文件。

M1d 完成后的主路径是：

```text
玄关首页
├── 问老师 ── 自由学习信纸 ── Note / 题卡 / 记忆
├── 继续上课 ── Roadmap / Plan / Lesson 三纸工作区
└── 我的学习资料
    ├── 笺：Note
    ├── 卷：题卡与作答
    ├── 文献：Material 与定位
    ├── 账簿：可重建学习足迹
    └── 知识关系：局部语义关系图
```

## 二、设计取向

### 2.1 视觉命题

界面像一间安静、有人长期使用的中式书房：纸张承载内容，墨线建立层级，朱砂只标记最重要
的行动入口。它不是仿古装饰，也不是现代 SaaS 卡片墙。学生应先看到“现在可以做什么”和
“正在学什么”，再按需看来源、revision、locator 等技术细节。

视觉层级只依赖以下元素：

- 三层纸色、稳定留白与发丝线；
- 文楷正文与少量等宽元数据；
- 黛青洗色用于普通主行动和当前状态；
- 朱砂印章只用于 `学 / 继 / 问` 三类品牌或主入口语义；
- 无悬浮抬升、厚阴影、玻璃态、渐变大卡与装饰性仪表盘。

### 2.2 内容计划

首页只回答三个问题：是否有正在进行的课、是否要问老师、从哪里查看已有学习资料。资产页
负责浏览和选择内容；详情页负责阅读、编辑、作答与带上下文提问；足迹页负责回看来时路；
知识关系页负责从一个语义词出发寻找附近资产；课程页负责当前 Roadmap—Plan—Lesson 周期。

不把教师内部判断、对象记忆、能力假设、偏好模型或 Runtime 状态机展示成学生仪表盘。

### 2.3 交互命题

学生不需要先理解系统对象才能行动。首层行动使用自然语言；技术身份、来源 revision 与
canonical locator 渐进披露。长任务必须有安静但持续的可见进展。所有写入仍沿既有 API、
stale-write、批准门和 Runtime 生命周期完成，前端只投影真实状态，不复制一套控制逻辑。

## 四、版本边界

### 4.1 本期新增

- 统一桌面端视觉语法与页面五金件；
- 依据真实课程状态确定首页唯一最强行动；
- 自由学习、Meta、资产详情与课程工作区的页面级重组；
- 学生可理解的来源、形成现场与 Material locator 展示；
- 从既有事实重建的账簿式学习足迹；
- 标签中心、局部展开的知识关系图；
- 读投影所需的少量 typed display fields；
- 长任务、断线、保存冲突与局部读取失败的克制反馈；
- 桌面端确定性 E2E、截图和一次真实模型冒烟验收。

### 4.2 本期不做

- 不新增数据库、向量库、图数据库、坐标文件、足迹日志或知识图正文；
- 不新增对象记忆、能力、偏好、掌握度、BKT 或复习排程的学生仪表盘；
- 不让标签或资产内容冒充学生能力；
- 不新增前端生命周期状态机、额外确认弹窗或通用回执协议；
- 不重写流式传输、工具回执、断线重连和数学渲染协议；
- 不删除仍被服务端或兼容路径使用的旧知识读取能力；
- 不做移动端产品设计、图谱编辑、多选拖拽、人工连边、管理后台或分享市场；
- 不以脆弱的像素快照作为验收门。

## 五、共享视觉语法

### 5.1 颜色、字体与可读性

- 保留三层纸：`--paper`、`--paper-mid`、`--paper-deep`。
- `--ink-faint` 调整为约 `#70695d`，确保在三层纸与白色上的普通字号对比度均超过 4.5:1。
- 全站继续使用自托管霞鹜文楷；等宽字体只用于 ID、revision、canonical locator 与时间戳。
- 11px 只允许等宽身份和时间；其他辅助文字至少 12px，正文至少 14px，对话正文以 16px 为准。
- 保留当前 `font-synthesis: none` 与 Markdown / KaTeX 字体边界。

### 5.2 朱砂与行动层级

朱砂印章有三种语义：

| 章 | 含义 | 使用位置 |
| --- | --- | --- |
| 学 | StudyForge 品牌 | AppShell / 品牌区域 |
| 继 | 继续当前正式课堂 | 首页 active Lesson 主入口 |
| 问 | 开始自由学习 | 首页无 active Lesson 时的主入口 |

这不是三个固定 DOM 组件，而是一套受限语法。朱砂永不编码错误、掌握度、认知状态或一般
按钮。按钮分四档：

1. 深黛青实心：只用于“问老师”这一上下文行动；
2. 黛青洗色：保存、发送、开始、完成等当前页面主操作；
3. 墨线描边：普通操作；
4. 文本链接：返回、查看更多、低频技术细节。

继续课堂卡依靠左脊、底部墨线和“继”章形成层级，不使用实心按钮。

### 5.3 标签与足迹分类

- `core` 标签使用轻黛青洗色；`related` 标签使用白纸描边；两者文字同时说明语义，不只靠色。
- 足迹分类点：Session 灰实心、资产空心、作答暗金、认知变化黛青。
- 这些颜色只分类事件，不表达掌握程度。

### 5.4 页面形状

共享 AppShell、导航、纸层、按钮、印章、标签、来源行、空态、加载与错误语言。页面内部保持
不同阅读姿态：玄关、信纸、架、笺、卷、文献、账簿、三纸课程工作区与局部关系图不互相
套模板。

## 六、首页：玄关

### 6.1 唯一最强行动

首页只由服务端真实课程树与 Session 状态选择主入口：

1. 存在 `active Lesson`：朱砂“继”卡是唯一最强行动，链接到该 Lesson 所属的精确 Plan 与
   Lesson；“问老师”降为安静次入口。
2. 不存在 `active Lesson`：朱砂“问”是唯一最强行动。
3. 已有课程但没有 active Lesson：显示文本入口“进入正式课程 · 当前所在位置”。
4. 没有课程：显示文本入口“规划长期学习”。

自由学习线程只进入最近对话列表，不能抢走主入口。前端不得用浏览历史或 `localStorage`
猜测课程位置。

### 6.2 内容布局

- 品牌行与学习集标题；
- 当前主行动；
- 课程安静入口或长期规划入口；
- 最近自由学习对话；
- “我的学习资料”入口。

首页不显示能力星图、Trace 数量、虚构下一个 Plan、掌握百分比或课程外推。

## 七、自由学习与 Meta：信纸

### 7.1 自由学习

自由学习采用单列信纸，页头显示真实线程标题。标题由首条学生消息机械生成：去 Markdown、
去换行、截断；没有学生消息时回退“自由学习”。不调用模型命名，也不建立标题生命周期。

若对话由资产发起，页头安静展示随身上下文：资产标题、revision 与最近作答状态。不可变的
`selectedAssets` 在对话创建后只读，学生仍可在新线程中选择不同上下文。

学生显式结束后，完整信纸保留可读，composer 禁用；不隐去历史，也不自动升级为课程。

### 7.2 Meta

Meta 同样使用单列信纸，但只讨论长期 Roadmap。Roadmap 创建成功后关闭输入，显示“进入
正式课程”；Meta 内不继续设计首个 Plan。拒绝长期路径时不物化 Roadmap，资产与自由学习
入口照常可用。

### 7.3 对话实时反馈

一轮对话的学生可见顺序是：

```text
学生消息立即出现
→ 老师正在思考
→ 如有专门长任务，以 Scout / Reviewer / 讲义 / Material 状态替换通用思考
→ 教师文字流式出现
→ 完成或保留可恢复失败状态
```

保留现有 Material Search、Lesson Reviewer、Printable Handout 与其他安全活动投影。普通工具
默认不展示原始 JSON：成功只给一行自然语言回执；失败给学生可理解的说明，并只在内部调试
入口折叠技术细节。

WebSocket 断开时顶部显示“正在重连”；composer 可继续编辑但发送禁用，草稿保留。已结束
Session 不因重连恢复输入。

## 八、我的学习资料：架

### 8.1 浏览与选择

资产架按现有类型和最近状态浏览 Note 与题卡，并保留 Material 入口。多选上下文只允许
Note 与题卡；Material 必须先选定真实 locator。选中态使用整行洗色与页头计数按钮：
“带着所选问老师 · N”。

页头提供文本入口“知识关系”。标签可以进入知识关系页并聚焦该词，但标签本身不能直接作为
对话上下文。

### 8.2 两种来源必须分开

资产详情分别展示：

- **形成于：** 创建资产的自由学习或 Lesson Session，用于返回当时对话；
- **内容来源：** `sources` 中固定的 Material / Note / 题卡 revision 与 locator，用于核查内容。

二者不可合并成“来源”。形成现场不是内容依赖，内容依赖也不能证明学生在现场学会了什么。

## 九、资产详情

### 9.1 Note：笺

Note 保留阅读、编辑、revision 冲突和回忆块能力。页头提供“带着这份笔记问老师”。保存为
黛青洗色主操作，revision 与来源信息渐进披露。

保存成功原位显示结果；失败保留输入。若 stale write，提示“内容已被更新”，保留本地草稿并
允许重载最新版本，不做自动合并。

### 9.2 题卡：卷

题卡保持 append-only 作答、不会、答案门与笔记更新契约：

- 作答前：“带着这道题问老师”；
- 作答后：“带着这次作答问老师”；
- 学生可以在两个时机进入对话；
- 标准答案仍必须经过既有 reveal gate；
- 查看答案不会被前端解释为掌握。

各写请求状态相互独立：保存题卡笔记、提交作答、标记不会、查看答案只禁用自己的按钮。

### 9.3 Material：文献

Material 使用渐进定位：

1. 自动读取建议 locator；
2. 主界面显示“第 62 页”等人类标签；
3. 次级位置显示 `page-0062`、`lines-1-80` 等 canonical locator；
4. 只有必要时展开高级 locator 输入；
5. “问老师”只绑定当前成功显示的 locator。

若只能读取原文件，应明确说明老师将读取原文件。新的定位失败时保留上一份成功内容与问答
绑定，不把失败输入冒充当前 locator。上传、定位与提问使用各自请求状态。

## 十、学习足迹：账簿

足迹始终是从 canonical Session、资产、activity 与对象 Learning History 重建的学生投影，
不新增日志、编辑器或写入 API。

- 单条时间轴，最新在前；
- 独立事件不合并；
- Session 进入相应对话或课程；
- Note / 题卡打开内容；
- Material 打开材料；
- Attempt 打开题卡；
- cognition 事件返回相应学习现场；
- 缺少真实时间的条目排在末尾并显示“时间未记录”，不伪造日期。

认知条目只展示该条 Learning History 中学生可见的变化，例如“在提示比较共同结构后完成，
尚未证明能自主识别”。不得展示 Current Judgment、能力假设、偏好、教师待办或内部桶结构。
M1d 首版不加筛选、统计和足迹详情页。

## 十一、知识关系：局部语义图

### 11.1 数据与边界

`/knowledge` 改为读取 `/api/semantics/relations` 的 typed projection。关系页按路由加载，不把
图结果注入 Agent 上下文。旧 `/api/knowledge` 服务能力可保留兼容，但旧方法树退出学生主界面。

图只包含：

- 语义标签；
- Note 与题卡；
- 被当前选中资产直接引用的 Material；
- 标签—资产 core / related 关系；
- 标签共现邻居；
- 资产直接来源链。

对象记忆、能力、偏好、分桶和教师内部判断不得进入学生图。

### 11.2 桌面布局

- 左：标签搜索与入口词；
- 中：以当前标签或资产为中心的局部关系图；
- 右：选中标签或资产的检查器与完整关联列表。

标签是主节点，Note / 题卡是资产节点。选中标签时展开邻居标签与相关资产；选中资产时展开
其 core / related 标签与来源。Material 只在选中资产确实引用它时出现。

### 11.3 防止毛线团

- 永远只展示当前局部邻域；
- 中央画布最多展示 12 个代表节点，并说明“显示 12 / 共 86”；
- 完整关联项进入右栏列表；
- 使用稳定、确定性的局部径向布局，不运行全局 force solver；
- core 边较强，related 边较轻；
- 标签邻居线只表示同一资产中的共现次数，不表示先修、相似或因果。

点击标签会重新居中；点击资产打开检查器；检查器可“打开内容”或带该资产问老师。标签不是
上下文资产，因此没有“带着标签问老师”。只允许 URL query 保存当前 focus，不持久化坐标、
展开状态或人工关系。

关系图为空时说明尚未形成带标签的资产并返回资产架，不自动打标签。关系接口失败只影响
本页，不能拖垮资产与课程页面。

## 十二、正式课程

### 12.1 课程总览

课程总览只使用真实 Roadmap、Plan Tree、Lesson Tree、当前位置与状态。它不再推算能力星图、
Trace 证据数或未物化课程。

### 12.2 三纸工作区

- 左纸：精确 Roadmap → Plan → 该 Plan 自己的 Lessons；
- 中纸：当前标题、公开摘要或课堂重点、教师对话；
- 右纸：学生可见文档。

右栏标题统一为：Roadmap“长期路线”、Plan“阶段安排”、Lesson“本课提纲”。关闭 Lesson 的
转录保持只读。生命周期按钮使用洗色主操作，合法性仍由 Runtime 独占；前端不复制状态机，
不额外弹确认窗。Material Search、Reviewer 与 Handout 状态继续在相关对话中原位显示。

## 十三、最小显示投影

M1d 只允许以下非 canonical 读投影：

1. 首页课程摘要可选 `activeLesson`：title、plan title 与精确 route；
2. 自由学习详情暴露创建时已固定的 `selectedAssets`；
3. 自由学习标题由首条学生消息机械生成；
4. Note / 题卡详情增加 `formation`：Session kind、display title 与 route，来自既有
   `createdSessionId`；
5. Material locator 增加人类可读 display helper；
6. `/api/semantics/relations` 使用共享 TypeScript 类型，替换客户端 `unknown[]`；
7. `/knowledge` 消费语义关系投影；旧方法树不再出现在学生 UI。

不新增 home cache、模型命名任务、坐标、足迹日志、来源 schema 或写工具。

## 十四、加载、失败与局部恢复

- AppShell 与当前内容在后台刷新时保持可见，只增加一条细的“正在更新”；
- 页面首次读取使用安静的内容内加载，不建立 toast 栈或通用 modal；
- 页面读取失败在原位置说明并提供一次重试；
- Note 保存、题卡笔记、作答、答案查看、Material 上传和定位均有独立请求状态；
- 成功在动作附近显示；失败保留输入；
- revision 冲突保留草稿并提供重载，不静默覆盖；
- Material 定位失败保留上一次成功内容；
- 图谱失败只影响关系页；
- 空课程、空资产、空足迹、空关系图使用各自真实空态，不复用一个泛化文案。

## 十五、实现原则

1. 先补显示投影与确定性纯函数，再改页面；
2. 复用现有 AppShell、ChatPanel、MarkdownView、safe activity projection 与 API；
3. 视觉组件只抽取重复语法，不为每个边框建立组件；
4. 页面状态与请求状态留在当前页面，只有跨页稳定语义进入共享类型；
5. 用 CSS 和确定性布局完成关系图，不引入重型图可视化依赖；
6. 实现以 1440×900 为主、1280×800 为次；保持基本不溢出 CSS，但移动端不设发布门；
7. 不写无真实失败模式支撑的防御分支与重复测试。

## 十六、验收

### 16.1 确定性测试

- 首页在 active Lesson 与无 active Lesson 时分别守住“继 / 问”唯一主行动和精确 route；

## 十七、最终判断

M1d 的完成标准不是“每张预览稿都像素复刻”，而是学生第一次打开真实学习集时，能够自然
地进入学习、看见老师仍在工作、理解资产从哪里来、回到自己的学习历史，并从少量语义词语
找到下一条联系；与此同时，M0—M1c 已建立的事实所有权、记忆边界和生命周期不被前端重新
搅在一起。
