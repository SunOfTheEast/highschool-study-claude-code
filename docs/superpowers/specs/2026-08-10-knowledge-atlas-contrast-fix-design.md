# 知识图谱左右区域对比度修复设计

**日期：** 2026-08-10
**范围：** StudyForge 桌面端知识图谱页
**状态：** 已确认方案

## 问题

学生无法迅速分辨左侧知识地图与右侧上下文活页的边界。

这不是布局宽度问题，而是三个样式因素叠加：

1. 地图画布与活页都使用接近的米白纸色；
2. 活页只有顶部朱砂线和低强度阴影，没有完整外轮廓；
3. `knowledge.css` 使用了未定义的 `--rule-strong`，因此浏览器会丢弃地图边框等依赖该变量的声明。

## 视觉决定

**视觉命题：** 左侧是铺开的工作底图，右侧是压在桌面上的独立活页；两者仍属于同一套纸张主题，但无需仔细观察就能分区。

- 在留白主题中补充一个比 `--rule` 明显、但不接近正文墨色的 `--rule-strong`；
- 地图画布继续使用网格纸和完整细框；
- 右侧活页改用 `--paper-deep`，增加完整的 `1px` 强分隔线，顶部继续由 `3px` 朱砂线覆盖；
- 保留现有左向纸张阴影，但不再依靠阴影单独承担分区；
- 不改变 7:3 布局、间距、文案、图谱语义、操作按钮或响应式断点。

## 内容与交互

本次没有内容结构变化：左侧仍负责探索关系，右侧仍负责查看当前焦点的完整上下文。

本次也不增加动画。边界必须在静止状态下成立，不依赖悬停、聚焦或过渡效果。

## 验收

- 样式令牌中存在明确的 `--rule-strong`；
- 地图画布拥有有效的完整外框；
- 活页拥有稍深纸色、完整外框和原有朱砂顶线；
- 1024px 与 1440px 桌面视口下两栏仍保持原布局且无横向溢出；
- 知识图谱功能测试、视觉语法测试、完整组件测试与 M1d E2E 均通过；
- 新旧截图对比中，学生无需阅读标题即可分辨地图和活页区域。

## 明确不做

- 不加粗所有分隔线；
- 不把右栏改成悬浮卡片或弹窗；
- 不改变全站纸张色板；
- 不借机调整图节点、字体、搜索栏或内容密度。
