# M2 共享头脑风暴与论文研究设计

**状态：** 已讨论定稿，等待实施计划

**日期：** 2026-08-11

**适用范围：** `apps/pi-teaching-web` 的 Free Learning 与 Lesson Tutor

**上位文档：** `2026-08-10-studyforge-m2-m4-milestone-outline.md`

## 一、问题与目标

StudyForge 已经能够让学生围绕一个问题自由讨论，也能在正式 Lesson 中根据真实回应调整教学；
Note、题卡、Material、平坦语义标签和关系投影已经提供了个人学习内容，原会话与活动记录则
提供可追溯的学习经历。但是当前 Skill 树没有一项可以被 Free Learning 与 Tutor 按需读取的、
明确面向发散问题的教学技巧。

现有能力不能简单等同于头脑风暴：

- 诊断、概念修复、方法比较、反例、迁移和检索练习已经存在，主要服务收敛的课堂判断；
- Peer persona 可以追问、联想或质疑，但一句人格描述不是可复用的学习方法；
- `/knowledge` 能展示标签共现，却不负责师生怎样共同把不同内容连起来；
- Free Learning 可以直接解释、追问和比较，但没有一条按需加载的发散技巧；
- 当前 Runtime 没有论文或网页检索能力，不能只靠提示词兑现“看看前沿研究”。

本设计只增加一个简单的共享教学技巧：当学生想发散、建立联系，或提出明显开放的问题时，
老师接住学生已经想到的内容，再按需利用学生的真实学习经历、学习集库存、模型世界知识和
外部论文共同展开。它不是知识图谱查询模式，不是教师列菜单，也不是一份自动生成的研究报告。

## 二、核心判断

### 2.1 头脑风暴是共同思考，不是推荐系统

学生是展开过程的参与者。老师先接住学生已经提出的联想、猜测、疑问或桥梁，再补充、质疑、
解释或继续搭桥。不能把流程写成“老师检索候选 → 学生从菜单选择”。学生可能自己先发现关键
联系，也可能只需要老师补一条路；两种情况都属于正常头脑风暴。

### 2.2 四路是可选信息源，不是四个必经阶段

头脑风暴可以从四种来源取得材料：

1. **学生真实经历。** 当前对话，以及能由原会话、作答活动或其他真实发生记录支持的旧内容。
   这一路可以说“你上次在……里遇到过”，用于重访、对照和迁移；资产单独存在不能进入此路。
2. **学习集库存。** Material、Note、题卡及其语义标签中已经存在、但没有证据表明学生接触过
   的内容。这一路可以提供新的例题、材料或桥梁，只能说“学习集中有一张相关题”之类的库存
   事实，不能改写成学生过去的经历、理解或掌握。库存内容在当前讨论中真正被学生使用以后，
   本次互动才成为新的学习经历；不能倒推学生以前见过它。
3. **模型的世界知识。** 模型可以提出学习集中尚未出现的概念、表示、应用、类比或问题。这些
   是当前生成的候选联系，不得冒充已有资产。
4. **可选外部论文。** 只有学生明确要求看看研究前沿，或接受老师的简短建议后才启动。论文只
   提供外部证据和新的桥接材料，不替代师生讨论。

哪一路对眼前问题有价值就使用哪一路。空白学习集不妨碍老师发散；已有丰富资产也不要求老师
每次同时检索和联网。不能为了流程完整而强制凑齐四路。四路在不同 Session 中仍受原有读取
权限约束；区分信息来源不会自动扩大文件或记忆权限。

### 2.3 语义共现只召回，老师负责关系判断

`semantics/indexes/asset-recall.tsv` 与派生的标签邻居只说明词语在资产中共同出现。它们不证明
先修、因果、相似、对立或教学优先级。老师公开一条联系时，应在普通语言中说明为什么可能
相关；关系可以是共同机制、边界对照、条件依赖、共同表示、方法迁移或自然引出的新问题。

本设计不新增关系类型、关系边或图数据库。真正讨论后形成的 Note 或题卡仍通过现有确认流程
保存，并携带平坦标签；关系投影随后从资产自然重建。

## 三、Session 路由

### 3.1 共享方法 reference

新增一个共享的按需 reference：

```text
apps/pi-teaching-web/resources/skills/references/learning-methods/brainstorming.md
```

它只拥有“怎样共同展开一个发散问题”的方法，不拥有 Session 权限、课程目标或资产写入规则。
首版只有一个方法文件，不预建 `INDEX.md`。

### 3.2 Free Learning

`free-learning/SKILL.md` 直接路由到该 reference：

- 学生主动要求发散、建立联系、一起想可能性或把多个内容串起来时直接读取；
- 学生不知道还能问什么，而当前锚点确实存在值得探索的方向时，老师可以用一句话建议；学生
  接受后再读取；
- 不因刚解释完一个概念、刚保存一个资产或看见很多标签而自动进入头脑风暴。

Free Learning 允许沿兴趣临时换方向，不要求最后回到预设目标，也不强制总结或保存。

### 3.3 Lesson Tutor

`tutor-lesson/SKILL.md` 在学生提出明显具有发散性的开放问题时直接读取同一 reference。Tutor
不需要先把这个问题变成新 Block，也不要求它预先出现在 Teacher Control 中。

何时继续、何时回到课堂主线，仍由 Tutor 已有的 Lesson Goal、一次一个教学动作和小幅可逆
调整边界决定。共享 reference 不复制这些 Session 规则，也不因为学生发散就擅自改 Plan。
学生许可后的 `paper_research` 是唯一新增的外部内容入口；返回内容只是当前讨论可用的临时
教学材料，不是课堂证据，也不授权 Tutor 搜索未链接资产或扩大文件读取范围。

## 四、共享技巧的最小行为

共享 reference 只需要一条正向亮线：

> 抓住当前一个或多个锚点 → 接住学生已经想到的联系 → 按需从真实学习经历、学习集库存、
> 模型知识或已获同意的论文研究补充一条路 → 与学生共同解释、检验、质疑或继续分叉。

它同时支持：

- **单锚点向外发散：** 从一个概念、问题、题卡或段落继续联想；
- **多锚点搭桥：** 学生同时选中或说出多个内容，尝试找到共同机制、中间概念、鲜明差异或
  值得验证的桥梁。

公开表达没有固定两栏、候选数量、轮数或收敛仪式。需要区分来源时，老师可以自然说“你的
学习集里有一张相关题……”；只有真实活动记录支持时才能说“你以前想过这题”。新的方向可以
说成“这里我还想到一条新的线……”，不能播报内部路由。每条真正拿出来讨论的联系要说明
理由，不能只抛术语。

学生可以继续发散、追问其中一条、反驳联系或换方向。老师不追求完整知识图谱、最佳联系或
覆盖所有可能性；当前讨论已经自然形成下一步时就继续，不为证明 Skill 被调用而增加流程。

## 五、四个信息源的边界

### 5.1 学生真实经历与当前对话

当前 Session 中学生已经说出、推导、作答或明确选入讨论的内容可以直接使用。回访更早经历时，
老师必须能够沿现有会话或活动记录指回真实发生的互动；找到了内容相似的资产文件，不等于
找到了学生经历。没有活动证据时应转入下一节的“学习集库存”，而不是猜测学生见过。

对象记忆只能在当前 Session 原有记忆契约允许读取时静默帮助老师判断哪条联系更适合这个
学生，例如是否值得重访一个旧边界；共享技巧本身不扩大记忆权限。对象记忆不是公开知识
资产，不能被展示成图节点或宣读为学生画像。

### 5.2 学习集库存

Free Learning 需要寻找学习集中已有但尚未接触的材料时，可以使用现有 `read` / `grep` 对安全
召回索引做短词检索；只沿少量相关精确路径读取，不枚举题库，也不为证明“没有相关材料”遍历
全库。召回结果必须指回真实资产，并保留“这是可用库存，不是学生经历”的边界。

Lesson 仍只使用当前对话、当前 `Uses` 已经授权的资产，以及 Tutor 原有契约另外允许的召回
路线；共享技巧不替 Tutor 打开全库。Lesson 中恰好存在一张合适但未链接的题，不等于 Tutor
获得了搜索或读取它的权限。

### 5.3 模型世界知识

老师可以直接使用可靠的学科知识补充新联系，不必先搜索资产或论文。新联系与学习集不一致时
应区分来源；存在不确定性时如实表达并决定是否需要外部核验。

例如学生问 `e^x + e^{-x}` 有什么特别之处：

- 学生过去真实讨论过的内容，可以把它接回当时形成的偶函数、指数不等式或对称换元经验；
- 学习集库存中尚未接触的题卡，可能提供一条新的导数最值或恒等变形入口；
- 模型知识可以指出它是 `2 cosh(x)`，满足 `f'' = f`，并继续连接双曲恒等式、悬链线或
  洛伦兹变换；
- 学生希望继续追到研究前沿时，论文检索可以补充一个有真实来源的现代应用；
- 这些内容应围绕学生真正感兴趣的桥展开，而不是一次性倾倒百科目录。

### 5.4 外部论文

论文路线必须由学生明确提出或接受建议后启动。启动许可只授权这一次研究，不自动改变以后
的默认行为。检索查询不携带学生姓名、对象记忆、能力判断或与学术问题无关的原话。

论文结果是外部内容事实，不是学生表现。查看、讨论或保存论文也不自动更新对象记忆。

## 六、Paper Research Scout

### 6.1 为什么独立

论文搜索可能需要改写查询、查看摘要、核对来源并消耗明显时间。把这些内容全部放进教师
Session 会污染上下文，也会让简单头脑风暴退化成检索任务。因此由一个新鲜上下文的只读
Paper Research Scout 完成，教师只接收有界桥接材料。

DeepTutor 的 Deep Research 已验证“问题改写—分解—研究块—带引用报告”的完整 capability
可以运行在统一 agent engine 上；本设计只借用“研究能力可被对话按需调用”的边界，不复制
它的完整报告流水线：

- <https://github.com/HKUDS/DeepTutor/releases>
- <https://github.com/HKUDS/DeepTutor>

### 6.2 对外工具边界

Free Learning 与 Lesson 获得一个语义明确的 `paper_research` 工具，而不是开放通用
`subagent`、shell 或浏览器。父教师提交：

- 当前学术锚点；
- 学生真正想继续追问的桥接问题；
- 为解释难度所需的最少学生层级信息。

工具不接收 Session 路径、资产写入请求、记忆更新或“替我回答学生”的长提示。Runtime 负责
启动固定的 Paper Research Scout、联网检索、进度事件和失败降级。

### 6.3 首版论文源

首版使用 Semantic Scholar Academic Graph 的公开 relevance search 作为默认论文目录。官方
说明大多数 endpoint 可不带 API key 使用，但匿名请求共享限流；API 可以返回题名、年份、
作者、摘要、页面链接和开放 PDF 等按需字段。首版只请求解释当前桥梁必需的元数据与摘要，
不自动下载全文：

- <https://www.semanticscholar.org/product/api>
- <https://api.semanticscholar.org/api-docs/graph>

匿名访问失败、被限流、离线或没有合适论文时，Scout 如实返回不可用或未找到；教师继续使用
前三路，不自动重试、不改用未经设计的网页抓取，也不把模型记忆伪装成已检索论文。以后可在
设置中增加可选 API key 或替换 provider，但不把 provider 细节写入教学 Skill。

公开发版前必须复核 Semantic Scholar 当时的 API 条款、归属展示和商业使用边界；provider
保持可替换，不能让一个第三方目录成为头脑风暴 Skill 的语义主人。

### 6.4 返回给教师的内容

Scout 返回少量可以继续讨论的桥接材料，而不是完整综述：

- 论文题名、年份、作者或机构的必要识别信息；
- 可打开的来源链接；
- 由摘要或公开元数据直接支持的核心发现；
- 它为什么可能连接当前学生问题；
- 证据不足、论文较旧、仅有预印本或无法读取摘要等限制。近期发表不自动等于前沿、可靠或
  适合当前问题，Scout 必须根据实际内容限制措辞。

教师负责把结果与学生真实经历、学习集库存和模型知识编织成自然回应。Scout 不直接对学生
说话，不形成新的 Session、记忆、Note、题卡、Material 或关系边。

### 6.5 学生可见进度

论文研究不能复用一条静态“老师查看了相关内容”让学生长时间等待。前端沿既有工具活动投影
显示真实阶段，例如正在搜索、正在核对来源、已经返回；错误使用普通语言安静降级，不暴露
tool name、HTTP 状态、内部 query 或 agent ID。文字对话仍是事实主人，进度不是新学习事件。

## 七、资产、记忆与 Peer

- 头脑风暴不自动调用 `save_note`、`save_problem_card` 或记忆提交；只有真实讨论满足现有门
  且学生明确确认时才保存。
- 新 Note 或题卡仍写平坦 `core` / `related` 标签；不会持久化“老师认为 A 导致 B”的边。
- 学生在头脑风暴中真正重新解释、推导、比较或使用一个联系，并改变教师对对象当前位置的
  判断时，现有 Free Learning / Lesson 记忆门仍可独立触发；Skill 本身不创造证据。
- Peer 可以在学生点名或接受教师建议后参与头脑风暴，但不是必需步骤，也不因加载该 Skill
  自动出场。Peer 发言仍是教学帮助，不是学生表现。

## 八、方案比较与选择

### 方案 A：把完整方法写进两个根 Skill

实现直接，但会重复正文、长期常驻，并使 Free Learning 与 Tutor 的 Session 边界和认知方法
混在一起。后续修改容易漂移。

### 方案 B：共享按需 reference + Session 各自路由（采用）

共享文件只拥有头脑风暴方法；两个根 Skill 用可观察条件直接读取。它保留按需加载，复用真正
相同的认知动作，又让 Free Learning 与 Lesson 各自承担节奏和权限。

### 方案 C：把头脑风暴做成 Runtime 模式或图查询工具

结构化程度过高。Runtime 无法决定一个联系是否具有教学价值，也无法承担学生已有联想和模型
世界知识。Runtime 只为确实需要联网与隔离的论文研究提供原子入口。

## 九、实施改动面

预计实施只触及以下表面：

1. 新增共享 `brainstorming.md` reference；
2. 在 `free-learning/SKILL.md` 与 `tutor-lesson/SKILL.md` 各增加一条直接路由；
3. 新增只读 Paper Research Scout 资源；
4. 新增 Semantic Scholar 客户端、范围绑定的 `paper_research` 工具和最小返回契约；
5. 为 Free Learning 与 Lesson 装配该工具，不开放通用 `subagent`；
6. 将研究进度和失败翻译成学生可见活动；
7. 增加机械测试与真实模型行为验收。

不修改课程、资产、语义标签、对象记忆或 Pi Session 的 durable schema。

## 十、验证设计

### 10.1 Skill RED / GREEN

按照 Skill TDD，先在没有新增 reference 和路由时运行真实模型基线，记录首次行为，而不是先写
正文后证明它有效。至少覆盖：

1. 有活动证据的单锚点：学生问一个陌生函数的特点，观察老师能否诚实接回学生过去真实讨论
   过的内容，而不是只讲世界知识；
2. 只有库存命中：题库中存在高度相关但学生从未接触的题，观察老师是否把库存发现虚构成
   “你以前做过”，以及是否把标签共现说成已经成立的关系；
3. 空白学习集：观察老师是否仍能共同发散，而不是因无资产停止；
4. 多锚点搭桥：观察老师是否分别总结两个资产，却没有建立可解释的桥；
5. Lesson 发散问题：观察 Tutor 是否压住学生问题、越权搜索未链接库存、无边界地改课，或能
   在现有权限内做一次自然展开；
6. 论文未获许可：观察老师是否擅自联网；
7. 论文已获许可：观察研究结果是否带真实来源，并被教师与真实经历、库存资产和模型知识串回
   同一讨论。

GREEN 使用相同情境，只增加 Skill 与工具；不把预期答案、失败诊断或固定措辞泄漏给验证模型。

### 10.2 机械测试

机械测试只覆盖可执行契约：

- 两个 Session 能发现共享 reference，其他角色不会误加载；
- `paper_research` 只在 Free Learning 与 Lesson 可用；
- 工具输入不接受路径、写入或学生画像字段；
- Semantic Scholar 结果经过有界字段解析，超时、限流、空结果和无摘要安静失败；
- Scout 无文件写入和记忆权限；
- 研究进度、完成和失败不暴露内部标识；
- 工具结果不自动生成资产、关系或记忆。

不为 Skill 全文或固定中文措辞编写快照测试。

### 10.3 成功标准

- 首次回应接住学生已有想法，而不是直接倾倒关联清单；
- 有活动证据时能够重访学生经历；只有库存命中时只介绍可用内容，不伪造过去；
- 模型能够提出学习集外的新联系，并说明关系；
- 四路不被强制凑齐，普通问题不触发论文检索；
- 获得许可的论文结果有可打开来源，并被教师转化为当前学生能进入的桥；
- Lesson 中的发散动作自然发生，又不改写课程目标或证据边界；
- 没有新增 durable schema、关系边、掌握判断或隐藏写入。

## 十一、明确不做

- 不在本轮实现完整 Deep Research、多轮系统综述或长报告编辑器；
- 不把标签共现升级成 canonical 知识图谱；
- 不要求每次头脑风暴列固定数量的方向或完成固定收束；
- 不让老师代替学生生成全部联系；
- 不把外部论文、Peer 发言或教师解释当作学生学习证据；
- 不自动下载或保存论文全文；
- 不同时扩展其他学习方法、Peer 预设编辑、日历、番茄钟或遗忘复习。

## 十二、定稿决策

1. 首个新增学习方法是共享的简单头脑风暴技巧，不是语义推荐器。
2. Free Learning 与 Lesson 都可以按可观察情境读取；Lesson 入口由学生的发散问题触发。
3. 四路来源是学生真实经历、学习集库存、模型世界知识和经学生许可的可选论文研究。
4. 学生已有联想优先；四路可选，不形成固定工作流。
5. 标签共现只召回，老师解释关系；关系不持久化。
6. Paper Research Scout 返回桥接材料而非完整报告，教师负责串联。
7. 首版论文目录使用 Semantic Scholar，失败不妨碍前三路。
8. 资产、记忆、Peer 和课程继续遵守各自现有所有权与确认门。
