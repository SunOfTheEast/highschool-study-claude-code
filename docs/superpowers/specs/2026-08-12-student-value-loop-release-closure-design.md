# StudyForge 学生价值闭环与发布收口设计

**状态：** 已失效，不得作为实施依据
**日期：** 2026-08-12
**实现基线：** `0163fd8`
**审计来源：** `docs/audits/2026-08-12-student-experience-release-audit.md`

> 本文是逐条事实复核前的候选方案，保留作设计过程记录。其中“保存不自动加入复习”、
> “逾期复习固定最多五项”和“新增共享诊断 Skill”等结论，已经被后续复核撤回。
> 当前发布收口以 `docs/audits/2026-08-12-student-experience-release-audit.md` 为唯一实施依据。

## 一、目标

本设计不再新增一组并列功能，而是把 StudyForge 已有的自由学习、资产、记忆、日历和复习
收束成一个学生能够亲自感知的价值闭环：

```text
普通学生第一次进入
→ 带着一个真实问题开始
→ 当下真正理解或独立完成一步
→ 按需留下资产、记忆或下一步
→ 第二次回来时准确续接
```

闭环回答三个问题：

- **现在为什么有用：** 不是收到一篇答案，而是把问题想明白并自己完成一步；
- **下次为什么回来：** 不用重新介绍，系统从真实停点之后继续；
- **长期为什么留下：** 对话逐渐成为可读、可修订、可复习、可追溯的个人学习环境。

核心学生表达是：

> 不只告诉你答案，而是和你一起确认真正卡在哪一步，再让你自己走通一次。下次回来，
> 从这次之后继续。

## 二、三种收口方案

### 方案 A：只做首页与文案

把价值主张写进首页、帮助和官网，增加“今日”、搜索和能力示例。改动快，但学生第一次学习
后若仍看不见承接，文案会成为空承诺。

### 方案 B：先重做完整资产工作台

一次完成阅读器、文件夹、搜索、标签、历史、导出、图片和批量管理。资产体验会明显增强，
但范围过大，也不能证明学生会在第二次回来继续学习。

### 方案 C：价值闭环优先（采用）

先保证第一次进入、第一次真实收益、可选固化和第二次准确续接，再把 Material 阅读器与资产
工作台作为第二批能力。它直接验证产品最承重的采用假设，又不要求一次重建所有子系统。

## 三、闭环参与者与事实边界

| 参与者 | 责任 | 不负责 |
| --- | --- | --- |
| 应用壳 | 推荐设置、跨集“我的今天”、导航与可及性 | 教学判断、掌握推断 |
| Tutor | 回应问题、观察表现、给最小帮助、提出可选下一步 | Runtime 身份、时间、路径和自动排程 |
| 原生 Session | 保存真实对话及 actor 顺序 | 代替对象记忆或资产 |
| Note / 题卡 | 保存学生以后继续使用的内容 | 证明学生掌握 |
| 对象记忆 | 保存有证据边界的当前教学判断与流变 | 保存教师待办、课程安排或资产正文 |
| Calendar / Review history | 保存约定和真实复习事件 | 判断知识轻重、考试优先级或能力变化 |
| 学习足迹 | 投影已经发生的事实并回到来源 | 新写一份进步结论 |

本设计不新增“价值闭环记录”或“首次学习完成”事实。闭环是否发生由现有 Session、作答、
资产、对象记忆、复习和日历事实共同验收，不再持久化一个重复状态。

## 四、端到端学生体验

### 4.1 第一次进入

面向普通学生的默认路径不出现 Provider 清单、Scout、思考强度或 TTS 参数。学生完成一种
推荐授权后即可进入；现有开放模型配置保留在高级设置。推荐使用哪个授权与模型组合由切片 A
的小设计结合当时可用服务决定，本伞形设计只规定默认路径不暴露模型拓扑。

首次设置用一句可展开的说明准确表达：学习文件保存在本机；向老师发消息时，本轮消息和回答
所需的相关上下文会发送给学生选择的模型服务商。不得把“本地保存”写成“内容从不离开电脑”。

首次首页只有三个需要理解的区域：

1. **我的今天：** 今天已有的约定、待复习小批次、可继续的活动；没有内容时安静说明；
2. **问老师：** 允许从一句问题、猜想或不会开始；
3. **当前学习集：** 课程、资料与最近学习的入口。

“我的今天”属于应用壳并跨学习集投影。它只聚合现有约定、复习候选和可继续入口；点击其他
学习集内容时先切换学习集再打开。学习集记忆保持隔离。

### 4.2 第一次真实学习

学生使用普通语言提问。Tutor 先处理眼前问题，不要求制定目标、创建课程或保存资产。首段
回应必须与学生提供的具体内容相连，不能用产品介绍代替教学。

首日差异首先来自教师能否选对教学动作，而不是是否启动了一套诊断流程：

- 学生只需要一个事实时，直接准确回答；
- 学生明确要求讲解时，讲到足以解决眼前问题的概念边界，再归还一个小动作；
- 学生带来真实错题、互相矛盾的解释或明显说不清的困惑时，如果教师已有两种以上会导向
  不同教法的合理解释、现有证据又不足，才进入短诊断；
- 学生已有一条可能成立的复杂路线时，先核验并认真重建这条路线，再按需攻击关键环节、
  比较平行路线或换外壳检验，不先假设学生存在缺陷。

短诊断只服务眼前教学决策。共享方法的亮线是：保留几种合理解释 → 给一个最有区分力的
短动作 → 保留学生无帮助的首次表现 → 形成可推翻的暂定判断 → 深入解决当前缺口 → 归还
一个独立动作。学生拿不出真题或无法准确描述问题时，可以现场给一个很短的探针；邀请学生
提供真实材料不能成为开始教学的门槛。诊断结果不在自由学习里升级为 Roadmap、Plan、能力
标签或永久结论；一次短探针本身也不足以触发对象记忆，之后真正出现的认知变化仍按 4.3 的
既有门槛判断。

“三回合”只作为首日体验的验收目标：学生已经给出足以处理的材料时从该条消息起算；材料
不足时从教师启动第一个短探针起算。此后尽量在不超过三次教师回应内让学生看见当前卡点或
路线已经被准确理解，并得到与之对应的教学动作。它不是 Skill 里的固定轮次，也不能为了赶
回合数过早宣判。

一次真实收益至少出现以下一种可观察行为：

- 学生重新解释了关键关系；
- 学生独立完成了一个小步骤；
- 学生比较了两条路线并说出边界；
- 学生识别并修正了原先的错误前提；
- 学生提出了比最初更准确的问题。

教师讲完、学生说“懂了”、打开答案或保存资产都不构成这一步。若学生只需要查一个事实，
正常给出事实即可，不强迫把短问答改造成检验。首日是否形成题卡、对象记忆或预约仍由
4.3 的各自条件决定，不能把它们包装成每次首晚必须领取的“奖杯”。

### 4.3 可选固化

学习过程中只有三种独立的后续结果：

1. **资产：** 已形成学生以后想继续使用的内容；
2. **对象记忆：** 本次真实表现改变了未来教师对该对象的判断；
3. **约定：** 学生愿意在一个明确时间继续。

三者互不触发：

- 保存资产不自动加入复习；
- 保存或复习资产不自动写对象记忆；
- 写对象记忆不自动创建资产或约定；
- 结束 Session 不自动执行任何一种固化。

资产仍采用公开草稿、自然语言修订和明确确认。学生只确认“保存”时仅保存；只有明确选择
“保存并加入复习”或以后从详情页主动加入，才产生 enrollment 事件。

对象记忆仍只在真实认知变化满足既有门槛时写入。为了让长期能力可理解，前端可以在写入
成功后投影一条安静、可打开的“老师记下了”回执；没有真实变化就不显示。回执来自已经成功
写入的记忆，不让 Tutor 为展示功能强行生成判断。

当存在清楚且未完成的后续动作时，Tutor 可以在自然收口处提议一次预约；学生忽略、拒绝或
没有明确后续时停止。不得把预约作为每次对话的结课仪式。

### 4.4 结束与离开

学生显式结束时，Tutor 自然收住。可以用一句话说明“下次可以从哪里继续”，但不强制总结、
复盘、记忆或资产。关闭页面、沉默、断网和开启另一线程都不推断为学完。

若 Session 已产生可恢复的未完成写入，Runtime 按各事实自己的幂等与恢复协议处理；学生价值
闭环不另建统一事务。

### 4.5 第二次回来

首页先回答“今天可以做什么”，而不是只介绍当前学习集：

- 已有约定：显示时间与主题；
- 有逾期资产：按学习集显示总数；每次主行动只在一个学习集中带入最早到期的最多五项；
- 有未结束线程或进行中课程：提供准确的继续入口；
- 什么都没有：允许直接问一个新问题，不制造空状态焦虑。

学生重新进入相关学习时，Tutor 先使用当前问题和眼前表现，再按需沿记忆索引读取相关对象。
历史只能帮助选择解释或检验，不能覆盖学生本轮表现。若历史确实改变了本轮动作，教师可以用
学生语言说明承接点，例如“上次你已经能在提示下分清这两种情况，这次先看看没有提示时能否
认出来”，不朗读内部画像。

## 五、第一阶段的五个独立切片

本文件是发布收口的伞形设计，不直接对应一个实施计划。第一阶段拆成五个能够分别实现、回归
和真实验收的垂直切片；不得把五个切片塞进同一份计划后并行改写整个产品。

### 切片 0：首日教学深度

1. 抽出一条不含 Session 持久化语义的共享短诊断方法；
2. Free Learning 只在当前教法取决于区分多种合理解释时按需读取；
3. Lesson 用它处理备课预案外的新问题；Roadmap 保留决定长期方向与 Plan 的上层触发和
   记录边界，不把两种 Session 混成一套流程；
4. 用真实模型分别验收直接回答、深度讲解、短诊断和强学生路线挑战的首击分流与教学结果。

### 切片 A：第一次进入与应用首页

1. 推荐设置的一键路径，高级配置继续存在；
2. 应用级“我的今天”，聚合跨集约定、复习候选和继续入口；
3. 应用级标准 / 大字与关键对比度复核；
4. 首次设置和帮助中的准确数据边界。

### 切片 B：复习事实与回归体验

1. 保存资产与加入复习分开；
2. 逾期复习默认小批次，完整列表可展开；
3. 既有自动入队历史继续兼容，不改写旧事件。

### 切片 C：资产找回

1. 学习资料页本地关键词与标签搜索；
2. 搜索只使用学生可见投影；
3. 519 张 legacy 题卡与新资产使用同一入口。

### 切片 D：第二次续接显形

1. 赴约打开后，用既有约定事实自然接话；
2. 记忆成功写入后，只投影与学习足迹相同的公开变化摘要和证据入口，不公开内部 Current
   Judgment、Boundaries 或能力假设，不强制首次记忆；
3. 第二次相关学习优先使用眼前表现，再按需读取历史。

以下不进入同一个实施计划：

- 完整 Material PDF 阅读器；
- Note 历史、Markdown 预览、目录与详情页邻居；
- 标签学生编辑与学习回望；
- 通用教学内核拆分；
- 重要日期、批量导入、音频、图片 Note、移动端；
- 阿夏的日历与专注提醒投影。

它们保留在总审计的第二、第三批，并分别立小设计。第一阶段不能为了“顺手”引入文件夹、Topic、
跨集学生模型、考试调度或新的进步分数。

## 六、异常与降级

- “我的今天”某个学习集暂时不可读时，保留其他学习集内容并把该项标为暂不可用，不猜测数据；
- 跨集项打开失败时留在当前页面，说明可以采取的下一步，不暴露绝对路径或内部 Session key；
- 模型未配置或授权失效时，自助资产阅读和复习仍可使用，问老师入口给出直接恢复授权的路径；
- 记忆写入失败时不显示成功回执，不阻塞学生继续对话或结束；
- 复习候选中资产缺失时不进入默认小批次，原始复习历史不被删除；
- 搜索只返回当前可读取的学生投影，不泄露标准答案或教师专用字段。

## 七、验收设计

### 7.1 自动回归

1. “只保存”不产生 enrollment；明确“加入复习”才追加事件；
2. 历史自动入队资产保持兼容，移出、重启和后续复习事件仍可读取；
3. 47 个逾期候选仍全部存在；每个学习集默认按既有确定性顺序带入最多五项，学生可展开选择
   更多，不把不同学习集的资产混进同一个复习 Session；
4. “我的今天”跨学习集聚合事实，打开时正确切换学习集，不读取或合并其他集的记忆；
5. 搜索不返回隐藏答案和教师讲解字段；
6. 字号切换跨重启保留，主要桌面页面不横向溢出；
7. 记忆回执只在真实写入成功后出现，并能回到对应对象记忆或证据；
8. 打开约定只记录 opened，不记录完成、复习结果或掌握。

### 7.2 真实模型验收

使用普通学生话语，不告诉模型产品规则：

- 学生只问一个很小的事实问题时，教师直接回答，不强制诊断、保存、预约或写记忆；
- 学生只说“我就是搞不懂”且拿不出材料时，教师能用一个短而有区分力的动作开始，而不是
  要求学生先准确描述自己的问题；
- 学生很自信地给出错误前提时，教师把判断作为待验证假设，定位决定性分歧后再修复；
- 学生只是表达不严谨但概念并未错误时，教师不虚构误解或给学生贴标签；
- 强学生提出一条有效但非参考答案的路线时，教师先核验这条路线，再攻击、比较或迁移，
  不把“不同”误判为“不会”；
- 学生明确只想听一次讲解时，教师讲清边界并按需归还小动作，不把讲解改造成连续审问；
- 学生发生真实理解变化时，教师能以正确边界写对象记忆；
- 学生说“保存吧”时只保存，不擅自加入复习；
- 学生明确说“以后考我”时，保存后进入复习；
- 第二次进入时，教师只读取相关历史并以当前表现为准；
- 预约打开后教师接住既有主题，但不宣称学生已经开始或完成学习。

记录首击教学分流正确率、误诊率、探针区分力、修复或路线处理深度、独立动作是否归还、从
首条有效证据到学生可感知收获的教师回应数、工具调用、首段有效回应时间、总响应时间和学生
可见等待状态。模型失败不靠学生提醒后再算通过；“三回合内出现收获”作为体验指标，不覆盖
不误判和不提前泄露决定性方法的优先级。

### 7.3 真实学生验收

至少观察以下完整行为，而不是询问学生“喜不喜欢”：

1. 在没有口头指导的情况下完成首次进入；
2. 用自己的真实问题开始，而不是照测试脚本提要求；
3. 出现一次可观察的理解或独立动作；
4. 自己决定是否保存、加入复习或离开；
5. 隔天或隔周再次打开，找到上次内容并继续；
6. 资产达到几十项后能找到目标；
7. 有较多逾期项时愿意开始一个小批次，而不是直接关闭。

记录卡点、误解、退出位置和实际回访，不用模拟学生的高质量回答证明教学有效。学习效果需要
更长周期的真实数据，首轮只验证可进入、可理解、可续接和事实边界。

## 八、完成标准

第一阶段完成不等于全部审计缺口关闭。它只在以下条件同时成立时通过：

- 普通学生不理解模型架构也能进入；
- 第一次真实学习能根据证据选择直接回答、深度讲解、短诊断或路线挑战，不把所有学生拉进
  同一套诊断流程；
- 首页能回答今天可以做什么；
- 学生能找到已有资产；
- 保存不再自动制造复习债务，积压不会变成一次性悬崖；
- 第一次学习可以获得当下收益而不被迫形成产物；
- 真实变化若被记住，学生能看见且回到依据；
- 第二次学习确实从上次之后继续；
- 跨学习集投影、可及性与异常路径不破坏既有课程、资产、记忆和复习事实。

完成后才进入第二批 Material 阅读器与资产可读性设计。新的模拟角色不构成继续扩范围的理由。
