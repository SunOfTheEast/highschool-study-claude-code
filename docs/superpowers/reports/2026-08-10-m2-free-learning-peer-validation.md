# StudyForge M2 自由学习 Peer 首闭环验收报告

**日期：** 2026-08-10  
**范围：** 自由学习中的单个文字 Peer“阿澄”  
**模型：** Sol 教师（high）与 Terra Peer（high）

## 结论

首闭环通过。学生明确邀请阿澄后，教师会调用一次 `ask_peer`，阿澄以独立的 AI 同学身份
公开发言，随后教师在同一轮继续主持。普通提问、只提到名字、尚未接受教师邀请时均不会
触发 Peer。

Peer 回复作为原生工具结果持久化，刷新后不会复制或重跑。Peer 只获得学生可见的对话与
资产内容；未揭示的标准答案、`teacherRationale`、教师思考和记忆均未泄露。调用失败或取消
只留下失败结果，不伪造 Peer 发言，原线程随后仍可继续。

## 真实模型情境

| 情境 | 结果 |
| --- | --- |
| 普通化学提问 | 未调用 Peer |
| “阿澄你怎么看” | 恰好一条 Peer 回复，教师正常续接 |
| 只说“我同桌阿澄说……” | 未误判为邀请 |
| 教师建议、学生先拒绝后接受 | 拒绝时不调用，接受后调用一次 |
| Peer 提出争议观点 | 教师明确归因后给出自己的判断，身份未混淆 |
| 带未揭示答案的题卡 | Peer 看见题干、学生笔记和作答，看不见隐藏答案与教师依据 |
| Peer 调用中止 | 无伪造成功消息，原 Session 可继续 |
| Peer 后学生重新解释 | 记忆明确保留“在阿澄提醒后”的帮助边界 |

验收中同时校正了一条过严边界：不能凭 Peer 回复本身新增或抬高学生记忆，但邀请 Peer 之前
已经发生的真实学生表现仍可记录。否则会错误丢弃本轮已经出现的学生证据。

## 响应节奏

| 情境 | 教师发起 Peer | Peer 完成 | 教师续接 | 总时长 |
| --- | ---: | ---: | ---: | ---: |
| 题卡讨论 | 11.56 s | 9.62 s | 6.02 s | 27.21 s |
| 争议观点 | 8.82 s | 5.86 s | 14.36 s | 29.04 s |
| 记忆边界 | 10.46 s | 5.68 s | 5.17 s | 21.31 s |

Peer 当前使用一次性非流式生成，因此只能观测完整回复时间，不能观测首字时间。首轮总节奏
约为 21–29 秒，可用于实验；后续若要进一步改善体感，应优先增加流式 Peer 输出，而不是
增加新的语义路由层。
