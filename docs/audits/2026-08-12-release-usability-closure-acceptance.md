# StudyForge 发布可用性收口验收

**日期：** 2026-08-12  
**验收基线：** `1eefd67`  
**结论：** 本轮发布可用性收口通过；可交给内测学生使用。书籍来源主路、PDF 阅读器与学习集蒸馏仍按计划留给下一阶段。

## 一、交付面

本轮没有改变既有学习事实所有权，也没有新增掌握度、自动诊断标签或复习配额。完成的改动包括：

- OAuth 后为未手动填写的教师与 Scout 模型回填推荐配置，并统一说明本机保存与模型处理边界；
- 日历、资料导入和模型工具活动使用学生可理解的成功、等待和失败投影；
- 资料架可按标题、学生可见正文、来源和标签查找，519 张 legacy 题卡使用召回索引而非逐卡重解析；
- Material 页将内部 locator 翻译成页码或行段导航；
- Note 支持未保存草稿预览，Note 与题卡支持学生安全的内容历史；
- 标签可进入知识图谱，详情页显示可解释的“共享标签”关系；
- 直接复习结果进入学习足迹；
- 增加标准 / 大字阅读偏好，以及五个自然语言学习方法入口；
- 批量复习 Session 只预装完整轻量索引，正文按需读取；普通自由学习仍保留 12 份完整上下文边界；
- 常驻教学核心拆成跨学科原则，数学方法改为按需读取；
- 真实 DMG 走查中补齐两个漏项：HTTP 层允许 13 项以上 review，以及知识关系投影直接复用已有索引。

## 五、仍需保留的真实风险

1. **严格限定题库来源、一次要求两个不同外壳且禁止高级方法的 Scout 压力样本，完成耗时 518.9 s。** Scout 确实先快速返回候选，但 Coach 深核验后发现其中一题违反“禁止高级方法”，随后窄检索和词表别名使总耗时显著增长。现有契约已经明确“够用而非最优、达到数量即停”，不再追加同义提示词；这项应在真实备课分布中继续测，而不是凭一个刻意严格样本改架构。
2. **普通教学首个可见反馈多为 3.8–14.8 s，完整回答约 19.8–48.3 s；Plan 与备课明显更久。** 本轮已让真实工具阶段可见并去重，但模型推理本身仍是主要延迟。
3. **一次备课遇到上游 WebSocket 1006。** 系统恢复正确，说明持久化边界有效；Provider 稳定性不是提示词能消除的风险。
4. **Roadmap 方案话术仍曾建议学生回复一个显式确认短语。** Runtime 已接受自然语言确认，没有语义正则门；后续可继续把教师话术变自然，但这不是物化阻塞。
5. **启动首次读取大规模货架时，旧 DMG 曾出现长空档。** 最终代码已将货架与知识关系都切到索引，并在最终包分别测得 0.020 s 与 0.115 s。后续若索引缺失仍会诚实回退到源文件，首次打开会较慢，这是兼容路径而非日常路径。

## 六、发布判断

本轮完成定义已经满足：发布阻塞与 7.1–7.3 的小缺陷都有实现、自动回归或真实走查结论；学生端不再要求内部 locator，13+ 复习不靠提高全文上下文上限，通用核心不再常驻数学责任，打包和真实模型链路都有新鲜证据。

因此当前版本适合进入小范围真实学生内测。下一条产品主路仍是已经确定的“书籍作为固态胶水与来源骨架”：上传 / 精选 / 模型生成的书，保留章节顺序与原文回溯，再让多本书之上的学习集承载共识和跨书联系。本轮没有把它偷塞进发布小修。
