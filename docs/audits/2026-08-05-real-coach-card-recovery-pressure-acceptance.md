# 真实 Coach 原题恢复压力验收

日期：2026-08-05

分支：`codex/gentle-judgment-isomorphic-acceptance`

运行起点：`3ca14199ff30b1af53f2cc157dc0205f5e13622e`

实验设计：`docs/superpowers/specs/2026-08-05-real-coach-card-recovery-pressure-design.md`

## 结论

Phase 2 **未通过**。四个真实 Plan Coach 情境中，精确原题恢复为 **0 / 4**；没有一次
为“找回学生丢失的原题”建立检索 brief 并调用 Material Scout。唯一一次真实 Scout 调用
发生在 C4，但它只为课末短检查找题，与原题恢复无关。

这不是 sidecar 召回能力退化。Phase 1 已证明规范 brief 可以稳定命中；本轮失败发生在更
上游：当前备课流程没有把“学生只能模糊回忆、但课程承诺使用其原题”识别成一个必需的
原题恢复槽位。Coach 因而把缺失原题当成可自行重构的内部细节，或者假定学生上课时会把
原题带来，只给辅助练习建立槽位。

最终教学效果没有整齐地一起坏掉：C3 虽无来源证据，却凭学生记忆重建出正确题面与完整
教学主线；C2 也准确处理了下界不足以判号的局部问题。但 C1 的教学主线漏掉决定性的第二层
转换，C4 则停在泛化的“符号加单调性”框架，没有解释原题特殊偏移为什么成立。因此本轮
不能用“Lesson 都写出来了”掩盖检索与教学理解的失败。

## 分层结果

| 情境 | 诊断与讨论 | 原题 brief | 精确恢复 | 深核验与教学理解 | 物化与体验 |
|---|---|---|---|---|---|
| C1 · 构造后回不到原函数 | PARTIAL | FAIL | FAIL | FAIL | PARTIAL |
| C2 · 下界不足与命题真假 | PARTIAL | FAIL | FAIL | PARTIAL | PARTIAL |
| C3 · 固定参数与点态参数 | PASS | FAIL | FAIL | PARTIAL | PARTIAL |
| C4 · 偏移比较与零点位置 | PASS | FAIL | FAIL | FAIL | PARTIAL |

“精确恢复”按设计要求目标卡路径进入 Scout 候选并由父 Coach 完整核验。题面恰好被重构出来、
相似题可用或辅助练习合适，都不能替代这一层。

### C1

公开讨论抓到了“辅助函数结论怎样回到原函数”与“特殊点闲置”，但没有继续问到足以区分
两层构造的题面结构。确认后父 Coach 直接枚举题卡目录、读取图谱并自行写课，没有调用
Scout，也没有读取目标卡。

最终 Lesson 把路线写成“新函数单调后展开定义并代入特殊点”。真实原题中，第一层构造
只消去原关系，不能直接推出原函数的单调性；还需要第二层符号转换并由特殊点锁定全局高度。
因此这不是措辞略粗，而是决定性教学路线错误。Lesson 还在写入公开批准设计之前就开始读
模板和搜材料，物化顺序也未完全守住。

### C2

Coach 准确说明了“不恒正的下界不能推出导数恒正，也不能反向推出导数为负”，但在 Plan
讨论阶段已经讲了较多正式教学内容。原题丢失后，它把记忆中的一部分重建成工作版，未搜索
完整多选题。

Lesson 对学生的真实误判有教学价值，也给出了反例来区分“当前证明不够”与“命题确实不
成立”；但它只处理了原题的一个选项，没有找到与题设同向的替代构造，也没有完成其余选项
依赖的路线。因此教学理解记为 PARTIAL，不是 PASS。

### C3

这是四组里公开诊断和成课质量最好的一组。Coach 清楚地区分了“每个点各选一个参数”和
“同一个参数对所有点成立”，并把公共交集、固定水平线分隔与全局极值严格分离组织成完整
课堂。Lesson 的提示阶梯和迁移检查也切中要害。

但是 Coach 明知原题已经丢失，仍说“原题丢了不碍事”，随后凭记忆重构并把它称为原题；
没有发 Scout、没有读取目标卡、所有 problem Block 的 `Uses` 都为空。内容上接近正确答案，
证据上却没有完成原题恢复，所以“深核验与教学理解”只能记 PARTIAL。

### C4

公开讨论追问到了两个真正的卡点：特殊偏移为何这样取，以及函数值符号如何反译成零点横
坐标顺序。确认后也确实调用了 Scout，但槽位名称和 brief 明确是 `check-card`：目标是寻找
一张十分钟迁移题，而不是找回学生描述的三问原题。Scout 返回的候选作为短检查是合理的，
却与隐藏目标不是同一张卡。

主 Lesson 仍要求学生“把手边原题带来并抄完整题面”。Teacher Control 只给出一般性的
“选点、判号、用单调性定位”框架，甚至把锚点理解成极值点处的函数值；它没有抓住原题中
特殊偏移使一端落到已知边界零点、另一端落到待比较位置的机制。因此辅助练习可用，主问题
仍未备出来。

## 检索链路

| 指标 | 结果 |
|---|---:|
| 为原题恢复建立的 brief | 0 / 4 |
| 为原题恢复启动的 Scout | 0 / 4 |
| 隐藏目标进入 Scout candidates | 0 / 4 |
| 父 Coach 完整读取隐藏目标 | 0 / 4 |
| 原题 problem Block 精确 `Uses` | 0 / 4 |
| 其他用途 Scout | 1 次，C4 课末短检查 |

C4 的短检查 Scout 保持了浅召回边界，没有打开正式题卡、答案或评分细则；它读取词表、
别名和 sidecar 后返回一个候选。但 brief 使用了非冻结规范词，Scout 又列出了 `graph/`
目录并进行了三次逐步放宽式 grep，偏离“一次 anchor grep、行内核对、首个合格即停”的
亮线。该 child 共耗时约 3 分 11 秒、7 次工具调用和 22,222 reasoning tokens。它证明
sidecar 仍能给出可用候选，也证明真实 brief 一旦不规范，Scout 仍会重新进入长推理。

## 等待与模型负担

| 情境 | 确认到最终回复 | 首次 Lesson 写入 | 实际 Scout | 准备轮 reasoning | 准备轮工具 |
|---|---:|---:|---:|---:|---:|
| C1 | 3 分 04 秒 | 2 分 50 秒 | 无 | 17,907 | 19 |
| C2 | 3 分 39 秒 | 3 分 25 秒 | 无 | 21,153 | 15 |
| C3 | 2 分 28 秒 | 2 分 16 秒 | 无 | 13,558 | 10 |
| C4 | 6 分 20 秒 | 6 分 06 秒 | 3 分 11 秒 | 父 16,471 + 子 22,222 | 父 18 + 子 7 |

四组确认后的平均等待约 3 分 53 秒，中位数约 3 分 22 秒；4 / 4 超过两分钟，3 / 4
超过三分钟。没有 Scout 的前三组平均也要约 3 分 04 秒，说明性能问题不能再只归因于
subagent：父 Coach 在少量 `find/read` 之后仍会花一到两分钟私下推演整份 Lesson。

C4 从确认到真正启动检索 child 已过约 84 秒；child 返回后到 Lesson 写入又过约 90 秒。
因此即使把 Scout 单独压回 Phase 1 的几十秒，总等待仍不会自动变得适合学生。

四个 Session 都在关键节点发过可见进展，C4 的三分钟 child 期间也持续产生
`material-search` 投影；这比完全静默好，但部分文本直接播报“模板、槽位、Scout、
child-first、文件链接”等内部术语。它既没有给学生可参与的小任务，也没有显著缩短等待，
只能算部分改善。

## 根因定位

1. **缺失原题没有结构触发。** `prepare-approved-lesson` 只区分“已知准确路径直接读”和
   “需要探索比较时发 Scout”，没有说明学生口述的残缺原题属于后者。模型便把重建题面当成
   已知材料。
2. **素材槽位优先级倒置。** 一节课承诺“原题 + 短检查”时，真正缺失的是原题；C4 却只为
   可选的短检查建槽，主载体继续依赖学生以后带来。
3. **父级兜底仍然可发生。** 未进入 `material-preparation.md` 时，父 Coach 不受其中“不要
   批量列目录、不要父级兜底搜索”的亮线约束。C1 枚举了完整卡目录，C2 使用 `find`，C3
   直接生成题目。
4. **真实 brief 未稳定使用冻结词。** C4 brief 的三个建议字段都需要 Scout 再归一化，导致
   额外读取、搜索和高推理长尾。
5. **父 Coach 本身仍有长推理。** 三个无 Scout 场景已经足以证明，检索优化不是总响应时间
   的唯一杠杆。

## 建议的下一轮最小修复

不需要把系统改造成只支持正规题卡的结构化查询工具。先补一条上游语义即可：

- 若已批准课堂把“学生过去卡住的原题”作为主载体，而当前 Plan 中没有可访问的精确题面或
  资产路径，就把它视为必需的 `original-anchor` 材料槽位；残缺记忆只能进入 brief，不能
  被静默升级为“原题已知”。
- 原题槽位先于迁移题和短检查；命中后由父 Coach 完整核验并写入该 problem Block 的
  `Uses`。找不到时应如实把课改称“同结构重建题”，或回到对话讨论，不能宣称找回原题。
- brief 中不确定的规范字段宁可省略并保留短题面词，也不要发明近义标签；Scout 仍保留自由
  文本和非题卡 fallback。
- 单独收紧父 Coach 的备课亮线：材料与课堂结构确定后立即物化，不再为了“更完整”追加目录
  枚举、来源页追逐或长时间内部最优化。

修复后应重跑同四个情境。首要验收不是措辞，而是 `original-anchor` 是否 4 / 4 触发、目标
是否进入 candidates、父 Coach 是否完整核验、主 problem Block 是否引用目标，以及确认后
等待是否回落到学生可接受范围。

## 结论边界

四个压力情境足以否定“当前真实 Coach 链已稳定接上 Phase 1 召回能力”，但不足以估计长期
成功率。它也没有测试 Tutor 实际上课后的学习效果。C3 说明模型在题面线索足够时可以独立
形成高质量数学教学设计；本轮要修的是让这种能力建立在可追溯原题证据上，并以更短、更可
预期的路径完成。
