# StudyForge 真实学生体验总审计

**日期：** 2026-08-12
**实现基线：** `0163fd8`
**用途：** 收束多轮学生视角审计，确定真实学生内测前的发布优先级
**性质：** 角色扮演用于发现问题，不作为问题已经发生的证明

## 一、结论

StudyForge 已经能完成自由学习、正式课程、学习资产、对象记忆、语义关系、日历、专注和
资产复习闭环。当前主要风险不再是“有没有这些功能”，而是学生能否：

1. 不懂电脑也能第一次进入；
2. 当下立刻获得一次真实的学习收益；
3. 第二次回来时看见系统确实承接了上一次；
4. 资产和复习逐渐增长后，仍能找得到、读得动、还得起；
5. 在不同学科、多个学习集和现实时间中继续使用，而不被错误画像或系统压力绑住。

多轮审计的边际收益已经明显下降。后续不再通过不断增加学生角色扩写需求，而应围绕一个
最小学生价值闭环实施、观察真实学生并修正。

## 二、证据等级

| 等级 | 含义 | 本文怎样使用 |
| --- | --- | --- |
| A | 真实 DMG、真实学生反馈或可复现运行记录 | 可以直接进入缺陷或验收 |
| B | 已与当前代码、Skill、schema 或页面逐项核对 | 可以进入设计，但仍需真实体验验证优先级 |
| C | 角色扮演、专家推演或产品假设 | 只用于提出问题，不证明频率、严重性或学生偏好 |

“多个角色都提到”只能提高调查优先级，不能把 C 级证据自动升级为 A 级。尤其是深夜劝睡、
家长报告、对抗模式、文件夹和移动端等建议，不能仅凭角色故事直接进入实现。

## 三、学生凭什么使用

### 3.1 不是只靠三个月后的纵向优势

“老师会随着时间认识学生”是 StudyForge 的长期价值，但不能接受“第一天横评必输、三个月
后纵评必赢”。学生若第一次没有获得真实收益，不会把三个月交给系统。

学生要在三个时间尺度分别得到答案：

| 时刻 | 学生的问题 | StudyForge 必须给出的真实价值 |
| --- | --- | --- |
| 现在 | 为什么不直接问普通聊天模型？ | 帮我把眼前问题真正想明白，并让我自己完成一步 |
| 下次 | 为什么还要回来？ | 不用重新介绍，从上次真正停下的地方继续 |
| 长期 | 为什么不用完就丢？ | 对话长成可读、可改、可复习的资产；未来教学使用可检查的学习证据 |

真正的差异不只是“记得你”。普通聊天产品也能记住偏好。StudyForge 更具体的承诺是：它能
记得学生在哪一步卡住、得到过什么帮助、哪些只是提示后完成、哪些仍未独立检验；这些依据
学生本人也能查看和纠正。

### 3.2 学生语言

建议的核心表达是：

> 不只告诉你答案，而是和你一起确认真正卡在哪一步，再让你自己走通一次。下次回来，
> 从这次之后继续。

“考场里只有你自己”适合作为高中场景的传播内容，但不作为整个产品的终局定义。更稳定的
终点是：**老师不在场时，学生也能独立理解和解决问题。**

不使用以下过度承诺：

- “唯一一个会随时间变强的学习软件”；
- “这里的老师不给答案”；
- “用了三个月一定提分”；
- “老师完整认识你”；
- “家长可以通过系统确认孩子学会了”。

## 四、已经核实的承重缺口

### 4.1 P0：阻碍首次采用、日常回访或系统信任

#### P0-1 首日教学深度没有成为自由学习的稳定能力

Roadmap 已有成熟的现场短诊断探针，Lesson 也有概念边界修复、主张挑战和独立迁移检查；
但学生第一晚实际进入的自由学习只有发散、重组、对照、驳斥与检索方法，没有一条定位型
方法。遇到真实错题、互相矛盾的解释或说不清的困惑时，教师能否找到决定性卡点完全依赖
模型临场发挥。

首日不能等待长期记忆产生后才体现差异。自由学习需要按证据选择正确教学动作：简单事实
直接回答；明确讲解请求深入解释并归还一个小动作；存在两种以上会导向不同教法的合理解释、
且现有证据不足时，才用一个短探针定位；强学生的有效路线则用核验、攻击与比较认真对待。
短诊断是“假设—区分—校正”，不是给学生贴标签，也不是每次对话的固定流程。

诊断技巧应抽成共享的低层方法，由 Free Learning、Lesson 和 Roadmap 在各自决策尺度上按需
使用；不能把决定长期 Plan 的 Roadmap 流程原样搬进自由学习。首晚也不强制生成题卡、对象
记忆或预约：这些仍只在各自条件成立时独立发生。

#### P0-2 第一次设置仍面向懂模型的人

普通学生不应先理解 Provider、主模型、Scout、思考强度和 TTS。默认路径应只有授权与开始；
完整模型配置留在高级设置。该问题直接决定非技术学生能否完成第一次进入。

#### P0-3 首页没有“学生本人的今天”

当前 `/api/home` 只读取当前学习集；Calendar 已能投影多个已知学习集的约定和复习候选。正确
形态是应用级“我的今天”：聚合今天的约定、到期复习、可继续的活动和当前专注；点击跨集项
时再切换学习集。它不得合并各学习集的对象记忆或制造跨集学生画像。

#### P0-4 学生资产没有统一搜索

知识图谱页已有标签和资产搜索，但学习资料页没有。学生不应先理解图谱才能找一张卡。首版
只需要本地关键词与标签过滤，覆盖标题、可见正文和标签；不引入语义排名、用户画像或推荐流。

#### P0-5 保存资产会自动制造复习债务

新 Note 和新题卡保存时自动追加 `enrolled` 事件，把“存档备查”和“以后考我”合成一个事实。
保存只应创建资产；进入复习轨道必须来自学生明确表达或资产详情页的主动操作。不得继续使用
隐藏默认入队再让学生退出。

#### P0-6 逾期复习被投影成一次性债务

所有逾期项都归到今天，日历面板还默认全部勾选。保留每项真实到期事实，但主行动默认只选
一个小批次，例如确定性顺序中的前五项，并明确其余仍在且不会因这次没选而被判失败。学生
可以展开并主动增加，不修改历史复习事件或伪造新的到期日。

#### P0-7 可及性缺少最小承接

当前视觉 token 最小文字为 11px、标签为 12px，且没有全局字号选择。近期至少应提供应用级
“标准 / 大字”阅读比例，保证放大后主要桌面布局仍可用，并复核低对比文字、键盘焦点和减少
动画。偏好属于应用设置，不属于任何学习集或学生认知模型。

#### P0-8 赴约打开后的第一步仍不够清楚

“打开约定”不等于学习已经发生，但学生也不应面对空白页面。Runtime 已拥有约定标题、计划
时长、目的和打开时间；教师可以用这些既有事实简短接住学生，再等待学生决定从哪里开始。
不得把打开动作记录成完成、复习或掌握。

#### P0-9 本地与模型服务商的边界需要用学生语言说明

学习集、资产、记忆和 Session 文件默认保存在本机，不等于学习内容从不离开电脑。学生向老师
发消息时，本轮消息和完成回答所需的相关上下文会发送给学生选择的模型服务商。首次设置与
帮助页必须准确说明这两层边界，不使用“只有你和本地老师能看到”之类错误承诺，也不把完整
技术隐私政策塞进第一次进入。

### 4.2 P1：决定一周后是否真正形成个人学习环境

#### P1-1 Material 是检索切片，不是阅读器

当前 Material 页面主要展示抽取文本，并把 `page-0062`、`lines-20-80` 等 canonical locator
暴露给学生。原始文件是人类阅读面；locator 是模型引用证据的投影。学生应阅读原 PDF、图片
或连续文本，通过翻页、目录和选区移动；系统在“问老师”或生成资产时静默绑定当前页或选区。

#### P1-2 资产组织能力停留在三个种类架

先完成统一搜索、标签过滤、来源可读和详情页邻居，再决定是否需要专题收藏。专题、置顶、
最近阅读和文件夹只要能跨重启保留，就都是新的持久事实，不得称为“纯界面”。首版不建立
Topic 本体、层级目录或“弱项夹”自动判断。

#### P1-3 学生看不见资产版本流变

Note 和新题卡的历史 revision 已存在，但学生只看到最新版。先提供按时间排列的历史只读查看，
明确“这是当时保存的版本”；不急于做合并、恢复、分支或复杂 diff。

#### P1-4 笔记编辑与长文阅读仍然粗糙

提供 Markdown 编辑 / 预览切换；阅读时根据标题生成当前文档目录与锚点。图片正文先通过现有
Material 来源关联，不立即扩展 Note block schema。真正需要正文内嵌图时再单独设计附件所有权、
revision 与离线读取。

Note 的打印 / 另存 PDF 使用面向当前资产的打印样式，不套用 Lesson 讲义的 Student View、
Block 选择或课程出版语义。

#### P1-5 关系图没有进入资产使用现场

在资产详情页投影最多三条可解释的相关内容，说明“共享核心标签”“共享相关标签”或“来源
关联”，允许打开；不在详情页重建整张图，不把共同出现说成先修、相似或掌握。

#### P1-6 标签底层可写，学生入口缺失

现有 semantic tag sidecar 已有 revision 和服务端写入接口。学生可以编辑核心与相关标签；
输入时优先提示现有词，减少无意分叉。首版不做自动同义词合并，也不静默改写其他资产标签。

#### P1-7 学科教学核心错误地固定为数学

自由学习和课程 Session 都无条件装载数学教学内核。先提取真正通用的教学核心：先看学生
表现、最小帮助、归还独立动作、诚实记录与学生决策权；学科气质由学习集指南和按需 Skill
承担。未完成前，不宣传语文、历史等学科已得到同等教学支持。

#### P1-8 学习足迹还不能支持诚实回望

足迹当前缺少复习、专注和赴约等高频事实。先补全事实投影，再提供学生主动开启的“回顾最近
学习”。回望可以叙述做过什么、理解怎样变化、哪些仍未检验，并链接证据；它不能成为第二份
掌握度档案，也不默认面向家长。

普通自由对话中若围绕已绑定资产发生了未被答案或提示污染的首次提取，也应具备记录复习结果
的资格。资格来自行为证据与资产绑定，不来自 Session 是否预先标为 `review`；没有完成提取、
资产未绑定或已经先看答案时不记录。review intent 只负责预装复习简报，不垄断事实写入资格。

#### P1-9 高阶学习能力存在但不可发现

论文查找、反例攻击、结构比较和头脑风暴已经存在于 Skill 或工具中。先在自由学习空状态、
帮助或输入区给少量自然语言示例，例如“帮我找反例”“尽量挑出这段证明的漏洞”“看看有
没有相关研究”。不创建持久“攻击模式”或把普通问答拉成长流程。

#### P1-10 老师只能被动等待学生提出下次时间

当一次学习自然收住且存在清楚的后续动作时，老师最多提议一次“要不要约个时间继续”；无
清楚后续、学生忽略或拒绝时停止。约定仍需公开完整内容和学生确认。阿夏只投影已存在的日历
或专注提醒，不能自行判断学生“有题没做完”。

### 4.3 P2：扩展使用边界，但不阻塞当前桌面内测

#### P2-1 考试与重要日期语境

考试不是学习预约。未来可以建立应用级重要日期事实：日期、名称、学生描述的范围和关联学习
集。首页与教师可读取并提出建议，但 Runtime 不自动改变复习阶梯、倒排课程或判断优先级。

#### P2-2 批量资料导入与书籍蒸馏

支持一次选择多份文件、显示逐项进度和失败项；资料的阅读、索引和蒸馏应在 Material 阅读器
边界稳定后继续，不把批量上传误写成已经理解或已经建立知识关系。

#### P2-3 音频材料

音频需要原始播放、时间段 locator 和可选转写三件事，不是增加 `audio/mpeg` 白名单即可。
在语言学习真实需求明确后，与 Material 阅读器作为新的媒体适配器设计。

#### P2-4 legacy 题卡的个人延伸

默认允许从旧题卡创建与其关联的个人 Note。只有学生确实要修改题干或答案时，才派生一张
可编辑题卡并保留原始来源；不批量“认领”或覆盖 legacy canonical 内容。

#### P2-5 移动与离线形态

本地自助翻卡已经具备有价值的离线边界；老师依赖模型网络。移动端对住宿生、艺考生和碎片
时间学生很重要，但属于独立产品形态，不阻塞本轮 macOS 桌面真实内测。

## 五、明确不做或暂缓

1. 不因角色扮演中的深夜故事加入自动劝睡；普通 Session 当前也没有持续权威时间。
2. 不强迫第一次对话生成对象记忆、课末总结、资产或预约来展示产品价值。
3. 不自动向家长生成成绩、能力结论或监控报告。
4. 不根据考试日期让 Runtime 自动重排复习阶梯或课程。
5. 不建立跨学习集统一学生模型；全局首页只聚合可投影的日程和入口。
6. 不以文件夹、Topic、弱项或置顶把新的持久事实伪装成纯界面。
7. 不增加全局对抗模式；高强度质疑仍是按需学习方法。
8. 不让桌宠独立读取认知记忆、制造提醒或支配学习流程。
9. 不把所有 legacy 资产复制成另一份 canonical 内容。
10. 不继续通过更多模拟角色扩写发布范围；下一轮证据来自真实学生使用。

## 六、发布优先顺序

### 第一批：学生能够进入、回来并信任系统

1. 首日自适应教学、共享短诊断方法与首击真实模型验收；
2. 推荐设置的一键路径；
3. 应用级“我的今天”；
4. 学习资料统一搜索；
5. 保存与加入复习彻底分开；
6. 复习积压默认小批次；
7. 标准 / 大字与关键对比度；
8. 赴约后的自然接话；
9. 首次设置和帮助中的准确数据边界。

### 第二批：让长期价值真正可见

1. Material 人类阅读器；
2. 资产历史版本、预览、目录和详情页邻居；
3. 标签学生编辑；
4. 足迹补全与按需学习回望；
5. 通用教学核心；
6. 高阶能力示例与老师一次性续约提议；
7. 阿夏投影已有提醒。

### 第三批：扩大资料和现实时间边界

1. 重要日期语境；
2. 批量导入与资料蒸馏；
3. 音频 Material；
4. legacy 资产的个人派生；
5. 图片笔记与移动端另立设计。

批次是产品风险顺序，不是一次实施计划。每个独立子系统仍需单独设计、实现和真实验收。

## 七、验收证据

下一轮不再以“模拟学生没有指出问题”为通过。需要三类证据：

1. **自动回归：** 事实所有权、revision、来源、复习事件和跨集路由不被破坏；
2. **真实模型：** 普通学生语言下，教师首击不越权、不强迫产物、能准确续接；
3. **真实学生：** 观察首次进入、第一次收益、第二次回访、资产查找和复习回归；记录学生
   实际停顿与退出，不教学生该提出什么高级要求。

是否改善学习效果仍需真实长期数据；完成界面和流程只能证明可用，不能证明提分或掌握。
