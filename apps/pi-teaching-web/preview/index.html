前端预览草稿

这是一组可以直接点开看的静态视觉稿，回应三个感受：视觉质感、学习动线、进度可见性。六个页面，全部锚定真实学习集内容（导数 · 定义域完整性 Plan），零构建、无应用代码改动。已定案两项：品牌章 B · 限量朱砂（2026-08-04）；全站字体统一霞鹜文楷（2026-08-04，对照记录见字体页）。建议顺序：先看设计系统立基调，再按「首页 → Coach → 课堂 → 回放」走一遍学习动线。

字体与公式渲染走 CDN，需要网络；无网络时回退系统楷体/黑体、公式显示 LaTeX 源码，布局仍然成立。
