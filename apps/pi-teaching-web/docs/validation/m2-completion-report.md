验收中发现导数学习集的自由学习页面曾为显示一条带入内容而解析 519 张题卡，打开需约
25–30 秒。现已改为只读取本 Session 显式选择的资产；最终 DMG 同一带 Note 线程实测
约 1.3 秒打开。随后又发现精确读取一张题卡仍会在服务端扫描完整题库，旧路径约需 40 秒；
现在优先通过受管的 `asset-recall.tsv` 索引定位文件，本地 519 卡样本约 54 ms，索引缺失或
失效时仍兼容原扫描路径。最终 DMG 中携带三张题卡的真实复习线程重载约 1.5 秒，三张均
正确显示。资料库和知识图谱页仍只在确实需要全库时读取全库。
