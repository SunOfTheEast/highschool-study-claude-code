# StudyForge M2 完成验收协议

日期：2026-08-12
范围：学习方法、对话内资产提案、专注周期、统一日历、资产级间隔复习

## 1. 验收边界

M2 的结论由三类证据共同构成：确定性自动化、真实模型首次行为、真实 macOS 桌面操作。
单元测试不能代替教学行为，真实模型成功一次也不能代替 Runtime 不变量。

所有会改变学习内容的验收只在公开示例学习集的临时副本上运行。不得使用真实学生的私有
学习集，不提交 OAuth、API Key、原始 Session JSONL、完整转录或隐藏推理。报告只保留学生
可见回复摘要、公开工具/活动名、文件变动路径、时延和人工判定。

发布模型固定为：

- 教师：`openai-codex/gpt-5.6-sol`，thinking `high`；
- Scout：`openai-codex/gpt-5.6-terra`，thinking `high`。

## 2. 证据记录器

先做连通性与场景清单预检：

```bash
bun run validate:m2 -- \
  --root /tmp/学习集副本 \
  --api-base http://127.0.0.1:65127
```

记录一个真实模型轮次：

```bash
bun run validate:m2 -- \
  --root /tmp/学习集副本 \
  --api-base http://127.0.0.1:65127 \
  --scenario question-formation \
  --session-key free:SESSION_ID \
  --message '学生的自然输入' \
  --label question-first-hit \
  --output /tmp/studyforge-m2-validation-run
```

桌面 Runtime 需要令牌时，只传环境变量名：

```bash
export STUDYFORGE_VALIDATION_TOKEN='本轮临时令牌'
bun run validate:m2 -- ... --token-env STUDYFORGE_VALIDATION_TOKEN
```

记录器只连接显式的 `127.0.0.1` 端口；它在轮次前后哈希学习集，保存变动路径、首个学生
可见事件时延、总时延、公开投影中的工具/活动名与学生可见历史，不读取或导出模型推理。

## 3. 九个场景

| 场景 | 入口 | 核心 Gate |
| --- | --- | --- |
| 模糊问题形成 | Free | 先帮学生辨清问题；普通对话不强迫进入固定方法或保存 |
| 四路头脑风暴 | Free | 区分真实活动、库存资产、模型常识、论文；论文需明确同意 |
| Note 提案 | Free | 提案不写；纠正后自然确认保存最新草稿 |
| 自编题卡 | Plan | 提案不露答案；确认后才保存 |
| 专注周期 | 桌面 | 开始静默；结束只报告真实用时并询问进展 |
| 日历 | 桌面 | 精确打开 Plan/Free；跨学习集不串线；约定不被复习状态吞掉 |
| 直接复习 | 资产页 | Note 先回忆；题卡重新隐藏答案并绑定本轮作答 |
| 批量复习 | Free | 只记录真正触及的资产，未触及项保持到期 |
| Lesson 吸收复习 | Lesson | Prepare 只读有界；Tutor 只写 Uses 且在冷提取之后 |

每个场景的具体自然输入与完整 Gate 以
`scripts/m2-validation/scenarios.ts` 为唯一机器可读清单。输入模拟普通学生，不向模型复述
工具名或答案。

## 4. 判定规则

真实模型看“首击守住率”：若必须由学生提醒模型停止越权、停止泄露答案、先做冷提取或先
取得论文许可，则该 Gate 失败。措辞不要求逐字命中，只判断学生可见结果和持久化事实。

必须同时满足：

1. 普通对话不强制调用学习方法、资产保存、日历或复习写入；
2. `paper_research` 在许可前不发生，失败后仍能继续讨论；
3. proposal 与 save 分离，自然确认保存最新公开版本；
4. 专注、日历、复习日志均记录真实事件，不生成掌握或能力结论；
5. 同日、revision、答案门、Uses 和未触及条目边界由持久化结果证明；
6. 没有自动对象记忆、课程状态或资产正文双写；
7. 等待期间可见进展不暴露内部路径、参数、原始错误或子进程细节。

## 5. 桌面与 DMG 走查

在真实 DMG 中依次检查：单实例、自由学习、资产提案、专注开始/暂停/结束、日历重启持久化、
通知与点击、跨学习集复习候选、Note 翻卡、题卡答案重新隐藏、批量复习、提前复习后刷新、
索引删除后重建、失效资产提示，以及既有 Peer/Live2D 路径。

Computer Use 负责点击、输入、读取可见结果和截图；文件与 API 检查负责确认不可见的持久化
边界。若环境权限阻止系统通知或 DMG 挂载，报告为环境阻塞；若应用自身不能恢复，则属于
产品缺陷，不得标绿。
