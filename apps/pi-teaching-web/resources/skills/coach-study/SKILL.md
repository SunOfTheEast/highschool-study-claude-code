# Coach Study

1. Read `ROADMAP.md`, the current Plan, both confirmed profiles and source-linked earlier Lesson summaries. Read `memory/planner-attention.md` only during preparation.
2. Before card search, collect every card path from earlier Lesson aliases in this Plan as `usedCardPaths`. Search separately for each problem-role slot; every `card_search` hit already includes its active Trace. For unseen assessment, reject candidates in `usedCardPaths` or with non-empty `traceHistory`. A same-card retry is practice, not unseen transfer. If no fresh authentic card exists, say the slot is unavailable instead of fabricating validation.
3. Before changing Plan progress or choosing the next target, build a temporary evidence matrix: `criterion | lesson/block | cardPath | problem category | first exposure | assessment | current support | prior support | qualifies`. This table is reasoning context, not a new file or schema.
4. Apply the original Plan Test literally: consecutive means adjacent evidence-bearing attempts; never skip supported, failed, or conflicting attempts. The category rule is that method structure is not a problem category. A correct answer may inform discussion, but missing active Trace blocks attainment. Do not pass a criterion until every required matrix row qualifies.
5. Agree on the next Lesson direction with the student. Derive its problem-role slots before search and use 2–4 distinct unseen cards only when the Plan Test actually requires consecutive or cross-problem evidence; one long authentic problem is valid for explanation but cannot prove a multi-problem criterion.
6. Write a flexible sequence of dialogue, problem, material and reflection Blocks with Node State, Student View, Teacher Control and real aliases. Show only a no-spoiler outline. When recognizing a structure or method is the target, say only “new-structure transfer check” in Student View; keep the method, comparison object and direction in Teacher Control.
7. A `prepared` Lesson may be revised in place. Never overwrite an `active`, `paused`, `closed` or `abandoned` Lesson. After a Lesson closes, read its Lesson Summary and source-linked active Trace before discussing the next step. Long-term profile changes happen only after Plan completion and student confirmation.
