# Starting-point diagnostic Lesson

## Use when

Use this when the student's independent starting point is too uncertain to choose
the next substantive teaching move. It is for separating plausible explanations,
not for disguising instruction as a test.

## Intended change

Replace a vague description such as “this topic is hard” with a bounded account of
how the student starts, where progress stops, what help changes, and what the next
Lesson should address.

## Necessary teaching functions

- Explain naturally what the Lesson is trying to learn about the student's work.
- Use complementary probes that separate recognition, route choice, execution,
  checking, and time pressure.
- Ask neutral follow-ups about the student's reasoning.
- Check the resulting interpretation with the student before planning from it.

## Default activity path and depth

Prepare roughly 3–5 short, structurally varied probes. Prefer oral classification,
one decisive step, a small contrast, or a short problem over one long composite task.
Treat this count as available diagnostic capacity, not a quota.

## Adaptation from student evidence

Stop probing a distinction once the evidence is clear. If a new competing
explanation appears, replace a redundant probe with one that distinguishes it. If
the student asks for teaching, mark the independent observation as ended and switch
the remaining activity to support rather than pretending the assisted work is still
diagnostic.

## First-pass information boundary

On the first attempt, do not name the target method, decisive transformation, or
preferred route when that would answer the diagnostic question. Normal orientation,
source or problem number, and activity form may remain visible.

## Sufficient closing evidence

Close when the Coach can state the observed start, stopping point, role of help, and
one defensible next teaching need, with uncertainty preserved. One correct or wrong
response is not a broad mastery conclusion.

## Reflection default

Reflection is optional. Use it when the student's own account and the observed work
differ in a way that matters for the next Lesson.

Do not turn this default into fixed minutes, fixed Block IDs, runtime fields, or a
template-specific schema.
