# 课后复盘与下一课共备

只在"最新 Lesson 已 closed，且没有 prepared/active 的下一课"时读取。

顺序只有一条亮线。在上一步完成前不进入下一步：未听学生前不公开教师结论，未
讨论出下一步需要前不生成草案，未按统一批准门确认前不搜索材料、不读取模板、
不创建 Lesson。

## 1. 读证据

读取当前 Plan 与刚关闭的已链接 Lesson；只有当前判断需要时才查看相关 Block 与
Classroom Log。此时形成初步判断与待澄清问题，但不生成下一课草案；复盘判断在与
学生讨论收敛前不写回 Plan。

## 2. 先听学生

先给学生一个不受教师结论锚定的表达机会，例如自然询问上节课自己感觉哪里真的顺了、
哪里还不踏实。学生愿意详细说时就继续听；学生说不清、只说"还行"或希望教师直接
判断时，不反复逼问，进入下一步。

## 3. 公开判断

综合课堂事实与学生体验，公开说明并区分：

- 课堂中实际发生的作答、停止点和帮助；
- 学生现在报告的理解感、困难、兴趣和负担；
- 教师基于两者作出的暂定解释；
- 还没有被独立表现证明的部分。

两类证据冲突时保留冲突，把它转化为下一课需要检验的问题，不改写原始课堂事实。
同时说明对初始弧线的调整判断：按原方向继续、加快、放慢、调整阶段内顺序或负担，
或把超出本 Plan 的路线问题交回 Roadmap。

## 4. 再生成草案

师生讨论出下一步真正需要解决的问题后，教师才生成第一版下一课草案，说明为什么
这样安排及主要取舍。学生修订或拒绝后，教师整合为完整但不泄题的公开 Lesson 提案：
本课为何现在进行、目标、与 Plan 的关系、大致学习过程、预期参与方式、课末完成
标志，以及会实质影响学生选择的负担或取舍。

学生否定的是本课时，在阶段内重做草案；否定整个阶段时，停止创建 Lesson 并返回
Roadmap。

提案经学生明确确认后，按根 Skill 的统一批准门写入 `Next Lesson Arrangement` 并
调用 `prepare-approved-lesson`，一次只物化当前下一节 Lesson。讨论收敛后，可以把
共同确认的真实进展和边界更新到 Plan 的 Current Position。初始弧线只是可调整假设，
不是学生对未来 Lesson 的预先批准。
