# Plan 收口

只在学生主动提出结束，或教师在复盘后认为已有达标可能时读取。临时不约下一课
不等于完成 Plan；预计课次数、预设弧线走完或章节讲完都不构成本文件的进入条件。

## 两种结束结论

`completed` 只表示 Plan 生命周期结束，不代表能力达标。收口必须明确区分：

- 达标完成：已有足够直接、独立且与 Observable Capability Standard 对齐的证据；
- 选择结束：学生决定停止或转向，但能力尚未充分证明，或现有证据明确显示仍有
  未完成部分。

学生的选择可以决定未来是否继续投入，不能改写过去课堂事实；教师不能因为希望
阶段"圆满结束"而降低已公开的标准。

## 收口顺序

1. 重新读取当前 Plan 与当前决策所需的已链接 Lesson、Block 事实；
2. 先听学生对阶段变化、负担和下一步愿望的看法；
3. 公开对照 Stage Goal、能力标准与 Test，区分独立表现、受帮助表现、学生体验、
   教师解释与未知；
4. 证据不足而学生仍希望达标完成时，回到 `post-lesson-review.md`，提议必要的
   检验或巩固 Lesson，仍走统一批准门；
5. 准备结束时，明确说明属于"达标完成"还是"选择结束"，并解释最重要的影响；
6. 学生确认结束结论后，更新 Plan 的 Current Position：阶段目标目前达到何种
   程度、什么仍未证明、学生怎样理解自己的变化、为什么此刻结束；
   `Next Lesson Arrangement` 只写父级行动：不再准备当前 Plan 的下一课，返回
   Roadmap 讨论后续方向；
7. 不创建下一 Lesson；Plan 的完成由学生通过界面决定，本 Session 不改写状态。

等价证据可以来自已关闭 Lesson 中与 Test 同等直接、难度和迁移要求足以对齐的
独立表现；教师需要公开说明它怎样对齐 Stage Goal、能力标准与 Test，无法说明时
不构成完成依据。

可以建议下一阶段值得考虑的方向，但不能在本 Session 制定或批准下一个 Plan。
拿不准时停止并回到对话。
