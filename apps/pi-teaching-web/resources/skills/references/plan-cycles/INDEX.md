# Plan cycle archetypes

First fix the bounded stage problem, observable capability standard, and direct test.
Then choose one main cycle for the current planning problem and read only that file.

| Cycle | Use when |
|---|---|
| [`capability-construction.md`](capability-construction.md) | A concept, method, representation, or structural connection must first be formed. |
| [`strategy-strengthening.md`](strategy-strengthening.md) | Known methods need stability, discrimination, route choice, or transfer. |
| [`remediation.md`](remediation.md) | Original Lesson records show an important or recurring error that deserves a stage goal. |
| [`systematic-review.md`](systematic-review.md) | Review and reorganisation are the Plan's main progress objective. |
| [`diagnostic.md`](diagnostic.md) | Uncertainty is too high to prescribe the next substantive stage responsibly. |

Translate the chosen cycle into concrete, student-readable `Next Lesson Arrangement`
prose. Do not persist the template name or create future Lessons to mirror its phases.
The Plan and original Lesson records remain authoritative; this index is disposable
planning guidance.
