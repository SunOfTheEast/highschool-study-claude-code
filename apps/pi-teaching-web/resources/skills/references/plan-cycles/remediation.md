# Remediation cycle

## Use when

Use this when original Lesson records show an important, recurring, or transferable
error mechanism that merits a bounded stage goal.

## Stage problem

The system must first verify the problem, replace the mechanism that produces it,
and then show the repair independently on separate material before returning to the
Roadmap's main line.

## Minimum starting information

Read the original Block, including the student's actual attempt, help, correction,
and objection. Distinguish a stable mechanism from a slip, misread, bad asset, or
later Coach interpretation. Agree with the student on what is worth repairing.

## Default phase graph

```text
reread and verify the original problem
→ identify the mechanism
→ qualitatively different corrective experience
→ targeted practice
→ unseen parallel recheck
→ return to the main Roadmap line
```

## Evidence sought at each phase

- Verification: whether the claimed problem is present and consequential.
- Mechanism: what cue, representation, assumption, or habit caused the work.
- Corrective experience: whether a different representation changes understanding.
- Practice: whether the replacement can be used with fading support.
- Parallel recheck: whether the original mechanism is independently avoided elsewhere.

## Branches and loops

If the problem cannot be verified, shorten or end the cycle. If a small reminder
restores performance, recheck on new material rather than overteach. If core
understanding is absent, reinterpret the work as capability construction. If a
parallel task passes, return to the main line instead of drilling to fatigue.

## Sufficient completion boundary

The student can explain the corrected distinction and independently handle an unseen
parallel task, with the conclusion limited to the observed mechanism and scope.

## Common Lesson templates

Error remediation, deliberate practice, and capability assessment.

## Common misjudgment

Do not manufacture a durable weakness from one slip or “repair” it by repeating the
same explanation more slowly.

A phase may occupy zero, one, or several Lessons and may be skipped, repeated,
merged, or revisited. Do not encode fixed Lesson IDs, counts, minutes, mastery scores,
or runtime phase fields.
