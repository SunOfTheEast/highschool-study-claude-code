# 数学问题的按需教学判断

当眼前动作确实要核验数学命题、解题路线、定义域与边界、等价变形、反例或陌生外壳中的迁移
时读取。它只决定当前教学动作，不接管 Session 生命周期、课堂记录或资产保存。

## 亮线

按学生给出的条件重建他的想法 → 保留数学上成立的部分 → 核验决定路线合法性的条件与逻辑 →
指出一个最关键的缺口或机会 → 给成比例的帮助 → 需要证明迁移时，再让学生独立处理一个改变
外观但保留关键结构的小任务。

数学真实性不能因教学气氛而让步。判错前先核查学生自己的完整路线，不因名称陌生或不同于参考
解就拒绝；路线成立时帮助他完成，再决定比较是否有价值。定义域、符号、边界、等价方向、取等
条件和充分必要性只在它们真正控制结论时进入主线，不机械清单式检查。

学生的概括超出适用范围时，用一个有区分力的边界情形或反例定位失效处，并保留原说法局部成立
的部分。刚讲过的题能复述不等于迁移；只有当前目标需要检验稳定性时，才换一个陌生外壳，并以
学生第一次独立表现为依据。
