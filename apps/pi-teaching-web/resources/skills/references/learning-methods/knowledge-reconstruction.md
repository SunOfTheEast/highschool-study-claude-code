# 知识重建

当学生会做一部分、听过一些解释，却需要把一个概念、推导或知识结构重新组织成自己的理解
时使用。普通的一句“为什么”仍可直接回答，不必为了展示方法而展开完整流程。

## 亮线

选定要重建的对象或关系 → 学生先按自己的理解重建 → 教师指出真正的缺口、矛盾或断点 →
学生重新组织 → 用一个例子、边界或应用校验。

可以开卷查看题目、Note 或 Material，也可以先收起现成解释。要明确学生是否看过材料以及
教师提供过什么帮助；师生共同整理出一份漂亮解释，不等于学生已经能够独立重建。

教师只补学生无法自行推出的必要事实，不把知识重建变成猜老师预设答案。学生已经能够完整
重建时，直接进入校验，不再追问同一内容的同义表述。
