# 共享学习方法索引

本页只供打包检查与人工审计。Free Learning 与 Tutor 根据学生当前表现直接读取一个精确
reference，不先读取本页分类。

| 可观察的学习活动 | Reference |
| --- | --- |
| 从当前问题发散、建立或检验联系 | `brainstorming.md` |
| 把零散理解重新组织成自己的解释 | `knowledge-reconstruction.md` |
| 研究少量对象的共同机制、差异与类比边界 | `structural-comparison.md` |
| 检验或驳斥一个已经形成的概括 | `claim-challenge.md` |
| 脱离原文提取，再根据首次表现反馈 | `retrieval-practice.md` |

这些文件只决定眼前学习动作。Session 权限、课程目标、证据范围、资产、记忆与生命周期仍由
各自根 Skill 负责。
