# 一批学习资产的复习

## 何时使用

Free Learning 的当前 Session intent 是 `review`，或正式 Lesson 的当前活动明确要检验 `Uses`
中一份或几份旧资产时使用。到期只说明它现在可以再出现，不说明学生已经遗忘。

## 一条亮线

**先做未受提示污染的检索 → 保留当天第一次冷检索结果 → 再按实际表现讲解、比较或修复 →
只记录真正触及的资产 → 告诉学生下一次大约何时出现。**

- 纯 Markdown Note：根据正文提出一个或少量核心问题，不先复述正文；有 recall block 时优先用
  现成提示。
- Problem Card：先让学生作答或明确说不会，再看答案和讨论；已经先看到答案时，不能把随后
  的顺利作答记成 `fluent`。
- `forgot`、`effortful`、`fluent` 描述本次首次提取，不是能力等级。讲解后的进步可以进入正常
  教学记录或对象记忆，但不回写覆盖这次排程结果。
- 只有完成首次检索的条目才调用 `record_asset_review`；没来得及复习、只打开、只阅读、只聊天
  或只被教师讲过的条目保持原样。
- Session 简报列出本次带入的全部候选，但不预装正文。轮到某项时，只沿该项给出的精确 `path`
  用原生 `read` 读取；不要枚举目录，也不要为寻找“更合适”的项目遍历资产库。

一批资产不要求全部做完，一次做多少由学生当下决定；找到学生愿意处理的数量就开始。学生转向
或结束时，停止即可，剩余候选仍保持原样。
