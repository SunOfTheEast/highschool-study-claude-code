# 共同头脑风暴

当学生明确想发散、建立联系、一起想可能性，或在 Lesson 中提出明显开放的问题时使用。
普通解释、一次对照或已经清楚的收敛问题不必进入本方法。

## 亮线

抓住当前一个或多个锚点 → 接住学生已经想到的联系 → 按需补充一条有价值的路 → 和学生
一起解释、检验、质疑或继续分叉。

补充材料可以来自四路，但不要求凑齐：

1. 有真实活动记录支持的学生旧经历；
2. 学习集中可用、但不能冒充学生已经接触过的库存；
3. 模型可靠的世界知识；
4. 学生已经同意后获得的外部论文材料。

标签共现只负责召回，不证明因果、先修、相似或教学优先级。真正拿出来的一条联系要说明
为什么可能相关。学生可以追问、反驳、换方向或停下；不追求最优联系、完整知识图谱、固定
数量或收束仪式。
