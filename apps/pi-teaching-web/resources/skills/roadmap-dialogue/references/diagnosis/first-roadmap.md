# 初次 Roadmap 会面

只在"Plan Tree 为空且没有当前 Plan"时读取。

初次会面不是填写学习档案，也不是立即挑一个知识点开课。它是一段真实的初次接诊：
学生用自然语言描述愿望、困扰和最近经历；教师把这些材料解释为一条暂定的长期能力
方向、总体学法和下一个有边界的 Plan，再交还学生确认。Roadmap 同时回答两个问题：
学生希望较长周期后获得什么能力，以及准备采用怎样的总体学习方式获得它。

## 自然对话而非固定问卷

先根据 `LEARNING_GUIDE.md` 做足以让学生开口的短介绍，再听学生的自然诉求；不先
倾倒完整能力地图或假想课程目录。学生可以只说"我想学点高级技巧""导数题我经常没有
思路""我也不知道自己应该怎么学"；不能要求学生说出教育学术语。

教师内部逐渐形成四个判断：学生希望长期发生什么变化、哪些具体经历支持当前理解、
整体更适合怎样学、哪个首个 Plan 最值得尝试。这些不构成四道必问题，也不要求全部
确定。每轮最多处理一个真正会改变长期路线的问题，让学生的上一轮回答决定下一步。
学生说"你帮我安排"表示停止继续盘问，由教师承担提出方案的责任；它不是批准尚未
公开的 Roadmap 或 Plan。

停止追问不以填满字段为标准。满足以下条件即可提出方案：教师能够提出一条有理由、
可调整的长期路线，能够说明为什么先选当前 Plan，知道什么后续表现可能推翻判断，
并且学生已经能够理解并确认或修正。

## 现场短诊断

只有学生明显无法描述自己的问题、且决策性不确定性无法靠继续交谈区分时，才读取
`live-diagnostic-probes.md`，按其中的短探针协议进行；诊断目的达到后返回本文件的
判断与 Plan 提案，不顺势在 Roadmap Session 中上完一堂课。需要较多题、多轮复验、
正式课堂记录或跨 Session 观察时，停止现场探针，公开提议一个短诊断 Plan，并继续
遵守统一批准门。

## 公开方案与首个 Plan

讨论收敛后，采用"长期弧线公开、未来方向暂定、一次只批准并物化一个 Plan"的粒度。
公开方案需要让学生理解：教师目前怎样理解他的愿望和具体情况；这段长期学习希望产生
什么能力变化；总体准备怎样学；基于当前学习集与学生情况推导出的暂定能力方向；为什么
先做当前 Plan；哪些后续表现会改变路线、顺序或总体学法。

首个 Plan 从初次会面的真实诉求、总体学法、`LEARNING_GUIDE.md` 声明的学习集范围和
当前可支持的判断中推出；Roadmap 不为此浏览具体卡片或材料目录。
制定只走一条亮线：说明为什么现在值得做并区分证据、推断和未知 → 收敛一个有边界的
Stage Goal → 翻译为可观察的独立表现 → 设计直接对齐的 Test → 判断最关键的学习变化
→ 形成可调整的多课初始弧线 → 标出会改变路线的后续表现 → 给出教师建议与主要代价。
没有证据时保留假设，不能为了让 Plan 显得完整而发明学生的薄弱点。

未来阶段只作为 `ROADMAP.md` 正文中的暂定方向，不创建文件、不加入 Plan Tree。学生
明确确认或修正最终方案后，按根 Skill 的统一批准门写入 Roadmap 正文，并调用
`prepare-approved-plan` 一次只物化这一个 Plan。
