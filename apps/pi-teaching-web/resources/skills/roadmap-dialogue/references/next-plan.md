# 复诊与下一个 Plan

只在 Roadmap Plan Tree 中最新一个已链接 Plan 自身的 frontmatter 为 `completed` 时
读取。学生在 `prepared` 或 `active` Plan 中主动转向，或证据表明阶段目标可能选错时，
先回当前 Plan Session 完成结束讨论；本文件不为尚未完成的 Plan 预建后继。

## 回读与复诊

按一条披露亮线读取：

1. 先读刚完成的已链接 Plan 的阶段总结，包括 Current Position、Stage Goal、能力标准、
   Test 与结束理由；
2. 重新读取 `memory/INDEX.md`，查看与该 Plan 变化和当前学习前沿直接相关的路由；
3. 读取受影响的对象记忆，了解对象当前状态与流变边界；
4. 读取需要跨 Plan 校准的既有能力假设；
5. 读取会改变下阶段负担、节奏或互动的当前偏好；
6. 只有高影响判断或证据冲突无法由压缩记忆负责解决时，才沿精确链接读来源 Trace；
   Trace 仍不足时，才读同一已链接 Lesson 的相关 Classroom Log。

不得枚举目录发现“可能有关”的记录，不依赖复制摘要或 Handoff，不沿 Block `Uses` 读取
卡片或材料。Roadmap 消费逐课已经固化的结果，不重做逐课提取，也不把每节 Lesson 再
总结一次。

结合学生此刻的目标、时间和主观感受，公开说明：上一个阶段实际建立了什么、哪些仍需
支持；为什么当前最值得进入这个方向；还有哪些合理方向以及选择当前方向的主要代价；
什么新表现可能使这项建议需要改变。既有 Plan 是专业建议的证据，不是替学生自动决定
下一阶段的指令。

## 跨 Plan 能力校准

当新完成的 Plan 为已有跨对象模式提供了新的时间尺度证据时，继续维护同一个能力文件，
不要为 Coach 判断和 Roadmap 判断拆成两份。根据新证据强化、改写、削弱或撤回
`Current Hypothesis`，同时保留适用边界、反向证据与 Evolution Overview；在
`Calibration History` 追加这次跨 Plan 校准及其来源。不改写旧 Trace 或旧校准记录。

只有证据支持时才改变长期能力判断；Plan 完成、课次增加或模型想让画像更完整都不是
强化理由。学生在 Roadmap 中明确表达、改变或撤回需求时，按真实时间范围更新同一偏好
文件。最后局部更新当前前沿与受影响的 INDEX 路由。下一个 Plan 的检验、课程方向与
练习安排都是教学待办，写入 Roadmap / Plan，不进入 memory。

## Plan 的粒度

Plan 是有边界的中期能力周期，不按 Lesson 数量或知识点清单机械切分。检查三个关系：
这些 Lesson 是否共同服务一个连贯的 Stage Goal；各课证据是否进入同一个能力判断与
调整循环；完成这个循环后是否值得回到 Roadmap 重新选择方向。内容只是一次局部修复
时属于 Lesson；包含多个彼此独立的阶段目标、检验和循环时才拆成多个 Plan。

## 逆向制定

从阶段结束时希望看见的能力反推课程，而不是先凑 Lesson 清单：

1. 说明这个 Plan 为什么现在值得做，并区分证据、推断和未知；
2. 收敛一个有边界的 Stage Goal；
3. 把目标翻译成可观察的独立表现，并设计与之直接对齐的 Test；
4. 判断学生的当前位置与目标之间最关键的学习变化；
5. 选择合适的阶段推进方式，形成一条可调整的多课初始弧线（弧线不预先创建 Lesson）；
6. 标出会促使教师加快、放慢、补支架、改变顺序或返回 Roadmap 的证据；
7. 给出明确的专业建议、主要理由与代价，交给学生确认或修改；
8. 只有学生确认后，按根 Skill 的统一批准门把最终设计写入 `ROADMAP.md` 正文，并
   调用 `prepare-approved-plan` 一次只物化这一个 Plan。

Plan 周期原型可以帮助思考推进方式；需要时使用根 `roadmap-dialogue/SKILL.md` 中唯一的
“按需参考”入口，再只读一个匹配周期。本文件不另行计算或搜索共享 reference 路径。
周期是按需专业参考，不是要让学生选择的模板名，也不持久化为字段。

## 教师建议与学生决策权

不能把决策责任伪装成"尊重学生"，只给出一排中性选项：教师必须根据已有证据明确推荐
最值得做的 Plan，解释为什么现在做、会得到什么，以及暂时不选其他方向的影响。学生
保留路线和节奏的最终决定权。学生理解最重要的代价后仍选择另一条合理路线时，按学生
的选择重新形成方案；学生的选择可以改变未来学习安排，不能改写过去证据，也不能偷偷
降低已经公开的能力标准。学生的选择使原目标无法成立时，公开指出冲突并共同改写
Plan，而不是保留一个名不副实的测试。

## 动态课次

Lesson 数量取决于真实课堂中的独立表现、提示依赖、迁移速度和可用时间；制定时只能
估计工作量，不能承诺固定课次。学生关心时间投入时给出暂定范围并说明估算依据和可能
改变它的表现；否则优先讲清学习弧线，不为显得精确而编造课次。

## 物化边界

一次只物化当前一个 Plan；未来 Plan 只保留为 Roadmap 正文中的暂定方向，不预先创建
空文件。Lesson 到相应 Plan Session 逐节讨论、确认和准备。
