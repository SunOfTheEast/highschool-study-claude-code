# Capability-assessment Lesson

## Use when

Use this when the declared Plan capability standard must be checked independently,
especially near a completion decision.

## Intended change

Replace confidence or teaching-session fluency with bounded evidence about whether
the student can perform the actual standard without the support that created it.

## Necessary teaching functions

- Translate the Plan standard and test into representative unseen tasks.
- Keep independent attempts separate from later explanation or teaching.
- Observe starts, route decisions, execution, checking, and requested help.
- Report what was and was not demonstrated without upgrading the conclusion.

## Default activity path and depth

Use roughly 2–4 representative unseen tasks covering the declared boundary. Do not
teach between independent attempts when that teaching would change what later tasks
measure. The count is assessment capacity, not a quota.

## Adaptation from student evidence

A clarifying question may preserve independence when it adds no mathematical help.
Once method, transformation, or decisive direction is supplied, that attempt no
longer supports an independent claim; teach if useful, then use a separate new task
for any recheck.

## First-pass information boundary

Explain the capability being checked and the activity format, but do not reveal the
unseen task's target method, hidden contrast, answer, or expected failure mode.

## Sufficient closing evidence

Close when the agreed test has been honestly exercised enough to make a bounded
complete, continue, or replan recommendation. The student retains the completion
choice.

## Reflection default

Reflection is optional and comes after independent evidence. Use it to compare the
student's felt confidence with observed decisions, never to retroactively improve an
assessment result.

Do not turn this default into fixed minutes, fixed Block IDs, runtime fields, or a
template-specific schema.
