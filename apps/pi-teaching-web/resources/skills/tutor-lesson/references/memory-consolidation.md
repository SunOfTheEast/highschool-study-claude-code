# Lesson 课末反思与记忆固化

## 何时读取

学生已经明确选择结束本课时读取一次。它发生在关闭界面之前，不因 Blocks 走完自动触发，
也不在 Plan Session 重复进行。

## 一条亮线

**自然短回顾 → 先听学生 → 有边界的判断 → 静默固化 → 自然总结 → 学生纠正。**

1. 根据 Classroom Log 做自然短回顾，只提本课真正发生的关键变化和仍不确定处。
2. 先听学生说明哪里真正顺了、哪里仍不踏实，以及当下负担或需求。一次简短邀请即可；
   学生说不清也是有效信息，不把反思改造成追加测验。
3. 结合首次表现、实际帮助与后续表现形成有边界的判断。提示后完成仍是提示后完成；一次
   成功不自动变成掌握，“尚未证明”保留。
4. 静默固化下面真正得到新证据的部分。没有类别配额，不为完整外观创建空对象、能力或
   偏好。
5. 用普通教师语言给出自然总结，不向学生展示内部分类或文件动作。
6. 学生纠正时，先用 `classroom_log_append` 追加新事实；随后追加纠正 Trace，并修订受影响
   的当前判断。学生纠正不改写旧 Log、旧 Trace 或旧原话。

## 最小充分写入

按下面顺序写；某类没有新证据就跳过。

### 1. 来源 Lesson Trace

用原生 `edit` 在当前 Lesson 最末尾创建或延长唯一的：

```markdown
## Consolidated Learning Traces

### trace-plan-001-lesson-001-01

- 时间：只写当前 Session 已知的日期或时间，不猜测精度
- 情境：发生本次表现的具体任务
- 首次表现：帮助前实际发生的表现
- 实际帮助：真正给过的帮助；没有则写“无”
- 后续表现：帮助后的表现和仍未证明的边界
- 关联对象：obj-001
- 当时的能力信号：只写本对象中值得以后跨对象核查的候选；没有则省略
- 来源证据：本课 Classroom Log 中的对应记录
```

同一教学事件只保存一个 Trace，即使它关联多个对象。能力信号只留在 Trace；Tutor 不创建
或修改 `memory/capabilities/`。

### 2. 对象记忆

先沿 `memory/INDEX.md` 复用已有稳定对象和别名。确有新对象时才在
`memory/objects/` 创建稳定文件，并把它加入一个或多个相关 bucket。对象文件保持这个
可扫描形状：

```markdown
# obj-001：同构结构识别

## Current Judgment

能在明确提示下完成同构变形，尚未证明能自主识别。

## Evolution Overview

从首次未主动比较共同结构，到提示后能够完成；独立入口仍待检验。

## Trace Timeline

- 2026-08-07 [trace-plan-001-lesson-001-01](../../plans/plan-001/lessons/lesson-001.md#trace-plan-001-lesson-001-01)
  — 提示比较共同结构后完成，尚未证明能自主识别。

## Boundaries / Not Yet Demonstrated

- 尚无外观变化较大时的自主识别证据。
```

更新已有对象时，Current Judgment 和 Evolution Overview 可以随证据修订；Trace Timeline
按发生顺序补上本次所有相关 Trace，旧链接不删。对象分桶是多对多入口，不搬动稳定文件。
对象是否合并不明确时保留暂定对象，交给 Plan Coach，不在课末追求完美分类。

### 3. 明确偏好

只有学生明确表达或多次确认互动需求时，创建或更新 `memory/preferences/<stable-id>.md`。
保留最小充分原话、发生时间、来源 Lesson、真实作用范围、当前适用判断和表达时间线。
“用了对照后学得更快”只是效果观察，不自动写成偏好；“今天”不升级成长期特征。

### 4. 局部路由

只更新本课受影响的 `memory/indexes/*.md` 和 `memory/INDEX.md` 入口。INDEX 保留当前学习
前沿、相关 bucket、此刻可能改变教学动作的能力与偏好线索，以及稳定路径；它不是历史
清单。教学待办、下一课安排和跨对象能力定论都不进入 memory。

## 写完之后

本 Session 不回读刚写入的 INDEX、对象或偏好来重新判断学生。公开总结依据本课对话与
课堂事实；写入面向后续 Session。若某次文件写入失败，只核对并修复同一个目标，不重复
已经落盘的 Trace，也不扫描目录猜测其他产物。
