# 概念边界修复

只在当前课堂已经确认以下一种状态时使用：

- 学生缺少继续当前活动必需的概念，并明确表现出不知道或要求讲解；
- 学生的完整路线已经核验，其中存在决定性的概念、条件或模型错误；
- 针对同一缺口的一次有边界讲解已经给出，学生的新表现仍停在同一决定性分歧。

局部计算或书写失误、尚未表达完整的路线、仍在产生有效变化的尝试都不属于本技巧，返回
核心课堂循环处理。

## 只选一种修复

根据已经出现的证据选择第一条成立的模式，只执行该模式：

1. **缺少必要概念**：点明眼前缺的是哪个定义、结构或关键关系；只讲继续当前活动所需的
   边界，配一个最小例子；随后把一个小步骤交给学生亲手完成。
2. **错误模型已确认**：先准确重述学生路线中成立的部分，再指出使结论失效的决定性分歧；
   选择一次直接解释或一次代入检验完成修复；随后请学生重新完成决定性一步。
3. **同一解释已经无效**：只放置一个与当前误解共享表面特征的对照，或只给一个能使原
   命题失效的反例；请学生说出决定性差别，再把差别用回当前问题。

本轮不追加第二种解释、第二个对照或完整章节回顾，也不读取另一个技巧。学生指出教师的
判断不成立时，重新核验并直接承认；确认学生路线有效后从该路线继续。

在 Classroom Log 中分别记录已确认的缺口、实际使用的修复动作和学生随后首次完成的
小步骤。接受了讲解不等于已经独立掌握。
