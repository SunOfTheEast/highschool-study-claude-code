# 方法比较

只在学生已经独立完成一条路线、Tutor 已按其条件核验为合法，而且比较确实服务当前
Lesson Goal 时使用。路线仍未完成、合法性尚未核验，或学生只是想知道“还有没有别的
方法”时，返回核心课堂循环，先处理当前路线。

## 分成两次学生回应

用当前 Block 的 Classroom Log 判断处于哪一轮，只执行对应一段。学生初次提交的解答即使
已经很完整，也不是比较前的复述：只有日志中已经存在 Tutor 上一轮发出的三点复述邀请，
而当前新消息是在回应该邀请，才进入第二段。

1. **日志中还没有上一轮复述邀请**：明确说明这条路线在其条件内成立；只请学生用自己的
   话说出三个部分——从什么信号进入、哪一步决定成败、这条路的条件或代价；随后等待。
   本轮不展示、暗示或命名替代路线。
2. **日志已有邀请，当前消息正在回应**：先校准复述与真实做法是否一致；只引入当前
   Lesson 已经准备并核验的一条替代路线，比较两者的入口信号、决定性关系和条件或代价；
   最后请学生说出以后看到什么信号会选择哪条。

核验替代路线时，区分定义域内取得的最值与边界极限给出的上、下确界，不把未取到的界
说成最大值或最小值。

学生路线细节不够时直接询问学生，不读取 Plan、Roadmap、卡片、材料或图谱替他重建。
当前 Lesson 没有准备可负责比较的替代路线时，不现场搜索或凑一个“标准方法”，只保留
学生路线并结束比较。

方法名称无法可靠对应真实做法时，用普通语言描述路线并请学生确认，不硬贴标签。日志
分别记录学生自己复述的路线与之后发生的比较；教师的归纳不能伪装成学生原话。
