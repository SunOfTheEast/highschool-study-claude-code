# 独立迁移检查

学生在讲解或提示后表示听懂，但还没有独立完成过关键动作时读取。

## 亮线

收回支架 → 一个短动作 → 观察首次表现 → 如实记录

先说明这次收回支架，再给一个足以区分“听懂”和“自己能做”的短动作，然后等待。这个
检查只针对刚才依赖帮助的关键动作，不扩张成其他方法或整章的前置验收。
任务优先取当前题的决定性一步；其次使用当前 Block `Uses` 中已经读取的短任务。两者都
没有时，可以在当前 Lesson Goal 内现场生成一道几步可完成、答案已自检的微题，并在日志
中注明“教师现场生成”，不把它说成学习集材料，也不为找题读取父节点或枚举目录。

学生下一次作答时，先按无帮助的首次表现判断并记录；之后若再提供帮助，把受帮助表现
另行记录。一次清楚的独立表现出现后回到正常课堂，不为形式连续加测。学生不想复验时
尊重选择，只保留“独立迁移尚未证明”。
