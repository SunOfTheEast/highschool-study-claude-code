# Lesson 教学技巧目录

本文件只供打包检查与人工审计，不是 Tutor 的运行时路由器。Tutor 依据
`tutor-lesson/SKILL.md` 的可观察条件直接读取一个文件，不先读取本目录。

- `concept-boundary-repair.md`：必要概念缺失、已确认错误模型或同一解释无效时，选择一次
  有边界的概念修复动作。
- `frustration-and-pause.md`：学生明确停止时回应并停下；仍愿意继续时先接住挫败，再给一个
  可选的小入口或暂停选择。
- `independent-transfer-check.md`：帮助后尚无独立证据时，收回支架并安排一个短动作，区分
  听懂与独立完成。
- `method-comparison.md`：学生已经完成并核验合法路线时，先等学生复述自己的路线，下一轮
  才比较最多一个已准备的替代。
