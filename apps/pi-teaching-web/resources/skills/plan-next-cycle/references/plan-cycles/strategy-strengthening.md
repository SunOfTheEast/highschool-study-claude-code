# Strategy-strengthening cycle

## Use when

Use this when the student knows relevant methods but route recognition, comparison,
execution stability, or transfer across shells remains weak.

## Stage problem

The student must become able to select and carry a suitable route because of the
problem's structure, not because tasks are grouped under a method label.

## Minimum starting information

Know which methods are already available, where the student's choice or execution
becomes unreliable, the Plan standard, and what would count as a genuinely unfamiliar
or mixed test.

## Default phase graph

```text
independent route-choice baseline
→ compare conditions and costs
→ controlled variation
→ mixed/interleaved selection
→ unfamiliar transfer
→ direct check
```

## Evidence sought at each phase

- Baseline: what the student notices and chooses without a route menu.
- Comparison: whether conditions, costs, and switching points can be explained.
- Variation: whether one changed feature changes the decision appropriately.
- Mixed selection: whether method labels are no longer needed.
- Transfer and check: whether choice and execution survive a new shell independently.

## Branches and loops

If choice is sound but execution fails, add a small number of full closures without
reteaching the route. If execution is fluent only in labelled sets, increase mixed
selection. If several routes work but costs are unclear, compare them explicitly. If
an unfamiliar shell fails, distinguish surface-recognition failure from missing core
understanding before choosing repair or construction.

## Sufficient completion boundary

The student independently chooses, justifies, and carries a route on representative
mixed or unfamiliar material within the declared standard. Repetition inside one
obvious family is not enough.

## Common Lesson templates

Deliberate practice, stage-consolidation review, and capability assessment.

## Common misjudgment

Do not treat more same-method exercises as route-choice training, or a correct route
named after prompting as independent selection.

A phase may occupy zero, one, or several Lessons and may be skipped, repeated,
merged, or revisited. Do not encode fixed Lesson IDs, counts, minutes, mastery scores,
or runtime phase fields.
