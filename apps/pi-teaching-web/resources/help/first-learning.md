# 快速开始：完成第一次学习

StudyForge 不要求你先会制订学习计划，也不要求你准确说出自己哪里不会。第一次使用时，
只要从眼前真实在学的内容开始。

## 先选一个入口

| 你现在手里有什么 | 从哪里开始 |
|---|---|
| 一本 PDF 教材、教辅或讲义 | 在首页选择“放入一本 PDF 开始学习” |
| 一道题、一段话或一个想法 | 在首页选择“问老师” |
| 暂时没有书，也没有现成学习集 | 在首次设置中选择“从空白开始” |
| 以前使用过的 StudyForge 文件夹 | 在首次设置中选择“打开已有学习集” |

最推荐的第一条路是放入你正在使用的书。书已经替你安排好了章节顺序，老师可以沿着原文
解释，也能把新形成的笔记和题卡固定回原来的位置。

## 跟着一本书学一次

1. 选择 PDF，等待书籍页面出现。导入不会立即扫描整本书。
2. 如果 PDF 自带目录书签，可以直接点章节；没有书签时，只整理目录所在的少量页面即可。
3. 打开学校正在学的章节或当前页。中间显示的原始书页始终是核对依据。
4. 点击“从这一页开始学”。老师只会带入你明确选择的少量连续页面。
5. 直接说真实情况，例如：“这段话每个字都认识，但我不知道它为什么放在这里。”

原生正文能读时，系统优先使用原生正文；扫描页、公式或复杂图表可以选择“视觉读取这一页”。
转写只是帮助老师定位内容，公式、图表和版式仍以原页为准。

## 不知道该问什么，也可以这样说

- “先别直接讲，看看我到底卡在哪里。”
- “我会做书上的例题，但换个样子就不会了。”
- “这两个概念我总是混，能用一个小问题帮我分开吗？”
- “我突然觉得它和以前学过的东西有关，但说不清楚。”

老师需要定位问题时，会先把判断当作待验证的猜测，再用一个短问题核对；不会因为一句含糊
的话就给你贴标签。问题已经清楚时，老师会直接进入解释或讨论，不会强行考试。

## 把这次学习留下来

讨论中形成了值得保留的内容时，你可以说“把刚才的结论整理成笔记”或“把这道题保存成
题卡”。老师会先把完整草稿展示出来：

1. 先检查标题、正文、题干和答案；
2. 有问题就直接指出，老师会修改草稿；
3. 只有你确认最新草稿后，内容才会保存。

笔记可以带有用于遮住答案自测的回忆块；题卡会先隐藏标准答案，等你作答或选择“不会，
直接看答案”后再展示。保存只是把内容留下来，不代表老师认定你已经掌握。

## 下一次从哪里继续

- 首页会保留最近的自由学习和当前课程入口；
- “学习资料”可以查找书、笔记与闪卡、题卡，并带着选中的内容继续问老师；
- “学习日历”会显示学习约定和到期复习；
- 需要连续学习一个较大方向时，再使用首页的“规划长期学习”。

自由学习线程由你点击“结束这次自由学习”结束。一个小问题不必建立正式课程；希望老师在
多次学习之间持续调整方向、备课和上课时，才需要长期学习。

想查询某个具体功能，请切换到“功能手册”；遇到安装、模型连接或启动问题，请切换到
“安装与模型”。

## 文件和模型边界

学习文件保存在本机。每个学习集位于 `~/Documents/StudyForge/`，其中包括原始 PDF 与普通
学习文件。
向老师发消息或请求视觉读取时，当前任务所需消息、明确选择的资产或页段会交给你选择的
模型服务处理；不会无条件上传整个学习集或整本书。
