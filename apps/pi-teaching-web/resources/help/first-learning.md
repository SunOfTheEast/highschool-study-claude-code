# 第一次学习

StudyForge 不要求你先会做学习计划，也不要求你先准确说出自己哪里不会。最简单的用法是：
把正在学习的书放进来，打开眼前一页，然后和老师一起学。

## 从一本书开始

第一次打开时选择 PDF 教材、教辅或讲义。StudyForge 会保留原文件和真实物理页码，但不会
立刻扫描整本书：

- PDF 自带书签时，目录会直接出现；
- 没有书签时，只需指定实际目录所在的少量 PDF 页；
- 正文等到真正打开对应页面时才读取；
- 原生文本优先，扫描页或复杂版式可以使用视觉模型；
- 公式、图表和排版始终以原页为准，转写只是查找与讨论的辅助。

进入书籍页面后，可以按目录打开学校当前章节，也可以从第一页开始。点击“和老师学这里”
会建立一段带精确书页来源的自由学习；默认只带入当前选择的连续页段，不会把整本书塞给模型。

## 真的不知道怎么学也可以

你可以直接说：

- “这一节我看了两遍，但不知道它到底在解决什么。”
- “这道题我会算，换个样子就认不出来了。”
- “我分不清这两个概念，能不能先看我到底混在哪里？”
- “我有一个奇怪的联想，想看看它和以前学过的东西有没有关系。”

老师会先区分已有内容、你本次真实表现和仍然未知的部分。需要诊断时，会先把判断当作待验证
假设，而不是用一句含糊表达给你贴标签。普通寒暄或明确问题不会被强行变成测试。

没有 PDF 时也可以“从空白开始”，直接进入同样的自由学习。讨论形成的笔记和题卡以后仍可
作为学习集的第一批内容。

## 让讨论留下来

当一段理解或一道题适合保存时，老师会先在对话中展示完整草稿。你可以纠正、要求重写或
拒绝保存；只有你确认最新草稿后，系统才会写入：

- **笔记与闪卡**：正文用于完整阅读，可翻面的回忆块可以隐藏答案做快速提取；
- **题卡**：先看题干和自己的笔记作答，再决定是否查看标准答案；教师讲解依据不会提前泄露。

从书页形成的资产会固定到这份书的具体版本和页码。以后在“沿书学习”中可以按章节
找到它，也可以在“知识之间”按语义标签看到跨书联系。

保存内容不等于老师宣布你已经掌握。教师记忆只记录真实发生的表现及其边界，例如“在提示
比较共同结构后完成，尚未验证能否自主识别”。

## 查找、复习和继续问

“学习资料”支持按标题、正文、来源和标签查找。你可以：

- 打开一份笔记或题卡；
- 勾选少量资产后带着它们问老师；
- 从书的章节树查看资产从哪里长出来；
- 对到期资产直接复习，或选择一批进入复习对话；
- 在日历里查看约定和待复习内容；
- 在一段真实学习中开启专注计时。

复习结果记录的是这一次提取发生了什么，不会改写旧记录，也不会自动变成掌握分数。

## 需要长期课程时

自由学习适合眼前问题、发散讨论和按书阅读。想在较长周期里稳定推进时，可以从首页进入
“规划长期学习”：

1. 长期规划对话先确认是否真的需要一条长期路径；
2. 长期路线讨论希望发生的变化、可观察标准和直接检验；
3. 学习阶段讨论这一段要解决什么，并按实际情况准备若干次课；
4. 每次课堂都按学生真实回答推进并留下课堂事实。

完整方案必须先展示，再由你自然语言确认。继续聊天、沉默或“你安排”只允许老师提出方案，
不批准尚未看见的路线、阶段或课堂。浏览和刷新也不会自动开始或结束课程。

## 文件在哪里

每个学习集保存在 `~/Documents/StudyForge/`，核心内容是可以直接打开的 Markdown/YAML，
原始 PDF 单独保留。App 升级与学习资料彼此分开；备份时完整复制学习集文件夹即可。

学习文件保存在本机。向老师发消息或请求视觉读取时，当前任务所需消息、明确选择的资产或
页段会交给你选择的模型服务处理；不会无条件上传整个学习集或整本书。
