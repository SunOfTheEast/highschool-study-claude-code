# 安装、模型与故障处理

当前桌面预览版支持 Apple Silicon Mac 和 macOS 13 及以上。App 已包含运行学习所需的组件，
正常使用不需要安装 Bun、Node、Rust，也不需要打开终端。

## 下载并安装

1. 从项目的 [StudyForge 0.1.0 Release](https://github.com/SunOfTheEast/highschool-study-claude-code/releases/tag/studyforge-desktop-v0.1.0) 下载 `StudyForge_0.1.0_aarch64.dmg`。
2. 如需核对文件，SHA-256 应为 `2ca3fcabb4953c42b2a8461a379d327c00fc144fb069844a8969f0d6ed01cfe3`。
3. 双击 DMG，把 StudyForge 拖到“应用程序”。
4. 在“应用程序”中打开 StudyForge。

不要从陌生网盘或转发文件安装；文件名相同不代表内容相同。

## macOS 提示无法验证时

当前预览包采用 ad-hoc 签名，尚未经过 Apple 公证。第一次打开时，macOS 可能提示无法验证
开发者或无法检查恶意软件。这不是“已经被 Apple 证明安全”的版本。

先尝试打开一次 StudyForge，再进入“系统设置 → 隐私与安全性”，滚动到安全性区域，点击
“仍要打开”，按系统提示确认。学校管理的 Mac 可能禁止这个操作；此时请联系管理员，不要
绕过设备管理策略。

## 第一次选择学习集

安装完成后有四种入口：

- **选择 PDF**：最推荐，直接放入正在使用的教材、教辅或讲义；
- **从空白开始**：没有书也可以直接问老师，让学习集随讨论生长；
- **打开已有学习集**：选择以前的 StudyForge 文件夹；
- **使用导数示例**：复制一份带题卡和正式课程的演示学习集。

每个学习集独立保存在 `~/Documents/StudyForge/`。更换当前学习集不会删除其他学习集；正在
计时或处理一段学习时，系统可能要求先结束当前活动再切换。

## 安排模型

StudyForge 至少需要主教师和检索 Scout 两个位置。先在“模型连接”中连接一个服务，再选择：

| 位置 | 负责什么 | 使用频率 |
|---|---|---|
| 主教师 | 对话、诊断、长期方向、备课和课堂判断 | 几乎每次学习 |
| 检索 Scout | 备课时从学习资料中找出足够合适的候选 | 只在需要材料时 |
| 资料视觉 | 独立读取扫描页、公式和图表 | 只在页面需要图像读取时 |

主教师和 Scout 都必须选择，二者可以使用不同服务商。资料视觉默认“自动选择低成本视觉模型”；
也可以明确选择一个支持图像输入的模型。完成后点击“完成设置并开始学习”。

“思考强度”越高，复杂判断通常更稳，但也可能更慢、消耗更多。普通教学和方向性规划不一定
适合同一个模型；如果暂时不确定，先使用设置页自动带出的选项，实际体验后再调整。

### 登录与 API Key

不同服务商可能提供浏览器登录、设备代码或 API Key。界面会显示当前支持的连接方式：

- 浏览器登录时，选择“在浏览器中继续登录”，完成后回到 StudyForge；
- 需要设备代码时，按界面显示的代码完成授权；
- 输入 API Key 时，确认它来自服务商官方控制台，不要从聊天群购买或分享。

StudyForge 使用独立的模型凭据、设置和对话目录，不读取或改写普通 Pi 的配置。更换模型后，
本地教师会重新启动；稍等连接状态恢复后再发送消息。

## PDF 读取不准确时

先看中间的原始页，再判断问题出在哪里：

- **目录没有出现**：指定真实目录所在的少量物理页，让系统只整理这些页面；
- **扫描页没有正文**：选择“视觉读取这一页”；
- **公式、表格或图形转写不对**：以原页为准，在提问时指出具体位置；
- **读取速度慢**：从当前页开始，不必等待整本书处理；老师确实需要时再向前后展开。

视觉读取失败不会破坏原始 PDF，也不会阻止你继续查看原页。

## 常见故障

| 页面提示 | 可以先做什么 |
|---|---|
| 模型暂时不可用 | 打开“设置”，确认服务已连接且当前模型仍可使用 |
| 本地教师没有启动 | 选择“重试”；仍失败时彻底退出 App 后重新打开 |
| 学习集无法打开 | 重新选择正确的学习集文件夹，不要手动删除其中一部分文件 |
| 消息长时间没有回复 | 先等待当前状态结束；若连接已断开，再重试或更换模型 |
| PDF 页面无法读取 | 保留原文件，换一页测试；扫描页改用视觉读取 |
| 设置完成后没有回到学习页 | 等待本地教师重启；仍停留时关闭并重新打开 App |

反馈问题时可以附上页面显示的诊断代码和复现步骤，但不要发送 API Key、OAuth 一次性代码、
私人学习集、学生原话或整本受版权保护的书。

## 数据与隐私

- 学习文件保存在本机，替换或升级 App 不会删除 `~/Documents/StudyForge/` 中的学习集；
- 向老师发消息或请求视觉读取时，当前任务所需内容会交给你选择的模型服务处理；
- 系统不会无条件上传整个学习集或整本书；
- 云端处理仍受所选模型服务商的服务条款、计费方式和隐私政策约束；
- 备份时完整复制学习集文件夹，不要只复制其中某一份 Markdown 文件。

安装与模型就绪后，请切换到“快速开始”；想查具体功能，请切换到“功能手册”。
