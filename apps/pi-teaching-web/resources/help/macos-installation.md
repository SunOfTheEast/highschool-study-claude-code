# 在 macOS 上安装 StudyForge

当前桌面预览版支持 Apple Silicon Mac 和 macOS 13 及以上。App 已包含 StudyForge Runtime
与 Pi，正常使用不需要安装 Bun、Node、Rust，也不需要打开终端。

## 1. 下载并安装

1. 从项目的 [StudyForge 0.1.0 Release](https://github.com/SunOfTheEast/highschool-study-claude-code/releases/tag/studyforge-desktop-v0.1.0) 下载 `StudyForge_0.1.0_aarch64.dmg`。
2. 如需核对文件，SHA-256 应为 `2ca3fcabb4953c42b2a8461a379d327c00fc144fb069844a8969f0d6ed01cfe3`。
3. 双击 DMG，把 StudyForge 拖到“应用程序”。
4. 在“应用程序”中打开 StudyForge。

不要从陌生网盘或转发文件安装；同名 DMG 不代表内容相同。

## 2. 第一次被 macOS 拦住时

当前预览包采用 ad-hoc 签名，尚未经过 Apple 公证。macOS 因此可能提示无法验证开发者或
无法检查恶意软件。这不是“已被 Apple 证明安全”的版本。

先尝试打开一次 StudyForge，再进入“系统设置 → 隐私与安全性”，滚动到安全性区域，点击
“仍要打开”，按系统提示确认。学校管理的 Mac 可能不允许这个操作；此时请联系管理员，
不要绕过设备管理策略。

## 3. 选择怎样开始

第一次打开时，最直接的入口是“选择 PDF”：

- **从一本书开始**：导入正在使用的教材、教辅或讲义，老师沿原书次序带你学。
- **从空白开始**：没有书也可以直接问老师，学习集会随讨论生长。
- **打开已有学习集**：继续使用以前的 StudyForge Markdown 文件夹。
- **使用导数示例**：复制一份带 519 张题卡和正式课程入口的示例。

导入 PDF 不会立刻扫描全书。原文件先保存在本机，目录与正文等到真正打开对应页时再逐步
整理，因此不需要在第一次见面时长时间等待。

## 4. 连接模型

设置页会列出当前支持的模型服务商及登录方式。至少需要选择一位主教师：

- **主教师**负责对话、诊断、课程和最终教学判断；
- **检索 Scout**在备课需要材料时召回足够合适的候选；
- **资料视觉**只在扫描页、公式或复杂版式需要图像读取时工作，可以自动选择，也可以明确指定支持图像输入的模型。

主教师和材料检索助手可以使用不同服务商。模型不可用时，StudyForge 会要求重新选择，不会
暗中换成别的模型。视觉模型若未配置，原始 PDF 仍可阅读，只是扫描页无法自动转写。

StudyForge 使用独立的模型凭据、设置和对话目录，不读取或改写普通 Pi 的配置。调用云端
模型时，当前任务所需内容会受所选模型服务商的条款与隐私政策约束。

学习文件保存在本机。向老师发消息或请求视觉读取时，当前任务所需内容会交给你选择的
模型服务处理；不会无条件上传整个学习集或整本书。

## 5. 开始学习

导入书后：

1. 打开书；若 PDF 没有书签，先填写纸面目录实际位于 PDF 的页段，并整理这些目录页。
2. 打开学校正在学习的章节或页面。
3. 点击“和老师学这里”。老师默认只读取当前选中的少量页，需要时再向前后展开。
4. 遇到转写不准、公式或图表时，以中间显示的原页为准，也可以手动点“视觉读取这一页”。

完整学习流程见[第一次学习](first-learning.md)。

## 6. 文件与故障

学习集保存在 `~/Documents/StudyForge/`。替换或升级 App 不会删除这里的资料；备份时完整
复制对应学习集文件夹即可。

状态单会区分学习集无效、Provider 未连接、模型不可用和本地教师未启动。按页面给出的
动作重试、换模型或重新选择学习集即可。反馈问题时可以附诊断代码，但不要发送 API Key、
OAuth 一次性代码、私人学习集、学生原话或整本受版权保护的书。
