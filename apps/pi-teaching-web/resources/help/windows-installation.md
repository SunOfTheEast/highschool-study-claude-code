# Windows 安装与模型设置

这一页适用于 **Windows 10 或 Windows 11 的 64 位电脑**。当前 Windows 版本是小范围内测版，
尚未购买代码签名证书；请只从项目正式 Release 或你信任的内测分发者处下载安装包。

## 先安装 StudyForge

1. 双击下载的 `StudyForge_*_x64-setup.exe`。
2. 如果 Windows 显示“Windows 已保护你的电脑”，先确认文件确实来自项目正式 Release，
   再点“更多信息”与“仍要运行”。
3. 按安装向导完成当前用户安装，然后从开始菜单打开 StudyForge。

安装不需要管理员权限，也**无需安装 Git、Bash、Node.js 或 Bun**。StudyForge 会使用自己随包携带的
命令环境，不会读取或修改你电脑上已有的开发工具配置。

安装程序会在需要时联网安装或更新 Microsoft WebView2。多数 Windows 10/11 电脑已经自带它；
如果安装过程停在 WebView2，请先检查网络连接，再重新运行安装包。

## 第一次打开

第一次打开后按界面顺序完成三件事：

1. 选择“导入一本书”或“从空白开始”。第一次试用更建议放入你现在真正使用的教材或讲义 PDF。
2. 配置模型。可以使用 API Key，也可以选择界面提供的 OAuth 登录方式。
3. 回到学习首页，沿书页开始，或直接把一道真错题、一个真困惑交给老师。

## 三个模型角色怎么选

- **主教师**：负责与你对话、诊断、讲解和课程判断。这里最值得使用能力较强的模型。
- **检索 Scout**：负责从题卡、笔记和书页索引中找候选内容；可以用更快、更便宜的模型。
- **资料视觉**：只在 PDF 页面没有可靠文本时读取页面图像。主教师支持视觉时可以共用，
  也可以另选便宜的多模态模型。

不确定时先照界面推荐配置。模型质量会直接影响诊断、讲解深度、等待时间与费用；StudyForge
不会把不同服务商之间的差异伪装成没有差异。

## 文件与隐私边界

学习文件保存在本机的 `Documents/StudyForge`。教师在工作时只会把当前任务所需的文字、题目、
书页或图片交给你选择的模型服务处理，不会无条件上传整个学习集。不同模型服务商如何保存和
处理请求，仍以你选择的服务商政策为准。

StudyForge 的模型登录、会话和私有工具配置放在自己的应用目录里，不会占用或覆盖你另外安装的
Pi、Git 或 Bash。

## 常见故障

### 双击后被 Windows 拦截

当前内测安装包尚未签名。先核对下载来源；来源可信时，通过“更多信息”选择“仍要运行”。如果文件
并非来自正式 Release 或可信内测分发者，不要继续。

### 安装后白屏或提示 WebView2

保持联网并重新运行安装程序；必要时先通过 Microsoft 官方安装程序更新 WebView2，再打开
StudyForge。

### 设置完成后老师没有回应

先看顶栏是否显示“本地已连接”，再到“设置”检查主教师是否完成登录或 API Key 是否有效。
修改模型配置后按界面提示重启本地教师。

### 导入 PDF 后暂时没有章节

书籍会渐进处理：先显示原页，再逐步生成页文本、目录和章节投影。扫描版需要资料视觉模型，
处理时间会比原生文本 PDF 更长；不必等整本处理完再开始学。

### 想彻底移除

从 Windows“设置 → 应用 → 已安装的应用”卸载 StudyForge。卸载程序不会擅自删除
`Documents/StudyForge` 里的学习资料；确认不再需要后，可由你自己另行整理或删除。
