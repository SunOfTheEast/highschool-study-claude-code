# 功能手册

这份手册按“我现在想做什么”组织。你不需要从头读到尾；先在下面找到目标，再跳到对应章节。

## 我想……

| 目标 | 入口 |
|---|---|
| 跟着教材或教辅往下学 | 首页打开一本书，或在“学习资料”选择 PDF |
| 直接问一道题、一个概念或一个联想 | 首页“问老师” |
| 带着以前的笔记、题卡或书页继续聊 | “学习资料”勾选内容后选择“带着所选问老师” |
| 保存刚讨论出的结论或题目 | 在对话中告诉老师保存为笔记或题卡 |
| 复习已经保存的内容 | “学习日历”、资产页面或“学习资料”的“复习所选” |
| 连续学习一个较大的方向 | 首页“规划长期学习” |
| 约定下次学习或专注一段时间 | “学习日历”，或对话页的“开始专注” |
| 回看自己真正做过什么 | “学习足迹” |

## 沿着一本书学习

### 什么时候用

手里已有教材、教辅、讲义或习题书，并希望跟着学校进度、原书次序或某个真实章节学习时，
优先走这条路。书不只是题目和定义的集合，它还保留了编者安排的先后关系与上下文。

### 怎么用

1. 在首页或“学习资料”中选择 PDF。
2. 打开书籍页面，从目录进入章节；没有目录书签时，可以指定真实目录所在的少量页来整理。
3. 在阅读页使用上一页、下一页或目录移动，并以中间的原始书页为准。
4. 点击“从这一页开始学”，把当前页或明确选择的连续页带入自由学习。
5. 需要更多原文时，再让老师向相邻页面展开。

系统按需读取页面，不要求先把整本书处理完。原生正文读取失败或版式复杂时，可以使用
“视觉读取这一页”。从书页保存出的资产会保留书名和原始位置，以后可以从资产回到原文。

### 不会自动发生什么

- 导入一本书不会自动宣称你学过它，也不会生成阅读进度；
- 系统不会因为导入了整本 PDF，就把整本书作为对话上下文上传；
- 转写内容不会取代原始页，公式和图表仍应回原页核对。

## 自由学习：直接问老师

自由学习适合眼前的问题、没有固定目标的讨论、按页阅读、发散联想和临时复习。你可以不带
任何资料，只使用模型已有的知识；也可以从书页、笔记或题卡进入，让老师只看你选中的内容。

一次自由学习可以很短。普通寒暄不会自动变成诊断；明确问题不会被强行绕成考试。你确实
说不清卡点时，老师才会用短问题帮助定位。完成后点击“结束这次自由学习”，以后仍能从首页
的最近记录回看。

### 带着已有内容讨论

在“学习资料”中勾选少量笔记、题卡或资料，然后选择“带着所选问老师”。新对话顶部会列出
本次带入的内容。没有选中的资产不会因为它存在于学习集里就自动进入这次对话。

## 笔记与闪卡

StudyForge 把完整笔记和用于提取记忆的闪卡放在同一种资产里：

- **正文**保存完整解释、推导、比较或整理；
- **回忆块**由一个提示和一个隐藏答案组成，可以直接翻面复习。

笔记通常从对话中形成。你先看到草稿，确认后才保存；保存后仍可以打开“编辑笔记”，修改
标题、正文和回忆块。每次保存形成新的内容版本，旧版本仍可在“内容历史”中回看。

有回忆块的笔记可以直接复习；只有正文的笔记更适合带着去问老师，由老师根据正文提出问题。
一份写得很漂亮的笔记只代表内容已经形成，不自动证明你能独立复述或迁移。

## 题卡

题卡用于真正作答，而不是提前浏览讲解。打开题卡后：

1. 先阅读题干并写下自己的作答；
2. 如果完全不会，可以选择“不会，直接看答案”；
3. 作答发生后再打开标准答案；
4. 把自己的错因、提醒或新想法写进“我的题内笔记”；
5. 需要讨论时，选择“带着这次作答问老师”。

课堂或备课中采用了教师自拟题时，老师会先告知题目内容，再询问是否保存为题卡。题卡的
标准答案不会因为老师在备课时已经看过，就提前出现在学生作答面。

## 三种方式整理学习资料

“学习资料”不是只有一张货架，可以从三个方向看同一批内容：

| 视图 | 适合回答的问题 |
|---|---|
| 沿书学习 | 这份笔记或题卡来自哪本书、哪个章节？ |
| 按类型查看 | 我有哪些原始资料、笔记与闪卡、题卡？ |
| 知识之间 | 哪些内容带有共同的语义标签，可以继续建立联系？ |

搜索框可以按标题、正文、来源或标签查找。点击资产上的标签可以缩小范围。

“知识之间”的连线表示标签在同一批资产中共同出现，方便找邻居和发散；它不自动表示前置、
因果、相似或掌握程度。来源关系可以回到真实书页，语义联系则可以跨越不同的书。

## 复习

新保存的笔记和题卡会进入间隔复习；原始资料本身不是复习项。你可以从三个地方开始：

- 在“学习日历”选择当天到期的少量内容；
- 在“学习资料”勾选内容后选择“复习所选”；
- 打开单份笔记或题卡直接复习。

笔记需要先尝试回答回忆块，再显示答案；题卡需要先作答或明确不会，再查看标准答案。完成后
由你选择“没想起来”“想起来了，但比较吃力”或“顺利想起来”，系统据此安排下一次日期。

复习结果只描述这一次提取，不是总分，也不会回写或美化以前的记录。不想继续安排某份资产时，
可以在资产页面选择“移出复习”；以后仍可重新开始。

## 正式课程

当目标需要多次学习、备课和连续调整时，使用首页的“规划长期学习”。正式课程分为三层，
学生界面会把它们称为长期路线、学习阶段和课堂：

1. **长期路线**讨论一段较长时间里希望发生什么变化，以及怎样直接检验；
2. **学习阶段**收窄当前要解决的部分，课程次数按真实学习情况调整；
3. **课堂**承载一次具体学习活动、题目、材料和课堂记录。

老师会先讨论并展示完整方案；你用自然语言确认后才会建立相应内容。“你安排”、沉默或继续
操作不等于批准一个尚未看见的方案。每次课堂和学习阶段也由明确的“完成”动作收口。

备课可能需要检索和核对材料，因此会比普通对话慢。准备完成后，可以从课程界面开始上课；
需要打印课堂内容时，可以让老师在备课后生成讲义。

## 学习日历与专注

“学习日历”汇总所有本地学习集的约定和到期复习。点开某一天可以：

- 查看或选择到期资产，立即复习或安排到具体时间；
- 新建、修改或删除一次学习约定；
- 把约定指向自由学习、当前学习阶段或一批复习内容；
- 到时间后选择“现在开始”，进入相应位置。

自由学习或课堂对话中可以开始 15、25 或 45 分钟专注。计时可以暂停、继续或提前结束；
对话结束时，属于该对话的专注也随之结束。专注计时帮助保留时间感，不替你评价学习质量。

## 学习足迹与教师记忆

“学习足迹”按时间展示真实发生过的活动，例如一次对话、资产形成、作答或认知变化。它不是
排行榜，也不会把“打开过”“保存过”自动写成“已经掌握”。能回到原活动时，条目会提供
“回到这段学习”。

老师可以记住学生在具体知识对象上的学习变化、跨对象反复出现的能力假设和明确表达的互动
偏好。判断必须保留证据边界：提示后完成仍是提示后完成，一次表现不会自动变成永久标签。

## 可选与实验功能

这些能力不会改变核心学习流程，可能依赖特定模型、额外配置或当前学习情境：

- **头脑风暴**：把当前问题与已学资产、题库中尚未接触的内容、模型世界知识和可选论文线索连接起来；
- **主张挑战**：当你希望有人认真反驳或攻击一条论证时，老师会寻找决定性的分歧，而不是只表示赞同；
- **论文线索**：讨论确实需要前沿来源时，可以做一次有边界的检索；它不是默认开启的全面研究；
- **阿夏同学与语音**：你明确点名她时，可以让同龄伙伴加入自由学习；语音需要相应服务；
- **桌宠皮套**：设置中可以导入兼容的 Live2D 皮套；没有皮套时不会显示占位窗口。

当前没有真人群聊、云端班级或自动替学生发言的功能。实验能力失败时，老师应回到普通对话，
不能阻断核心学习。
