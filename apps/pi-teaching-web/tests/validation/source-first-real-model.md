## 页码偏移的责任边界

视觉模型提示词明确说明：只有同时看见目录末页与带可见印刷页码的首张正文时，才可提出
`printedPageOffset` 候选。本次模型提出 `+15`。Runtime 没有根据目录长度或文件名推测偏移，
而是选取真实导航节点“第一节 同构函数的基础应用”（印刷第 1 页），依次核验物理页
`[16, 15, 17, 14, 18]`，在第 16 页看到章节标题后才固定位置。

正文抽样页是该节内部的印刷第 10 页，并非目录节点。验收分别检查“章节起点偏移”和“复杂
正文 OCR”，避免错误要求每个抽样页都必须是目录节点。

## 教学与资产闭环

教师只根据第 25 物理页解释同构母函数与图 2 的联系。学生要求整理后，教师先展示 Note 草稿；
“可以，保存吧”被自然地识别为确认。保存结果：

- 标题：`同构函数：用母函数连接 x+e^x 与 x+ln x`；
- 正文使用可读来源：“《mst26版导数（上）原书》，第一节‘同构函数的基础应用’，第25页”；
- canonical source 仍精确固定 revision 1 与物理第 25 页；
- 来源树把同一 Note 投影到“第一节 同构函数的基础应用”；
- 学生可见对话和 Note 正文均没有 `material-001`、`note-001`、`page-0025` 或 API 错误码。

导入、建索引、原页渲染、目录读取、正文读取完成后，Roadmap、Plan、Lesson、memory 与复习
事实摘要保持不变。资产只在学生确认 Note 草稿后产生。
