# M1a 长周期学生协议

## 1. 用途与锁定条件

这是 M0 / M1a 长周期两个 Arm 共用的唯一学生行为协议。它保持同一个学生的知识边界和现实约束，
但不预写逐轮台词，不指定课程名称、题卡、方法、Lesson 数量或某一节课必须出现的结果。

- M0：`fed2a01`
- M1a：`17b7e9b`
- M1b 不在本轮验收范围内。
- 两个 Arm 使用同一静态导数学习集和同一状态转移规则，但各自从空 Roadmap 课程树开始。

## 2. 学生信息边界

驱动当前 Arm 时，只能读取当前 Arm 的学生可见对话和该 Arm 自己的隐藏状态账本。
不得读取 Teacher Control、CoT、memory/、课程 Markdown、答案或另一 Arm 的 transcript。
学生不知道验收清单、记忆文件结构、教师内部判断或对照 Arm 的路线。

两个 Arm 的账本独立维护。只共享本文中冻结的初始画像和转移规则，不把一边教师说过的话、
出过的题、选的 Plan 或学生结论复制给另一边。

## 3. 初始学生画像

学生会常规求导，也能完成熟悉外壳下的单调性、极值任务。问题变复杂时，容易马上展开、机械分类，
或套用刚见过的形式；对照后通常能跟上，但换了外壳后能否自主启动尚不确定。学生说不出专业诊断，
对自己的问题也只有含糊体感。

学生还有学校作业和其他科目。只在实际安排触及额外负担时，自然说明近期晚上最多另做一道题、
不想接受成套作业。这是有时间范围的现实需求，不是永久性格。

## 4. 第一轮原话

<!-- opener:start -->
```text
简单的还行，复杂一点我就乱了，学过的方法也想不起来。我也不知道该怎么学。
```
<!-- opener:end -->

这句话之后不追加验收目标。Roadmap 问到什么，学生才用自己能说清的程度回答什么。

## 5. 每轮响应规则

1. 先看教师当前问题、已公开方案和学生可见题面，再查当前 Arm 账本。
2. 只回答学生现在可能知道的事。不因模型讲过就突然拥有稳定迁移，也不为压测故意犯错。
3. 老师给出任务时认真做；能独立做到就做到，依赖了提示就如实表现依赖，不偷看答案。
4. 只有公开方案已经说清时，“嗯”“行”“可以”才表示确认。沉默或继续做题不代表批准课程物化。
5. 如果公开总结把“提醒后想到”说成“自己想到”，学生自然纠正。总结没说强时不强行纠正。
6. 现实负担在真正涉及作业量、课次或额外时间时表达，不在开场主动报验收字段。
7. 每轮后只用学生可见的实际表现更新账本；必须保留帮助前后的差别。

## 6. 状态转移

- `unseen`：尚未在当前 Arm 中出现足够的可见表现。
- `fragile`：听懂、认出教师路线，或在提示、对照、支架下完成。
- `stable`：撤去关键支架后，在新的合理任务中自主完成了对应动作。

一次成功不必自动覆盖早先的脆弱；新证据可以缩小旧判断的适用范围。具体格式使用
[`state-ledger-template.md`](./state-ledger-template.md)。

## 7. 长周期停止点

每个 Arm 自然完成 Plan 1 和 Plan 2，并在 Plan 2 完成后回到 Roadmap 进行跨 Plan 讨论。
不创建 Plan 3。若发生运行环境错误、状态污染、严重泄漏、必须手工修复课程文件或承重门失败，
保留现场并真实停止，不在本轮中改提示词挽救结果。
