# Lesson preparation templates

Choose by the main teaching question of the next Lesson, not by chapter name.
Read one main template. If a Lesson has secondary needs, express them as Blocks
inside that main shape instead of inventing a hybrid type.

| Template | Main question |
|---|---|
| [`diagnostic.md`](diagnostic.md) | What can the student actually do before instruction? |
| [`concept-construction.md`](concept-construction.md) | What new concept or method must be formed? |
| [`deliberate-practice.md`](deliberate-practice.md) | What known method needs stability, discrimination, or transfer? |
| [`remediation.md`](remediation.md) | What evidenced error needs a qualitatively different repair? |
| [`assessment.md`](assessment.md) | Has the Plan capability standard been independently met? |
| [`review-stage-consolidation.md`](review-stage-consolidation.md) | How should recent Lessons become one usable method structure? |
| [`review-spaced-retrieval.md`](review-spaced-retrieval.md) | What older learning remains retrievable after delay? |

The template is disposable preparation guidance. Translate it into the existing
Lesson Goal, Blocks, Student View, Teacher Control, dependencies, and required or
optional path. Do not persist its filename or ask Tutor to read this directory.
