# Error-remediation Lesson

## Use when

Use this only when an important error, misconception, or unproductive habit is
visible in an original Lesson Block and deserves focused repair.

## Intended change

Help the student replace the mechanism that produced the error, then show the change
on genuinely separate material. Rehearsing the corrected answer is not enough.

## Necessary teaching functions

- Reread the original Block and distinguish observed work from later summaries.
- Ask the student to confirm or refine what actually went wrong.
- Expose the mechanism through a clearer contrast, representation, counterexample,
  or route that is qualitatively different from the failed explanation.
- Practise the repaired decision, then recheck it independently elsewhere.

## Default activity path and depth

Use an original-error reconstruction, one illuminating contrast or representation,
a guided repair task, targeted practice, and a separate unseen parallel recheck.
Prepare only as many tasks as the mechanism requires; the sequence is capacity, not
a quota.

## Adaptation from student evidence

If the student's reconstruction disproves the Coach's hypothesis, change the repair
rather than defending the label. If the error disappears once the representation
changes, move to independent recheck. If it persists, vary the corrective approach,
not just the numbers in the same explanation.

## First-pass information boundary

The known error and purpose of repair can be discussed openly. Do not pre-solve the
unseen recheck or tell the student which cue it was selected to test.

## Sufficient closing evidence

The student can describe the corrected distinction and independently avoids the same
mechanism on a new parallel task. State how narrow that evidence is.

## Reflection default

Use reflection when the student can name the old trigger and a replacement check in
their own words. A forced apology or generic “be careful” statement has no value.

Do not turn this default into fixed minutes, fixed Block IDs, runtime fields, or a
template-specific schema.
