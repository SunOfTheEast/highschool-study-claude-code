# Roadmap 诊断 references

这里保存 Roadmap Session 按需读取的长周期诊断方法。

`roadmap-dialogue/SKILL.md` 仍是批准门和职责尺度的唯一入口。没有匹配的具体 reference
时，使用主 Skill 与 `LEARNING_GUIDE.md`，不要自行发明固定问卷、诊断分数或学生标签，
也不要一次加载全部诊断文件。

| Reference | 何时读取 |
|---|---|
| [`first-roadmap.md`](first-roadmap.md) | Plan Tree 为空且没有当前 Plan：初次会面的自然问诊与首个 Plan 提案。 |
| [`live-diagnostic-probes.md`](live-diagnostic-probes.md) | 仅在初次会面中学生无法稳定描述问题、两种以上解释会导向不同 Plan、且继续交谈难以区分时：现场短诊断探针协议。 |

跨 Plan 复诊与下一个 Plan 的制定不在本目录，见
[`../next-plan.md`](../next-plan.md)。
