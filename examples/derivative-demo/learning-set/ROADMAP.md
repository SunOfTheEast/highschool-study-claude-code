# 导数学习 Roadmap

## Goal

把定义域、同构变形和参数分离真正嵌入导数解题过程；先完成“定义域完整性”的专项加固，再根据真实课堂证据决定后续目标。

本 Roadmap 由 StudyForge 导数学习集迁移后去标识化生成，不把旧系统的临时推断冒充长期记忆。

## Observable Capability Standard

面对未见过的含对数、分母、根式或参数约束的导数题，能够在任何等价变形与分类讨论前独立写出全部合法域，并在解题中主动使用这些约束确定区间、参数边界和取等可行性；在最后一题嵌套约束迁移测试中首次尝试无遗漏、无提示。

## Test

- 连续两道不同结构题均独立列全定义域约束。
- 至少跨两类题型把定义域用于推导答案边界，而不只是最后验算。
- 最后一题包含嵌套或参数化定义域约束，首次尝试一次通过。
