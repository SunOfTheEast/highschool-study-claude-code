# 高阶导数学习指南

## Student Learning Principles

- 先看函数、参数和条件之间的结构，再决定是否立刻求导或分类讨论。
- 不只写“用了什么方法”，还要说清为什么当前结构值得用它。
- 同一种方法要在不同题目外壳中反复辨认；看起来相似不等于真正会迁移。
- 复盘时区分结构识别、方法选择、运算执行和条件检验，避免把所有失误都归为粗心。
- 以陌生题中的独立表现检验学习结果，而不是以刚讲过的题能否复述为准。

## Internal Teaching Notes

### Learning logic

本学习集以方法结构为主线。通常先辨认函数与参数的组织方式，再选择同构变形、
参变量分离、切线与公切线、数形结合或局部逼近等路线，随后完成推导并检查条件，
最后用不同外壳的陌生任务验证迁移。定义域和边界是论证合法性的一部分，但不应
默认挤占高级方法学习的主线。

### Learner difficulties

- 学生可能一看到参数就开始分类，尚未先判断能否降维或分离。
- 学生可能记住方法名称，却不能指出题目中真正触发该方法的结构。
- 一次计算正确容易被误认为方法已经稳定；同壳重复不能代替陌生迁移。
- 运算失误、条件遗漏和方法判断错误需要分开诊断，修复方式不同。

### Teaching choices

- 让每个任务承担清楚且不同的作用，例如暴露起点、形成对比或检验迁移。
- 需要比较方法时，先让学生完成自己的路线，再讨论两条路线各自抓住的结构。
- 结束任务优先更换题目外壳，检查学生能否独立说明结构、选择方法并完成关键论证。
- 若学生已表现出主线能力，不为覆盖边角条件而继续堆叠低价值练习。
