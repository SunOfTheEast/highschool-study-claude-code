# 根式函数处理 — 导数的秘密 增量补充

> MST 没有根式函数专题。导秘中有零星覆盖，以下提取为独立知识点。

---

## 核心场景

`√x`、`√(x+1)`、`√(x²+1)` 与 `ln x` 或 `eˣ` 的组合函数，典型的浙江卷风格。

---

## 技巧一：代换降次（最基础）

**思路**：设 `t = √x` 或 `t = √(x+1)`，把根式函数转化为多项式（或更低次）处理。

**例题**（2019浙江）：`f(x) = a·ln x + √(x+1)`，令 `z = √x`，`p(z) = −z − 1/z − 4ln z`，求导后 `p'(z) = (−z²−4z+1)/z²`，二次函数判别符号。

**触发条件**：√x 和 ln x 共现 → 设 t = √x，ln x = 2ln t。

---

## 技巧二：根式因式分解

**思路**：把 `√(x+1)` 当作一个整体变量 `u`，对 `f'(x)` 进行因式分解。

**例题**（2019浙江求导）：
```
f'(x) = ((2√(x+1)+1)(√(x+1)−2)) / (4x√(x+1))
```
因式分解后，符号只取决于 `√(x+1)−2` → 临界点 x=3。

**触发条件**：求导后表达式含 √(x+1)，尝试将 u=√(x+1) 代换后进行因式分解。

---

## 技巧三：√(x²+1) 型 — 有理化与反双曲

**核心恒等式**：
```
(√(x²+1) − x)(√(x²+1) + x) = 1
→  √(x²+1) − x = 1/(√(x²+1) + x)
```

**反双曲正弦**：
```
ln(x + √(x²+1)) = arsh(x)，导数 = 1/√(x²+1)
```

**例题**（导秘思考6）：求证 `1 + x·ln(x+√(x²+1)) ≥ √(x²+1)`。

---

## 技巧四：根式的切线放缩

**根式函数也可以做切线放缩**：

| 不等式 | 来源 | 等号 |
|--------|------|------|
| √(x+1) ≤ (√2/4)(x+3) | √(x+1) 在 x=1 处的切线 | x=1 |
| √x ≤ (x+1)/2 | 均值不等式 | x=1 |

**例题**（2019浙江充分性证明）：用 `√(x+1) ≤ (√2/4)(x+3)` 放缩后，根式消失，退化为多项式分析。

---

## 技巧五：根式对数不等式

**ln x 的根式上下界**（比切线更紧）：

| 不等式 | 条件 | 来源 |
|--------|------|------|
| ln x ≤ √x − 1/√x | x ≥ 1 | 飘带函数的根式变体 |
| ln x ≤ 4(√x−1)/(√x+1) | x > 0 | 帕德逼近的根式形式 |

**用法**：当切线精度不够时（如 `ln x ≤ x−1` 太松），升级到根式界。
