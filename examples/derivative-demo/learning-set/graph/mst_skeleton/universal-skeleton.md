# 导数通用知识图谱骨架 (Universal Skeleton)

> 按题型组织。每一类题型下列出可选策略、每个策略下的具体方法、每个方法调用的知识。
> 思想层作为全局认知基础前置。

## 全局认知基础（思想层）

解题前先回答"为什么往这个方向想"：

| 思想 | 核心判断 |
|------|---------|
| 阶差原理 | eˣ/x/lnx 无法通过求导同时消去 → 必须走代数变形 |
| 凹凸性 | 凸上凹下，切线为界 → 不等式方向由此决定。切线与最值本质等效：凸函数的最小值 = 切线在下方紧贴的位置，视角可互换 |
| 降维分析 | 高次行为由低次导数决定 → 通过导数逐层降维 |
| 局部逼近 | 光滑函数局部≈多项式/有理函数 → 可近似替代 |
| 数形结合 | 代数式↔几何图像同构 → 在两种语言间翻译 |
| 对称破缺 | 对称结构天然易解（抵消、取等、换元归一），非对称是常态。系数不等的表达式（x₁+2x₂, 3x₁−x₂）需要额外做功——加权、放缩、主元、配凑——才能归约到可处理框架。解题第一步：识别对称性，对称是送的，不对称才是要做的 |
| 必要-充分探路 | "先猜后证"在导数中的工程化版本。利用端点、极点、隐零点等特殊点获取参数的必要条件（缩参），再验证充分性。第七章（显点能直接算）和第八章（隐点需放缩代换）共享同一个逻辑框架，区别仅在于特殊点的可计算性 |

## 题型一：恒成立求参数范围

> 已知 f(x, a) ≥ 0 对所有 x∈D 成立，求 a 的范围（或最值）。

**策略选择指南**（按优先级）：
1. 端点可直接代入 → 端点效应
2. 存在明显零点（f(0)=0 或 f(1)=0）→ 极点效应
3. 极值点存在但不可显式求解 → 隐点代换
4. 可拆成非负函数之和 → 保值性分解
5. 可拆成两边各自求最值 → 分而治之
6. 含 ∀/∃ 量词嵌套 → 图像位置法（包裹性）
7. kx+b ≤ f(x) 型 → 切线零点比大小

### 可用策略

#### 策略：端点效应
**何时选**：区间端点处 f(a) 或 f(b) 可直接计算，提供参数的必要条件。
**方法**：端点效应标准流程、端点探路+矛盾取点、端点探路+指对清洁、双端点+中间零点模型（两端点均提供约束，中间零点锁定参数）、端点效应参变分离
**知识**：无特定知识依赖

#### 策略：极点效应
**何时选**：存在明显零点 x₀（如 f(0)=0 或 f(1)=0），可令 f'(x₀)=0。
**方法**：极点效应流程、双参数极点效应、极点效应失效分析、高阶导数判定极值
**知识**：K11 高阶导数与极值判定

#### 策略：隐点代换
**何时选**：极值点存在但无法显式求解，需要通过 f'(x₀)=0 建立关系后消元。
**前置步骤**：用放缩取点法证明隐零点存在（参见题型三·放缩取点）
**方法**：隐零点代换-初高分流、隐零点代换-参变分离、插值放缩法、整数格点探路法（参数限制为整数时，必要性探路后在整数格点上验证最大/最小解）
**知识**：K18 可解方程清单

#### 策略：保值性分解
**何时选**：f(x) 可拆分为 eˣ−x−1 或 x−lnx−1 等非负函数之和。

**本质**：多个非负项在公共零点处联动收紧，把参数逼出来。
- **加法型**：h₁≥0, h₂≥0, h₁(x₀)=h₂(x₀)=0，且 h₁+h₂+m·φ≥0。若 φ(x₀)=0，由于 h₁+h₂ 在 x₀ 处以"二次接触"（h'(x₀)=0），而余量 m·φ 在 x₀ 处是"线性穿过"（φ'(x₀)≠0），一旦 m≠0 余量就会在 x₀ 一侧变负，拖垮整体 → m 必须 = 0。
- **乘法型（因子同号）**：f(x)g(x) ≥ 0 恒成立，f 和 g 都单调过零 → 零点必须重合，否则一侧乘积为负 → 共零点条件锁定参数。这是 |a−1|+|b−2|=0 ⇒ a=1,b=2 在导数中的推广。

**方法**：保值性余量分析法
**知识**：K2 基本切线不等式

#### 策略：分而治之
**何时选**：f(x) ≥ g(x) 可拆分为两边各自求最值。
**方法**：上下函数选取法
**知识**：K1 六大函数模型、K2 基本切线不等式

#### 策略：图像位置法（包裹性）
**何时选**：题目含 ∀/∃ 量词嵌套 + 恒成立/能成立。
**方法**：包裹性分析法
**知识**：K15 包裹性四定理

#### 策略：切线零点比大小
**何时选**：kx+b ≤ f(x) 恒成立，求 b/k 或 ab。
**方法**：切线零点比大小法
**知识**：K2 基本切线不等式

## 题型二：不等式证明

> 证明 f(x) ≥ g(x)（或 >、<、≤）对所有 x 成立。

### 可用策略

#### 策略：同构归约
**何时选**：表达式中 eˣ、ln x、x 共现，可通过代换归约到同一单调函数。
**方法**：变换链操作、乘积型构造、和差型构造、双曲型构造、乘积指数化+切线放缩
**方法触发**：
- 出现 x·eˣ 或 x·ln x → 乘积型构造
- 出现 eˣ±x 或 x±ln x → 和差型构造
- 出现 eˣ 和 e⁻ˣ 共现 → 双曲型构造
- 含 a·eᵃˣ 且右侧含 ln → 乘积指数化+切线放缩
- 两侧共用母函数但自变量不对称 → 不对称补全+夹逼法
- 以上都不明显 → 变换链操作（最通用）
**知识**：K1 六大函数模型、K12 零点关联性质

#### 策略：切线放缩
**何时选**：函数凹凸性明显，可用切线不等式放缩。
**方法触发**：给定切点（如"在 x=1 处"）→ 切点构造法；给定斜率 → 斜率构造法
**知识**：K2 放缩公式谱系

#### 策略：逼近替代
**何时选**：函数局部行为可被多项式/有理函数/更简单的曲线近似。
**方法**：泰勒估值法、帕德夹逼法、双曲型放缩夹逼法、以曲代曲法（用一个可证不等式的简单曲线替代复杂曲线）
**知识**：K4 泰勒展开式、K5 帕德逼近、K2 双曲型放缩

#### 策略：分而治之
**何时选**：两侧可分别归约到已知最值的基本函数。
**方法**：上下函数选取法
**知识**：K1 六大函数模型

#### 策略：加强不等式
**何时选**：直接证 f(x) ≥ g(x) 困难，但 f 的结构暗示可添项凑出已知结论的形式。
**方法**：添加一项使不等式更"紧"但结构上能与已知恒等式或函数对齐，转证强化后的不等式
**知识**：K2 放缩公式谱系

#### 策略：表达式清洁
**何时选**：表达式含 ln x 或 eˣ 与复杂函数的乘积，需先清洁再识别结构。
**方法**：对数项孤立化、指数项配对化简、除以单项式重构法（不等式两边同除 xⁿ 使两侧出现已知最值函数形式）、根式代换降次法（√x 和 ln x 共现时设 t=√x）
**知识**：无特定知识依赖（清洁后调用同构或切线放缩的知识）

## 题型三：零点个数与存在性

> 判断 f(x)=0 有几个解，或证明在某区间内存在解。

### 可用策略

#### 策略：图像交点法
**何时选**：可将方程改写为 g(x)=a 形式，或两条曲线求交点。
**方法触发**：
- 参数可完全移到等式一侧 → 参变分离法（画水平线最简单）
- 参数不能完全分离 → 参变半分离法（画两条曲线）
- 含绝对值或分段定义 → 模块函数分析法
- f(f(x)) 型 → 嵌套函数零点法（内横外竖）

**知识**：K1 六大函数模型（帮助判断 g(x) 的图像形态）

#### 策略：放缩取点
**何时选**：需要严格证明零点存在（用介值定理），但端点函数值含有超越项无法计算。
**方法触发**：
- 标准零点存在性证明 → 放缩取点标准链（先极值点，再两侧找点）
- 两侧都有指数项，增长不对称 → 等效零点法（提取公因式后客体放缩）
- 含 eˣ 和多项式混合 → 主客体分析法（区分主导项和从属项）
- 极值点偏移场景下找点 → 极值点偏移取点法（利用偏移方向缩小搜索范围）
- 初步找到的点精度不够 → 二分法升级精度

**知识**：K18 可解方程清单、K19 放缩方向原则、K2 基本切线不等式

#### 策略：极值显点探路
**何时选**：f'(x) 可因式分解，一个极值点是显式的（如 x=1），其余需分析。
**方法**：从显式极值点出发，用单调区间推断零点分布
**知识**：K1 六大函数模型

## 题型四：对称中心偏移

> f(x₁)=f(x₂) 且存在对称中心 x₀（极值点或拐点），证明 x₁+x₂ 与 2x₀ 的关系。
> 这是题型十（双变量不等式）的高频特例——当两个变量由 f(x₁)=f(x₂) 约束时触发。

### 子类型

#### 4a. 极值点偏移（一阶导零点为对称中心）
**策略**：对称化构造 — F(x)=f(x)−f(2x₀−x)
**方法**：对称化构造法
**知识**：K14 极值点偏移方向判定

#### 4b. 拐点偏移（二阶导零点为对称中心）
**策略**：对称化构造 — 同一逻辑，对称中心改为拐点 x₀（f''(x₀)=0）
**方法**：对称化构造法（以拐点为中心）
**知识**：K14 偏移方向判定扩展到拐点

### 其他可用策略

**策略**：对数均值不等式策略 — 由 f(x₁)=f(x₂) 导出等式，套用对数均值不等式
**方法**：对数均值不等式应用
**知识**：K13 均值不等式族

**策略**：拟合替代 — 对称化构造精度不够时升级
**方法**：拟合替代法（二次函数/双曲型放缩逼近）
**知识**：K20 常见拟合函数

## 题型五：数值比较（比大小）

> 比较 a,b,c 的大小（通常涉及 e、ln、π 等常数的组合）。

### 可用策略

**方法触发**（按精度递进）：
- 可化同底/同幂 → 初级比较法（先做，排除明显大小关系）
- 可归约到六大函数 → 同构归约（中级精度）
- 可作图 → 图像交点法（直观）
- 数值非常接近，需高精度 → 逼近替代（终极武器）

#### 策略：初级比较法
**何时选**：可归一化或存在明显中间变量——先用粗方法排除，不要一上来就同构。
**方法**：同底/同幂化、中间变量传递法、二项式定理展开
**知识**：无特定知识依赖

#### 策略：同构归约
**何时选**：数值可归约到六大同构函数的自变量→用单调性比较。
**方法**：六大同构函数比大小（E1-E6）
**知识**：K1 六大函数模型、K17 aᵇ vs bᵃ 规则、K17 糖水不等式

#### 策略：逼近替代
**何时选**：数值接近，需要高精度估计。
**方法**：泰勒估值法、帕德夹逼法
**知识**：K4 泰勒展开式、K5 帕德逼近

#### 策略：图像交点法
**何时选**：可作图观察交点位置。
**方法**：直线与指数和差交点法
**知识**：K16 指数和差交点表

## 题型七：切线几何问题

> 切线的计算、条数判定、公切线、包络线——所有以切线为直接研究对象的几何问题。

### 子类型与可用策略

#### 7a. 基本切线计算
> 在某点处求切线；过曲线外一点求切线；设切点参数化。

**方法**：在某点处的切线（f(x₀)+f'(x₀)(x−x₀)）；过点外的切线（设切点 t，代入给定点，解的个数=切线条数）
**知识**：无特定知识依赖（导数定义+点斜式）

#### 7b. 切线条数判定
> 过某点可以作曲线的几条切线。

**策略**：切线计数（区域分类法）
**何时选**：函数有明显的拐点和/或渐近线。
**方法**：切线条数区域判定法——找到拐点（f''=0）→作拐点处切线→找渐近线→分区→查表
**知识**：K6 三次函数切线条数区域表、K7 含渐近线函数切线条数区域表

#### 7c. 公切线问题
> 两曲线的公切线条数、公切线方程、公切线涉及参数。

**策略**：公切线双轨
**何时选**：两曲线凹凸性明确（几何轨）或可设切点联立（代数轨）。
**方法**：公切线代数求法（设切点→斜率相等+截距相等→联立）；公切线几何判定法（凹凸性×交点个数→查表）；平行曲线公切线法（g(x)=f(x−a)−b → 斜率=b/a）
**知识**：K8 公切线条数判定表、K8 平行曲线公切线斜率公式、K8 aˣ与log_a x公切线

#### 7d. 包络线判定
> 切线族的边界曲线，判定某点是否在包络区域内。

**方法**：包络线判别法——设点 P(x₀,y₀)→写过 P 的切线方程（以切点 t 为参数）→看方程是否有实数解→有解在区域内，无解在区域外
**知识**：无特定知识依赖

#### 7e. 牛顿迭代（关联：零点求解）
> 用切线迭代逼近函数零点。

**方法**：x_{n+1} = x_n − f(x_n)/f'(x_n)，几何意义：过 (x_n, f(x_n)) 作切线，与 x 轴交点为 x_{n+1}
**知识**：K23 牛顿迭代法（二次收敛，每步有效数字翻倍）

## 题型十：双变量不等式

> 涉及 x₁,x₂ 两个变量且它们满足等式约束（如 f(x₁)=f(x₂)）。

### 可用策略

**方法触发**（按结论形式选择）：
- 结论涉及 x₁/x₂ 或 x₁·x₂ → 比值代换法
- 结论涉及 x₁−x₂ → 差值代换法
- 结论涉及 x₁+x₂ 与 2x₀（有对称中心）→ 对称化构造（题型四）
- 两变量地位不对称，一个求导后大幅简化 → 主元法
- 需要 |x₁−x₂| 的数值界 → 切割线夹法
- 以上精度不够 → 拟合替代法升级

#### 策略：调整法（多变量平均化降维）
**何时选**：三个或以上变量，无等式约束，需证明对称不等式。对变量排序后，证明"越平均目标值越大（或越小）"。
**方法**：排序→证明 f(x,y,z) ≤ f(x, (y+z)/2, (y+z)/2) → 重复至所有变量相等 → 退化为单变量
**知识**：K2 放缩公式谱系

#### 策略：比值/差值代换
**何时选**：双变量由 f(x₁)=f(x₂) 关联，可通过比值或差值消元。
**方法**：比值代换法、差值代换法
**知识**：K1 六大函数模型（用于单变量化后的函数分析）

#### 策略：主元法
**何时选**：两变量地位不对称，其中一个求导后表达式大幅简化。
**方法**：主元选择法
**知识**：无特定知识依赖

#### 策略：切割线夹
**何时选**：需要估计 |x₁−x₂| 的范围。
**方法**：切割线夹法
**知识**：K2 基本切线不等式

#### 策略：拟合替代
**何时选**：需要更精确的界。
**方法**：拟合替代法
**知识**：K20 常见拟合函数、K13 均值不等式族

## 题型十一：数列不等式

> 证明涉及 n 的求和/乘积不等式，用导数不等式作为放缩工具。

### 子类型

#### 11a. 切线放缩型求和
**方法**：将连续不等式中的 x 替换为 1/n 或 n/(n+1) → 裂项求和
**知识**：K21 数列代换模式、K2 放缩公式谱系

#### 11b. 裂项相消型
**方法**：接龙型裂项法（a_n − a_{n+1} 型累加抵消）、隔项相消法
**知识**：K21 数列代换模式

#### 11c. 等比放缩型
**方法**：等比放缩构造法（将不等式构造成等比数列形式后求和）
**知识**：K2 放缩公式谱系

#### 11d. 双曲型放缩/帕德高精度型
**方法**：用飘带或帕德逼近获得比基础切线更紧的数列界
**知识**：K5 帕德逼近、K2 双曲型放缩上界

#### 11e. 累乘估计型
**方法**：不等式取对数后累加，或直接累乘放缩
**知识**：K2 放缩公式谱系

## 题型十二：三角-导数综合

> 含 sin x, cos x, tan x 的导数问题。三角函数的周期性、有界性、恒等式使标准策略需要适配。

### 子类型与方法

#### 12a. 三角+零点
**方法**：周期分段讨论法——利用三角函数周期性将定义域分段，逐段分析单调性和零点
**知识**：K2 三角放缩、K22 三角恒等式

#### 12b. 三角+恒成立
**方法**：有界性压参法——利用 |sin|≤1、|cos|≤1 直接缩参范围，再对缩窄后的候选区间验证
**知识**：K2 三角放缩、K11 高阶导数与极值判定

#### 12c. 三角+数列
**方法**：将三角不等式（如 sin(1/n) 的泰勒界）代入数列通项，转为标准数列不等式处理
**知识**：K2 三角放缩、K21 数列代换模式

#### 12d. 三角+双变量
**方法**：和差化积+双变量法——用三角恒等式将双变量表达式转化为可分离的乘积形式，再套用主元法或比值代换
**知识**：K22 三角恒等式
