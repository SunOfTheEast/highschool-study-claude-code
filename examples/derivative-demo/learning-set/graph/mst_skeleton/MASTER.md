## 一、思想层

解题前先回答"为什么往这个方向想"：

| 思想 | 核心判断 |
|------|---------|
| 阶差原理 | eˣ/x/lnx 无法通过求导同时消去 → 必须走代数变形 |
| 凹凸性 | 凸上凹下，切线为界 → 不等式方向由此决定。切线与最值本质等效：凸函数的最小值 = 切线在下方紧贴的位置，视角可互换 |
| 降维分析 | 高次行为由低次导数决定 → 通过导数逐层降维 |
| 局部逼近 | 光滑函数局部≈多项式/有理函数 → 可近似替代 |
| 数形结合 | 代数式↔几何图像同构 → 在两种语言间翻译 |
| 对称破缺 | 对称结构天然易解（抵消、取等、换元归一），非对称是常态。系数不等的表达式（x₁+2x₂, 3x₁−x₂）需要额外做功——加权、放缩、主元、配凑——才能归约到可处理框架。解题第一步：识别对称性，对称是送的，不对称才是要做的 |
| 必要-充分探路 | "先猜后证"在导数中的工程化版本。利用端点、极点、隐零点等特殊点获取参数的必要条件（缩参），再验证充分性。第七章（显点能直接算）和第八章（隐点需放缩代换）共享同一个逻辑框架，区别仅在于特殊点的可计算性 |

## 题型一：恒成立求参数范围

> 已知 f(x, a) ≥ 0 对所有 x∈D 成立，求 a 的范围（或最值）。

**策略选择指南**（按优先级）：
1. 端点可直接代入 → 端点效应
2. 存在明显零点（f(0)=0 或 f(1)=0）→ 极点效应
3. 极值点存在但不可显式求解 → 隐点代换
4. 可拆成非负函数之和 → 保值性分解
5. 可拆成两边各自求最值 → 分而治之
6. 含 ∀/∃ 量词嵌套 → 图像位置法（包裹性）
7. kx+b ≤ f(x) 型 → 切线零点比大小

### 可用策略

#### 策略：端点效应
**何时选**：区间端点处 f(a) 或 f(b) 可直接计算，提供参数的必要条件。
**方法**：端点效应标准流程、端点探路+矛盾取点、端点探路+指对清洁、双端点+中间零点模型（两端点均提供约束，中间零点锁定参数）、端点效应参变分离
**知识**：无特定知识依赖

#### 策略：极点效应
**何时选**：存在明显零点 x₀（如 f(0)=0 或 f(1)=0），可令 f'(x₀)=0。
**方法**：极点效应流程、双参数极点效应、极点效应失效分析、高阶导数判定极值
**知识**：K11 高阶导数与极值判定

#### 策略：隐点代换
**何时选**：极值点存在但无法显式求解，需要通过 f'(x₀)=0 建立关系后消元。
**前置步骤**：用放缩取点法证明隐零点存在（参见题型三·放缩取点）
**方法**：隐零点代换-初高分流、隐零点代换-参变分离、插值放缩法、整数格点探路法（参数限制为整数时，必要性探路后在整数格点上验证最大/最小解）
**知识**：K18 可解方程清单

#### 策略：保值性分解
**何时选**：f(x) 可拆分为 eˣ−x−1 或 x−lnx−1 等非负函数之和。

**本质**：多个非负项在公共零点处联动收紧，把参数逼出来。
- **加法型**：h₁≥0, h₂≥0, h₁(x₀)=h₂(x₀)=0，且 h₁+h₂+m·φ≥0。若 φ(x₀)=0，由于 h₁+h₂ 在 x₀ 处以"二次接触"（h'(x₀)=0），而余量 m·φ 在 x₀ 处是"线性穿过"（φ'(x₀)≠0），一旦 m≠0 余量就会在 x₀ 一侧变负，拖垮整体 → m 必须 = 0。
- **乘法型（因子同号）**：f(x)g(x) ≥ 0 恒成立，f 和 g 都单调过零 → 零点必须重合，否则一侧乘积为负 → 共零点条件锁定参数。这是 |a−1|+|b−2|=0 ⇒ a=1,b=2 在导数中的推广。

**方法**：保值性余量分析法
**知识**：K2 基本切线不等式

#### 策略：分而治之
**何时选**：f(x) ≥ g(x) 可拆分为两边各自求最值。
**方法**：上下函数选取法
**知识**：K1 六大函数模型、K2 基本切线不等式

#### 策略：图像位置法（包裹性）
**何时选**：题目含 ∀/∃ 量词嵌套 + 恒成立/能成立。
**方法**：包裹性分析法
**知识**：K15 包裹性四定理

#### 策略：切线零点比大小
**何时选**：kx+b ≤ f(x) 恒成立，求 b/k 或 ab。
**方法**：切线零点比大小法
**知识**：K2 基本切线不等式

## 题型二：不等式证明

> 证明 f(x) ≥ g(x)（或 >、<、≤）对所有 x 成立。

### 可用策略

#### 策略：同构归约
**何时选**：表达式中 eˣ、ln x、x 共现，可通过代换归约到同一单调函数。
**方法**：变换链操作、乘积型构造、和差型构造、双曲型构造、乘积指数化+切线放缩
**方法触发**：
- 出现 x·eˣ 或 x·ln x → 乘积型构造
- 出现 eˣ±x 或 x±ln x → 和差型构造
- 出现 eˣ 和 e⁻ˣ 共现 → 双曲型构造
- 含 a·eᵃˣ 且右侧含 ln → 乘积指数化+切线放缩
- 两侧共用母函数但自变量不对称 → 不对称补全+夹逼法
- 以上都不明显 → 变换链操作（最通用）
**知识**：K1 六大函数模型、K12 零点关联性质

#### 策略：切线放缩
**何时选**：函数凹凸性明显，可用切线不等式放缩。
**方法触发**：给定切点（如"在 x=1 处"）→ 切点构造法；给定斜率 → 斜率构造法
**知识**：K2 放缩公式谱系

#### 策略：逼近替代
**何时选**：函数局部行为可被多项式/有理函数/更简单的曲线近似。
**方法**：泰勒估值法、帕德夹逼法、双曲型放缩夹逼法、以曲代曲法（用一个可证不等式的简单曲线替代复杂曲线）
**知识**：K3 泰勒展开式、K5 帕德逼近、K2 双曲型放缩

#### 策略：分而治之
**何时选**：两侧可分别归约到已知最值的基本函数。
**方法**：上下函数选取法
**知识**：K1 六大函数模型

#### 策略：加强不等式
**何时选**：直接证 f(x) ≥ g(x) 困难，但 f 的结构暗示可添项凑出已知结论的形式。
**方法**：添加一项使不等式更"紧"但结构上能与已知恒等式或函数对齐，转证强化后的不等式
**知识**：K2 放缩公式谱系

#### 策略：表达式清洁
**何时选**：表达式含 ln x 或 eˣ 与复杂函数的乘积，需先清洁再识别结构。
**方法**：对数项孤立化、指数项配对化简、除以单项式重构法（不等式两边同除 xⁿ 使两侧出现已知最值函数形式）、根式代换降次法（√x 和 ln x 共现时设 t=√x）
**知识**：无特定知识依赖（清洁后调用同构或切线放缩的知识）

## 题型三：零点个数与存在性

> 判断 f(x)=0 有几个解，或证明在某区间内存在解。

### 可用策略

#### 策略：图像交点法
**何时选**：可将方程改写为 g(x)=a 形式，或两条曲线求交点。
**方法触发**：
- 参数可完全移到等式一侧 → 参变分离法（画水平线最简单）
- 参数不能完全分离 → 参变半分离法（画两条曲线）
- 含绝对值或分段定义 → 模块函数分析法
- f(f(x)) 型 → 嵌套函数零点法（内横外竖）

**知识**：K1 六大函数模型（帮助判断 g(x) 的图像形态）

#### 策略：放缩取点
**何时选**：需要严格证明零点存在（用介值定理），但端点函数值含有超越项无法计算。
**方法触发**：
- 标准零点存在性证明 → 放缩取点标准链（先极值点，再两侧找点）
- 两侧都有指数项，增长不对称 → 等效零点法（提取公因式后客体放缩）
- 含 eˣ 和多项式混合 → 主客体分析法（区分主导项和从属项）
- 极值点偏移场景下找点 → 极值点偏移取点法（利用偏移方向缩小搜索范围）
- 初步找到的点精度不够 → 二分法升级精度

**知识**：K18 可解方程清单、K19 放缩方向原则、K2 基本切线不等式

#### 策略：极值显点探路
**何时选**：f'(x) 可因式分解，一个极值点是显式的（如 x=1），其余需分析。
**方法**：从显式极值点出发，用单调区间推断零点分布
**知识**：K1 六大函数模型

## 题型四：对称中心偏移

> f(x₁)=f(x₂) 且存在对称中心 x₀（极值点或拐点），证明 x₁+x₂ 与 2x₀ 的关系。
> 这是题型十（双变量不等式）的高频特例——当两个变量由 f(x₁)=f(x₂) 约束时触发。

### 子类型

#### 4a. 极值点偏移（一阶导零点为对称中心）
**策略**：对称化构造 — F(x)=f(x)−f(2x₀−x)
**方法**：对称化构造法
**知识**：K14 极值点偏移方向判定

#### 4b. 拐点偏移（二阶导零点为对称中心）
**策略**：对称化构造 — 同一逻辑，对称中心改为拐点 x₀（f''(x₀)=0）
**方法**：对称化构造法（以拐点为中心）
**知识**：K14 偏移方向判定扩展到拐点

### 其他可用策略

**策略**：对数均值不等式策略 — 由 f(x₁)=f(x₂) 导出等式，套用对数均值不等式
**方法**：对数均值不等式应用
**知识**：K13 均值不等式族

**策略**：拟合替代 — 对称化构造精度不够时升级
**方法**：拟合替代法（二次函数/双曲型放缩逼近）
**知识**：K20 常见拟合函数

## 题型五：数值比较（比大小）

> 比较 a,b,c 的大小（通常涉及 e、ln、π 等常数的组合）。

### 可用策略

**方法触发**（按精度递进）：
- 可化同底/同幂 → 初级比较法（先做，排除明显大小关系）
- 可归约到六大函数 → 同构归约（中级精度）
- 可作图 → 图像交点法（直观）
- 数值非常接近，需高精度 → 逼近替代（终极武器）

#### 策略：初级比较法
**何时选**：可归一化或存在明显中间变量——先用粗方法排除，不要一上来就同构。
**方法**：同底/同幂化、中间变量传递法、二项式定理展开
**知识**：无特定知识依赖

#### 策略：同构归约
**何时选**：数值可归约到六大同构函数的自变量→用单调性比较。
**方法**：六大同构函数比大小（E1-E6）
**知识**：K1 六大函数模型、K17 aᵇ vs bᵃ 规则、K17 糖水不等式

#### 策略：逼近替代
**何时选**：数值接近，需要高精度估计。
**方法**：泰勒估值法、帕德夹逼法
**知识**：K3 泰勒展开式、K5 帕德逼近

#### 策略：图像交点法
**何时选**：可作图观察交点位置。
**方法**：直线与指数和差交点法
**知识**：K16 指数和差交点表

## 题型七：切线几何问题

> 切线的计算、条数判定、公切线、包络线——所有以切线为直接研究对象的几何问题。

### 子类型与可用策略

#### 7a. 基本切线计算
> 在某点处求切线；过曲线外一点求切线；设切点参数化。

**方法**：在某点处的切线（f(x₀)+f'(x₀)(x−x₀)）；过点外的切线（设切点 t，代入给定点，解的个数=切线条数）
**知识**：无特定知识依赖（导数定义+点斜式）

#### 7b. 切线条数判定
> 过某点可以作曲线的几条切线。

**策略**：切线计数（区域分类法）
**何时选**：函数有明显的拐点和/或渐近线。
**方法**：切线条数区域判定法——找到拐点（f''=0）→作拐点处切线→找渐近线→分区→查表
**知识**：K6 三次函数切线条数区域表、K7 含渐近线函数切线条数区域表

#### 7c. 公切线问题
> 两曲线的公切线条数、公切线方程、公切线涉及参数。

**策略**：公切线双轨
**何时选**：两曲线凹凸性明确（几何轨）或可设切点联立（代数轨）。
**方法**：公切线代数求法（设切点→斜率相等+截距相等→联立）；公切线几何判定法（凹凸性×交点个数→查表）；平行曲线公切线法（g(x)=f(x−a)−b → 斜率=b/a）
**知识**：K8 公切线条数判定表、K8 平行曲线公切线斜率公式、K8 aˣ与log_a x公切线

#### 7d. 包络线判定
> 切线族的边界曲线，判定某点是否在包络区域内。

**方法**：包络线判别法——设点 P(x₀,y₀)→写过 P 的切线方程（以切点 t 为参数）→看方程是否有实数解→有解在区域内，无解在区域外
**知识**：无特定知识依赖

#### 7e. 牛顿迭代（关联：零点求解）
> 用切线迭代逼近函数零点。

**方法**：x_{n+1} = x_n − f(x_n)/f'(x_n)，几何意义：过 (x_n, f(x_n)) 作切线，与 x 轴交点为 x_{n+1}
**知识**：K23 牛顿迭代法（二次收敛，每步有效数字翻倍）

## 题型九：双变量不等式

> 涉及 x₁,x₂ 两个变量且它们满足等式约束（如 f(x₁)=f(x₂)）。

### 可用策略

**方法触发**（按结论形式选择）：
- 结论涉及 x₁/x₂ 或 x₁·x₂ → 比值代换法
- 结论涉及 x₁−x₂ → 差值代换法
- 结论涉及 x₁+x₂ 与 2x₀（有对称中心）→ 对称化构造（题型四）
- 两变量地位不对称，一个求导后大幅简化 → 主元法
- 需要 |x₁−x₂| 的数值界 → 切割线夹法
- 以上精度不够 → 拟合替代法升级

#### 策略：调整法（多变量平均化降维）
**何时选**：三个或以上变量，无等式约束，需证明对称不等式。对变量排序后，证明"越平均目标值越大（或越小）"。
**方法**：排序→证明 f(x,y,z) ≤ f(x, (y+z)/2, (y+z)/2) → 重复至所有变量相等 → 退化为单变量
**知识**：K2 放缩公式谱系

#### 策略：比值/差值代换
**何时选**：双变量由 f(x₁)=f(x₂) 关联，可通过比值或差值消元。
**方法**：比值代换法、差值代换法

## K3. 泰勒展开式与麦克劳林公式（理论）

> 具体不等式已移至 K2 放缩公式谱系。此处保留泰勒公式的理论框架和余项分析。

### 通用公式

麦克劳林公式（x₀=0 的特例）：
```
f(x) = f(0) + f'(0)x + f''(0)x²/2! + f'''(0)x³/3! + ... + f⁽ⁿ⁾(0)xⁿ/n! + Rₙ(x)
```
Rₙ(x) 为佩亚诺余项：Rₙ(x) = o(xⁿ)，即比 xⁿ 更高阶的无穷小。

### 余项符号规则（关键）

**截断后余项的符号决定不等式方向**。对拉格朗日余项：
- 若余项 ≥ 0 → 展开式为下界（≥）
- 若余项 ≤ 0 → 展开式为上界（≤）
- 凹凸性是其特例：凸函数的一阶泰勒余项 ≥ 0 → f(x) ≥ 切线

**实用判定**：展开到奇数阶和偶数阶交替时，不等号方向交替。例如 ln(1+x) 展开到奇数次方为正、偶数次方为负，所以交替给出上下界。

### 常用展开完整表

#### eˣ（全实数域，凸函数）
| 展开式 | 不等式 | 等号 | 精度 |
|--------|--------|------|------|
| eˣ = 1 + x + x²/2! + x³/3! + x⁴/4! + ... | — | — | 精确 |
| 截断到 1 阶 | eˣ ≥ 1+x | x=0 | 1阶 |
| 截断到 2 阶 | eˣ ≥ 1+x+x²/2 | x=0 | 2阶 |
| 截断到 3 阶 | eˣ ≥ 1+x+x²/2+x³/6 | x=0 | 3阶 |

#### ln(1+x)（x>−1，凹函数，不等号交替）
| 展开式 | 不等式 | 等号 | 范围 |
|--------|--------|------|------|
| ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + ... | — | — | −1<x≤1 |
| 截断到 1 阶 | ln(1+x) ≤ x | x=0 | x>−1 |
| 截断到 2 阶 | ln(1+x) ≥ x−x²/2 | x=0 | x>−1 |

#### sin x（全实数域，奇函数）
| 展开式 | 不等式 | 等号 |
|--------|--------|------|
| sin x = x − x³/3! + x⁵/5! − x⁷/7! + ... | — | — |
| 截断到 1 阶 | sin x ≤ x (x≥0) | x=0 |
| 截断到 3 阶 | sin x ≥ x−x³/6 (x≥0) | x=0 |

#### cos x（全实数域，偶函数）
| 展开式 | 不等式 | 等号 |
|--------|--------|------|
| cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + ... | — | — |
| 截断到 0 阶 | cos x ≤ 1 | x=2kπ |
| 截断到 2 阶 | cos x ≥ 1−x²/2 | x=0 |

#### 1/(1−x)（|x|<1，几何级数）
```
1/(1−x) = 1 + x + x² + x³ + ... (|x|<1)
```
| 截断 | 不等式 (x≥0) |
|------|------------|
| 1阶 | 1/(1−x) ≥ 1+x |
| 2阶 | 1/(1−x) ≥ 1+x+x² |

#### 1/(1+x)（|x|<1，交错级数）
```
1/(1+x) = 1 − x + x² − x³ + ... (|x|<1)
```
| 截断 | 不等式 (x≥0) |
|------|------------|
| 1阶 | 1/(1+x) ≤ 1 （trivial）；1/(1+x) ≥ 1−x |
| 2阶 | 1/(1+x) ≤ 1−x+x² |

#### (1+x)ᵅ（|x|<1，二项展开）
```
(1+x)ᵅ = 1 + αx + α(α−1)x²/2! + α(α−1)(α−2)x³/3! + ...
```
常用特例：
- α=1/2: √(1+x) ≈ 1 + x/2 − x²/8 + ...
- α=−1: 退化为 1/(1+x) 的展开
- α=−1/2: 1/√(1+x) ≈ 1 − x/2 + 3x²/8 − ...

**不等号方向**：取决于 α 和 x 的符号。0<α<1 且 x>0 时，截断到 1 阶给出上界。

### 使用指南

1. **选择截断阶数**：所需精度决定。比大小通常 1-2 阶足够，估值问题可能需要 3-4 阶。
2. **确定不等号方向**：奇偶阶交替则方向交替；单一符号则查凹凸性或余项。
3. **注意收敛域**：ln(1+x) 仅在 −1<x≤1 收敛；1/(1±x) 仅当 |x|<1。

## K13. 均值不等式族

### 对数均值不等式 (ALG)
若 0 < x₁ < x₂，则：
```
√(x₁x₂) < (x₁−x₂)/(ln x₁ − ln x₂) < (x₁+x₂)/2
```
等号仅当 x₁=x₂。左侧 = 几何平均，右侧 = 算术平均。

**变体**：
- 反向型（加法原理）：不等号反向使用，构造反向约束
- 常数项调整型：引入参数调整到目标形式
- 根号型：√(ALG)，与三角放缩结合用于偏移问题

### 指数均值不等式
```
e^{(x₁+x₂)/2} < (eˣ¹−eˣ²)/(x₁−x₂) < (eˣ¹+eˣ²)/2  (x₁≠x₂)
```

### 阿达玛积分不等式
对凸函数 f，有：
```
f((a+b)/2) ≤ (1/(b−a)) ∫ₐᵇ f(x) dx ≤ (f(a)+f(b))/2
```
在极值点偏移中用于构造积分形式的上下界。

## K17. 比大小规则

### aᵇ vs bᵃ
令 f(x)=ln x/x，f 在 (0,e)↑，(e,+∞)↓。
- a,b > e 时：a>b ⇔ aᵇ < bᵃ（大指小底）
- a,b < e 时：a>b ⇔ aᵇ > bᵃ

### 糖水不等式
a,b,c > 0, a < b → a/b < (a+c)/(b+c)

### (a−x)^(a+x)、a^a、(a+x)^(a−x) 比较
由函数 f(t) = (a−t)^(a+t) 的单调性（通过 ln x/x 分析），三者存在确定的大小序。a 足够小时结论不同，需结合 f(x)=ln x/x 在 (0,e)↑、(e,+∞)↓ 的单调性判断。

## K19. 放缩方向原则

## K23. 牛顿迭代法

**公式**：
```
x_{n+1} = x_n − f(x_n)/f'(x_n)
```

**几何意义**：过 (x_n, f(x_n)) 作曲线的切线，切线与 x 轴交点的横坐标即为 x_{n+1}。

**收敛速度**：二次收敛——每步有效数字翻倍（前提：初始值足够接近真根且 f' 在根附近不为零）。

**使用场景**：
- 方程无法解析求解时，用牛顿法逼近数值解
- 高考中通常以"阅读材料+填空"形式考查，给初始值和迭代步骤
- 与放缩取点中的"二分法升级精度"互补：牛顿法收敛快但需要导数，二分法普适但收敛慢

## K24. 根式函数处理技巧

> √x、√(x+1)、√(x²+1) 与 ln x 或 eˣ 的组合，典型的浙江卷风格。不是独立题型——解法落在已有策略中，以下为根式特有的操作技巧。

### 代换降次
```
设 t = √x → x = t² → ln x = 2ln t → 根式消失
设 t = √(x+1) → x = t²−1
```
触发：√x 和 ln x 共现 → 代换后求导表达式大幅简化。

### 根式因式分解
求导后表达式含 √(x+1)，设 u = √(x+1) 作为整体变量进行因式分解。例：`f'(x) = ((2u+1)(u−2))/(4x·u)`，符号仅取决于 u−2。

### √(x²+1) 型有理化
```
(√(x²+1) − x)(√(x²+1) + x) = 1
→ √(x²+1) − x = 1/(√(x²+1) + x)
```
常用于将差式转化为分式，便于求导或放缩。

### 反双曲正弦
```
ln(x + √(x²+1)) = arsh(x)，导数 = 1/√(x²+1)
```
看到 `x + √(x²+1)` 和 ln 组合，直接识别为反双曲函数。

### 根式切线放缩
√(x+1) 也可以做切线放缩（见 K2 根式函数表）。

## K25. 隐点代换体系

> 极值点、零点或切点无法直接求出时，把它们作为隐点保留下来，用导数方程、零点方程或切线方程把参数和原式改写掉。

### K25.1 隐零点代换-消参

触发：存在隐极值点或隐零点 `x0`，且 `f'(x0)=0`、`f(x0)=0`、切线条件等能给出参数关系。

流程：
1. 先证明隐点存在且唯一，避免代换对象不存在。
2. 用 `f'(x0)=0` 或题设方程把参数表示成 `x0`。
3. 把目标式中的参数消掉，转成只含 `x0` 的可判号表达式。
4. 再结合放缩、单调性或可解方程完成比较。

典型用途：极点效应、隐点探路、整数格点探路、双变量中把不可见极值点变成可计算对象。

### K25.2 插值放缩法

触发：两个函数或两个零点之间需要比较，但直接比较过硬。

流程：
1. 构造中间函数或中间曲线 `p`。
2. 证明 `f >= p >= g` 或反向夹逼。
3. 利用 `p` 的简单零点、切线或极值信息传递到原问题。

## K26. 因式分解

> 导数题里，因式分解不是纯代数整理，而是为了把零点、符号和临界点暴露出来。

### K26.1 因式分解-提公因式

触发：导数或整理后的表达式有公共因子，如 `(x-a)`、`e^x`、`x`、`ln x`、根式整体项。

作用：
- 降低判号复杂度；
- 把显点从复杂表达式中剥离出来；
- 将剩余部分交给单调性或放缩处理。

### K26.2 因式分解-十字相乘/分组

触发：二次三项式、高次多项式或分组后能拆成乘积。

作用：把导函数判号转化为区间符号表，常用于三次函数、参数二次式和分段讨论。

### K26.3 因式分解-试根法

触发：三次及以上多项式出现明显整数根或参数根。

流程：先试 `x=±1, ±2, ...` 或题中显点，再做多项式除法降阶，最后继续判号。

## K27. 非对称偏移

> 当对称中心偏移的标准结构失效时，用加权构造替代轴对称构造。

### K27.1 非对称偏移-加权构造

触发：题目比较的两个点不满足 `x1 + x2 = 2x0`，但存在比例或权重关系。

典型构造：
```
F(x)=f(x)-f(kx0-(k-1)x), k != 2
```

用途：处理非等距偏移、加权平均点、非对称双变量比较。关键是先确定权重，再证明构造后的函数单调或恒正/恒负。


```
1. 将表达式变形为 x·eˣ 或 x·ln x 形式
2. 利用 f(x)=x·eˣ 的单调区间判断
3. 代换 x→ln x 得到对偶形式
```

### A3. 和差型构造（eˣ±x 族）
```
1. 将表达式变形为 eˣ±x 或 x±ln x 形式
```

### A4. 双曲型构造（sh/ch 族）

### A5. 不完全对称夹逼

```
1. 向对称结构补项（使两侧表达式共用同一母函数）
2. 用单调性+不等式界定补项范围
3. 完成比较
```

### A6. 朗博-切线复合

## 方法组B：切线操作（策略：切线放缩、公切线双轨、切线计数）

### B1. 切点构造法
```
1. 确定函数凹凸性
2. 选定切点 x₀
3. 写出切线: y = f'(x₀)(x−x₀) + f(x₀)
4. 确定不等号方向（凸↑则 f≥切线，凹↓则 f≤切线）
```

### B2. 斜率构造法
```
1. 从给定斜率 k 反推切点
   - eˣ: x₀ = ln k
   - ln x: x₀ = 1/k
2. 写出对应切线不等式
3. 验证截距是否匹配，不匹配则需要代换调整
```

### B3. 基本切线计算
```
在某点处: 计算 f(x₀), f'(x₀) → y = f'(x₀)(x−x₀) + f(x₀)
过某点外: 设切点(t, f(t)) → 写切线 → 代入给定点 → 解出 t
```

### B4. 公切线代数求法
```
1. 设 f 在 x₁ 处切线，g 在 x₂ 处切线
2. 斜率相等: f'(x₁) = g'(x₂)
3. 截距相等: f(x₁)−x₁f'(x₁) = g(x₂)−x₂g'(x₂)
4. 联立求解 → 解的个数 = 公切线条数
```

### B5. 公切线几何判定法
```
1. 判断两函数凹凸性是否相同
2. 求交点个数
3. 查表（凹凸性×交点个数→公切线条数）
```

### B6. 平行曲线公切线法
```
若 g(x) = f(x−a)−b，则公切线斜率 = b/a
```

### B7. 切线条数区域判定法
```
1. 找到拐点（f''=0）
2. 作拐点处切线
3. 找到渐近线（若有）
4. 切线+渐近线将平面分区 → 查表得每区域切线条数
```

### B8. 包络线判别法
```
1. 设点 P(x₀, y₀)
2. 写出过 P 的切线方程（以切点 t 为参数）
3. 看关于 t 的方程是否有实数解
4. 有解→P 在包络区域内，无解→P 在包络区域外
```

### B9. 切线零点比大小法
```
条件: kx+b ≤ f(x) 恒成立，求 b/k
1. 识别 f 的凹凸性（f''>0=凹=切线在下方）
2. 找到切点 x₀: f'(x₀)=k
3. 写出切线 → b = f(x₀)−k·x₀
4. 比较零点: f 的零点 x₁ 与切线截距 −b/k
```

### F1. 四基底构造法

## 方法组H：放缩与找点（策略：分而治之、放缩取点、保值性分解）

### H1. 保值性余量分析法
```
1. f(x) = h(p(x)) + h(q(x)) + m·φ(x)
2. h(t) ≥ 0 且 h(0)=0
3. φ(x) 与 h(p(x)),h(q(x)) 共零点 → m 必须 = 0
4. 否则 f(x) 在零点附近变号
```

### H2. 上下函数选取法
```
要证 f(x) ≥ g(x):
1. 拆分 f = f₁·f₂·..., g = g₁·g₂·...
2. 分别求 min 和 max
3. 若 f₁_min·f₂_min·... ≥ g₁_max·g₂_max·... 则得证

常见匹配:
eˣ/x ≥ e, ln x/x ≤ 1/e, x·eˣ ≥ −1/e, x·ln x ≥ −1/e
```

### H3. 放缩取点标准链
```
1. f'(x)=0 → 确定极值点 x₀
2. 验证 f(x₀) < 0（必要条件）
3. 左侧: 找 m < x₀ 使 f(m) > 0（放缩为可解方程）
4. 右侧: 找 n > x₀ 使 f(n) > 0（同样放缩）
5. f(m)·f(n) < 0 → 两个零点存在
```

### H4. 等效零点法
```
口诀: 主题留一半，客体被吊打
1. 提取公因式（如 e^{x/2}）
2. 将剩余部分中"客体"（增长慢的项）放缩为常数
3. 求解放缩后的可解方程
```

### H5. 主客体分析法
```
1. 识别"主体"（增长最快的项，主导正负）
2. 识别"客体"（增长慢的项，被放缩控制）
3. 在主体主导的区间，用客体放缩来找点
```

### H6. 极值点偏移取点法
```
1. 利用三阶导符号判定偏移方向
2. 若极值点右偏 → x₂ > 2x₀−x₁ → 用 2x₀−x₁ 作为 x₂ 的界
3. 结合这个界进行放缩取点
```

### H7. 二分法升级精度
```
取点后若精度不够 → 在已找到的区间内再用二分法收紧界
```

## 方法组I：探路（策略：端点效应、极点效应、隐点代换）

### I1. 端点效应标准流程
```
1. f(x) ≥ 0 在 [a,b] 恒成立 → 代入 x=a, x=b 得必要条件
2. 假设参数超出必要条件范围 → 找反例点（矛盾取点）
3. 在必要条件范围内验证充分性
```

### I2. 端点探路+矛盾取点
```
1. 端点代入 → 参数候选范围
2. 取参数超出范围 → 找一个具体 x₁ 使 f(x₁) < 0
3. 因此参数必须在候选范围内
```

### I3. 极点效应流程
```
1. f(x) ≥ 0 且 f(x₀)=0 → x₀ 是最小点 → f'(x₀)=0
2. f'(x₀)=0 → 解出参数候选值
3. 代入验证充分性
```

### I4. 双参数极点效应
```
1. f(x₀)=0 且 f'(x₀)=0 → 两个方程
2. 若有两个参数 → 联合求解
3. 若有一个参数 → 一个方程确定参数，另一个用于验证
```

### I5. 极点效应失效分析
```
f'(x₀)=0 但 f''(x₀)=0:
→ 分析 f'''(x₀): ≠0 → 拐点（失效），=0 → 继续到四阶
替代: 转端点效应 / 分区间讨论 / 泰勒局部近似
```

### I6. 高阶导数判定极值
```
逐阶求导直到第一个非零导数:
偶数阶 → 极值（>0极小，<0极大）
奇数阶 → 拐点
```

### I7. 隐零点代换 — 初高分流
```
1. 证明隐零点 x₀ 存在（介值定理+放缩取点）
2. f'(x₀)=0 → eˣ⁰ = φ(x₀) 等关系
3. 将超越项替换为代数项 → 消去超越函数
4. 继续分析
```

### I8. 隐零点代换 — 参变分离
```
1. f'(x₀)=0 → a = ψ(x₀)
2. 参数 a 表达为 x₀ 的函数
3. 在 x₀ 的值域上求 a 的范围
```

### I9. 插值放缩法
```
当两个隐零点需要比较大小时:
1. 分别放缩两个隐零点到可计算的值
2. 在两者之间插入中间值
3. 完成比较
```

## 方法组J：双变量处理（策略：比值/差值代换、对称化构造、切割线夹、拟合替代、主元法）

### J1. 比值代换法
```
1. 设 t = x₁/x₂（通常 0<t<1 或 t>1）
2. 用 f(x₁)=f(x₂) 消去 x₁（或 x₂），表达为 t 的函数
3. 对 t 的单变量函数求导分析
```

### J2. 差值代换法
```
1. 设 d = x₁−x₂
2. 用 f(x₁)=f(x₂) 消去一个变量
3. 转化为 d 的函数分析
```

### J3. 对称化构造法（极值点偏移）
```
1. 构造 F(x) = f(x) − f(2x₀−x)
2. 分析 F(x) 在 x₀ 两侧的符号
3. 若 F(x₂) > 0 → f(x₂) > f(2x₀−x₂)
4. 利用单调性: x₁ > 2x₀−x₂ → x₁+x₂ > 2x₀
```

### J4. ALG 不等式应用
```
1. 由 f(x₁)=f(x₂) 导出等式关系
2. 代入 ALG: √(x₁x₂) < (x₁−x₂)/(ln x₁−ln x₂) < (x₁+x₂)/2
3. 变形为目标不等式
```

### J5. 切割线夹法
```
1. 在零点处作切线 → 切线交水平线于 x₃, x₄
2. |x₂−x₁| < |x₄−x₃|（切线夹，上界）
   或 |x₂−x₁| > |x₄−x₃|（割线夹，下界）
3. x₃, x₄ 可精确计算（线性/二次方程的根）
```

### J6. 拟合替代法
```
1. 构造拟合函数 g(x)（二次/飘带/帕德），与 f(x) 在某点处匹配
2. 用 g 的零点/极值近似 f 的零点/极值
3. 利用 g 的简单形式直接计算
```

### J7. 主元选择法
```
1. 判断哪个变量地位简单（求导后表达式简化）
2. 以该变量为主元，另一变量视为参数
3. 对主元求导 → 得出关于主元的结果
4. 再对参数讨论（或交换主元重复）
```

## 方法组K：数列代换（策略：同构归约、切线放缩在数列中的应用）

### MK1. 数列代换法
```
根据不等式形式选择合适的代换:
x = 1/n        →  标准切线放缩型
x = n/(n+1)    →  接龙型裂项
x = (2n+1)/(2n−1) → 帕德逼近型
x = 1+1/n      →  飘带放缩型
```

### MK2. 接龙型裂项法
```
1. 用切线/飘带不等式对通项放缩
2. 构造可裂项的形式: a_n − a_{n+1}
3. 累加（正负抵消）求和
```

### MK3. 隔项相消法
```
1. 放缩后构造隔项可消的形式
2. 累加后只剩首尾项
```

### MK4. 等比放缩构造法
```
1. 用指数不等式构造等比形式的放缩
2. 等比求和 → 得到最终上/下界
```

## 方法组L：三角处理（策略：各种策略在三角函数上的适配）

### L1. 分区间讨论法
```
1. 利用三角函数的周期性/有界性划分区间
2. 在每个子区间上逐段分析单调性/符号
3. 汇总得到全局结论
```

### L2. 三角放缩代入法
```
1. 根据精度需求选择三角放缩式（sin x ≤ x, sin x ≥ x−x³/6 等）
2. 代入原表达式替代三角函数
3. 对替代后的代数表达式分析
```

### L3. 和差化积+双变量法
```
1. 对三角双变量表达式用和差化积
2. 乘积形式分离变量 → 转化为单变量问题
3. 或结合主元法处理
```
