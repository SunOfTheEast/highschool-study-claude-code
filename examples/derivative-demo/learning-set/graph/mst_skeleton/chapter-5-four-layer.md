# 第五章 数形结合 — 四层框架提取

## 定位

第五章引入一种**新的思想**——数形结合：代数结构与几何图像是同一数学对象的两种语言，解题者可以在两者间自由翻译。在这一思想下，派生出若干个策略，每个策略内部包裹了特定的结构识别。

本章不引入新的知识（弹药），全在复用 Ch1-Ch4 的工具。

---

## 思想层（新增）

### 思想5：数形结合

**陈述**：函数表达式和函数图像是同一数学对象的不同表示。不等式 ⇔ 位置关系、方程 ⇔ 交点、最值 ⇔ 距离。

**为什么成立**：笛卡尔坐标系建立了代数与几何的双射——每一个方程对应一条曲线，每一个不等式对应一个区域。

**推出的策略**：下面 6 个策略全部源于这个思想。

---

## 策略层 + 包裹的结构识别

### 策略J：图像交点法

**路径**：方程 f(x)=0 有 N 个解 → y=f(x) 与 x 轴有 N 个交点 → 画图数交点

**包裹的结构识别**：

| 子策略 | 何时触发 | 具体操作 |
|--------|---------|---------|
| 参变分离 | 参数可以完全移到等式一侧 | 改写 f(x,a)=0 为 g(x)=h(a)，画 g(x) 图像，看与水平线 y=h(a) 的交点个数 |
| 参变半分离 | 参数不能完全分离，但可以部分分离 | 改写为 g₁(x)=g₂(x,a)，画两条曲线，看交点 |
| 模块函数分析 | 含绝对值或分段定义的函数 | 分段画图，逐段分析零点 |
| 嵌套函数零点 | f(f(x))=0 型 | 外层零点 f(t)=0 → t₁,t₂,... → 内层 f(x)=tᵢ 的解个数 |

**关键识别**：题目问"零点个数"或"方程有几个实根"时触发。先看参变能否分离（分离后画水平线最简单），不能分离则画两条曲线。

---

### 策略K：图像位置法（包裹性）

**路径**：不等式恒成立 → 一条曲线的图像始终在另一条的上方（或下方）

**包裹的结构识别 — 量词到图像位置的翻译表**：

| 量词条件 | 图像含义 | 等价条件 |
|---------|---------|---------|
| ∀x₁,∀x₂: f(x₁) > g(x₂) | f 的图像整体在 g 上方 | f_min > g_max |
| ∀x₁, ∃x₂: f(x₁) > g(x₂) | f 的最低点仍高于 g 的最低点 | f_min > g_min |
| ∃x₁, ∀x₂: f(x₁) > g(x₂) | f 存在一个点高于 g 的所有值 | f_max > g_max |
| ∀x₁∈D, ∃x₂∈D: f(x₁)=g(x₂) | g 的值域被 f 的值域包裹 | f_min < g_min 且 f_max > g_max |

**关键识别**：题目出现 ∀ 和 ∃ 的嵌套组合 + 恒成立/能成立 = 立即触发包裹性翻译。不需要分析函数细节，直接比较最值。

---

### 策略L：距离几何化

**路径**：曲线上动点的最短距离 → 作平行切线 → 距离 = 两平行线间距

**包裹的结构识别**：

| 子策略 | 触发条件 | 操作 |
|--------|---------|------|
| 平行切线法 | |PQ| 的最小值，Q 在直线上 | 在曲线上找斜率和直线相同的点（切点），计算点到直线距离 |
| 反函数水平距离 | f(a)=g(b) 求 a-b 的最值 | 取反函数：a-b = f⁻¹(t)-g⁻¹(t)，转化为单变量函数最值 |
| 朗博+切线复合距离 | 函数含 axeˣ-ln(ax) 类结构 | 先用朗博同构放缩出切线，再做距离 |

**关键识别**：题目给"P、Q 分别是 f、g 上的动点，求 |PQ| 的最小值"→ 触发距离几何化。

---

### 策略M：切线零点比大小

**路径**：kx+b ≤ f(x) 恒成立 → kx+b 是 f 的下方切线 → 比较两者的 x 截距

**包裹的结构识别**：

```
f(x) 为凹函数 (f''>0) → kx+b 是切线时不等式最紧
→ 切点处满足: f'(x₀)=k, f(x₀)=kx₀+b
→ x 截距: 切线截距 = -b/k, 曲线零点 = x₁
→ 几何关系: x₁ ≤ -b/k (凹函数切线在下方)
→ 代数结论: b/k 满足不等式约束
```

对称地，f 为凸函数时方向反转。

**关键识别**：题目给"kx+b ≤ f(x) 恒成立，求 b/k"或"求 ab"→ 触发切线零点比大小。识别凹/凸性是关键——f''>0 = 凹 = 切线在下方；f''<0 = 凸 = 切线在上方。

**衍生：双参数乘积/比值**：
- 指数切线找点：eˣ ≥ kx+b → 切点 x₀=ln k，b = k(1-ln k) → ab ≤ e/2
- 对数切线找点：ln x ≤ kx+b → 切点 x₀=1/k，b = -1-ln k → ab ≤ 1/e

---

### 策略N：乘积型探路

**路径**：f(x)g(x) ≥ 0 恒成立 → f 和 g 必须同号 → 它们的零点必须对齐

**包裹的结构识别**：

| 子策略 | 触发条件 | 操作 |
|--------|---------|------|
| 单调函数共零点 | f 和 g 都在 (0,+∞) 上单调递增 | 两者必须有相同的零点 → 联立零点方程 → 解出参数关系 |
| max{g,h} ≤ m 型 | 两个函数分别 ≤ 同一个常数 | 等价于 max(g_max, h_max) ≤ m |
| g_max ≤ m ≤ h_min 型 | 一侧 ≤ 常数 ≤ 另一侧 | g 的上界 ≤ h 的下界 → 函数包裹关系 |

**关键识别**：题目出现 (ax-1)(x²+bx-1) ≥ 0 在 (0,+∞) 恒成立 → 两个因式同号 → 触发乘积型探路。

---

### 策略O：指数和差交点法

**路径**：比较 aˣ+bˣ 和 cˣ → 两条曲线在特定 x 处有交点 → 交点由代数关系决定

**包裹的知识结构**：

| 代数关系 | 交点横坐标 | 交点纵坐标 |
|---------|----------|----------|
| a+b = c | x = 1 | y = c |
| a²+b² = c² | x = 2 | y = c² |

交点是"拐点"——交点两侧大小关系翻转。x 越大，cˣ 对 aˣ+bˣ 的优势越明显（因为 c > a, c > b）。

**关键识别**：题目出现 aˣ+bˣ 和 cˣ 的比较，且 a+b=c 或 a²+b²=c² → 触发指数和差交点法。画图，交点两侧直接读出大小关系。
