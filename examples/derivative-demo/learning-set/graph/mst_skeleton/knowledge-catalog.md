## K2. 放缩公式谱系

> 按函数分组，精度从低到高排列。解题时从低精度开始尝试，精度不够时升级。

### 指数函数 eˣ

| 不等式 | 等号条件 | 精度 | 适用场景 |
|--------|---------|------|---------|
| eˣ ≥ x+1 | x=0 | ★☆☆ 1阶 | 基础放缩，几乎处处适用 |
| eˣ ≥ ex | x=1 | ★★☆ 1阶切点平移 | 需要切点在 x=1 时 |
| eˣ ≥ eˣ⁰(x−x₀+1) | x=x₀ | ★★☆ 1阶任意切点 | 切点可选时的通式 |
| eˣ ≥ ex + (x−1)² | x=0, x=1 | ★★★ 2阶 | 需要二次精度 |
| eˣ ≥ (e/2)x² + e/2 | x=1 (x≥1) | ★★★ 二次下界 | x≥1 时更紧的下界 |
| eˣ ≥ 1+x+x²/2 | x=0 | ★★★ 2阶泰勒 | 局部高精度 |
| eˣ ≥ 1+x+x²/2+x³/6 | x=0 | ★★★★ 3阶泰勒 | 极高精度估值 |
| eˣ/xⁿ ≥ (e/n)ⁿ | x=n | ★★☆ 分式型 | 含 eˣ/xⁿ 的最值问题 |

### 对数函数 ln x / ln(1+x)

| 不等式 | 等号条件 | 精度 | 适用场景 |
|--------|---------|------|---------|
| ln x ≤ x−1 | x=1 | ★☆☆ 基础 | 对数万能放缩 |
| ln(x+1) ≤ x | x=0 | ★☆☆ 平移版 | 零点在 0 附近 |
| ln x ≥ 1 − 1/x | x=1 | ★★☆ 倒数界 | 需要下界时 |
| ln x ≥ 2(x−1)/(x+1) | x=1 (x>1) | ★★★ 帕德下界 | 比倒数界更紧 |
| ln x ≤ (x−1/x)/2 | x=1 (x>1) | ★★★ 飘带上界 | 比基础切线更紧的上界 |
| ln x ≤ √x − 1/√x | x=1 (x≥1) | ★★★ 根式上界 | 含 √x 的场景 |
| ln x ≤ 4(√x−1)/(√x+1) | x=1 | ★★★★ 根式帕德界 | 比根式上界更紧 |

| 不等式 | 等号条件 | 精度 | 适用场景 |
|--------|---------|------|---------|
| sin x ≤ x ≤ tan x | x=0 | ★☆☆ 1阶 | 基础三角放缩 |
| cos x ≤ 1 | x=2kπ | ★☆☆ 平凡上界 | 几乎处处可用 |
| cos x ≥ 1−x²/2 | x=0 | ★★☆ 2阶 | 需要 cos 下界 |
| sin x ≥ x−x³/6 | x=0 | ★★★ 3阶 | 需要 sin 下界 |
| tan x ≥ x+x³/3 | x=0 | ★★★ 3阶 | 需要 tan 更强下界 |

### 分式与幂函数

| 不等式 | 条件 | 精度 | 来源 |
|--------|------|------|------|
| 1/(1−x) ≥ 1+x | \|x\|<1, x≥0 | ★☆☆ | 几何级数 |
| 1/(1−x) ≥ 1+x+x² | \|x\|<1, x≥0 | ★★☆ | 几何级数 |
| 1/(1+x) ≥ 1−x | \|x\|<1, x≥0 | ★☆☆ | 交错级数 |
| (1+x)ᵅ ≥ 1+αx | α∈(0,1), x≥0 | ★☆☆ | 伯努利不等式 |
| (1+x)ᵅ ≥ 1+αx+α(α−1)x²/2 | 取决于 α,x | ★★☆ | 二项展开 |

### 根式函数

| 不等式 | 等号条件 | 精度 | 适用场景 |
|--------|---------|------|---------|
| √(x+1) ≤ (√2/4)(x+3) | x=1 | ★★☆ 切线 | √(x+1) 在 x=1 处的切线放缩 |
| √x ≤ (x+1)/2 | x=1 | ★☆☆ 均值 | 基本根式上界 |

### 使用规则

1. **先粗后精**：能用 1 阶的不上 2 阶，计算量差距大
2. **注意方向**：放缩需要的是上界还是下界？选错方向直接废
3. **注意定义域**：飘带和帕德要求 x>1；ln(1+x) 展开在 −1<x≤1 收敛
4. **取等条件**：同一道题中多个放缩同时取等 → 往往就是答案所在
5. **割线放缩**：切线给出单侧界（由凹凸性决定方向），割线可在特定区间给出反向界。过曲线上两点的割线，在区间内部位于曲线的某一侧

## K3. 泰勒展开式与麦克劳林公式（理论）

> 具体不等式已移至 K2 放缩公式谱系。此处保留泰勒公式的理论框架和余项分析。

### 通用公式

麦克劳林公式（x₀=0 的特例）：
```
f(x) = f(0) + f'(0)x + f''(0)x²/2! + f'''(0)x³/3! + ... + f⁽ⁿ⁾(0)xⁿ/n! + Rₙ(x)
```
Rₙ(x) 为佩亚诺余项：Rₙ(x) = o(xⁿ)，即比 xⁿ 更高阶的无穷小。

### 余项符号规则（关键）

**截断后余项的符号决定不等式方向**。对拉格朗日余项：
- 若余项 ≥ 0 → 展开式为下界（≥）
- 若余项 ≤ 0 → 展开式为上界（≤）
- 凹凸性是其特例：凸函数的一阶泰勒余项 ≥ 0 → f(x) ≥ 切线

**实用判定**：展开到奇数阶和偶数阶交替时，不等号方向交替。例如 ln(1+x) 展开到奇数次方为正、偶数次方为负，所以交替给出上下界。

### 常用展开完整表

#### eˣ（全实数域，凸函数）
| 展开式 | 不等式 | 等号 | 精度 |
|--------|--------|------|------|
| eˣ = 1 + x + x²/2! + x³/3! + x⁴/4! + ... | — | — | 精确 |
| 截断到 1 阶 | eˣ ≥ 1+x | x=0 | 1阶 |
| 截断到 2 阶 | eˣ ≥ 1+x+x²/2 | x=0 | 2阶 |
| 截断到 3 阶 | eˣ ≥ 1+x+x²/2+x³/6 | x=0 | 3阶 |

#### ln(1+x)（x>−1，凹函数，不等号交替）
| 展开式 | 不等式 | 等号 | 范围 |
|--------|--------|------|------|
| ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + ... | — | — | −1<x≤1 |
| 截断到 1 阶 | ln(1+x) ≤ x | x=0 | x>−1 |
| 截断到 2 阶 | ln(1+x) ≥ x−x²/2 | x=0 | x>−1 |

#### sin x（全实数域，奇函数）
| 展开式 | 不等式 | 等号 |
|--------|--------|------|
| sin x = x − x³/3! + x⁵/5! − x⁷/7! + ... | — | — |
| 截断到 1 阶 | sin x ≤ x (x≥0) | x=0 |
| 截断到 3 阶 | sin x ≥ x−x³/6 (x≥0) | x=0 |

#### cos x（全实数域，偶函数）
| 展开式 | 不等式 | 等号 |
|--------|--------|------|
| cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + ... | — | — |
| 截断到 0 阶 | cos x ≤ 1 | x=2kπ |
| 截断到 2 阶 | cos x ≥ 1−x²/2 | x=0 |

#### 1/(1−x)（|x|<1，几何级数）
```
1/(1−x) = 1 + x + x² + x³ + ... (|x|<1)
```
| 截断 | 不等式 (x≥0) |
|------|------------|
| 1阶 | 1/(1−x) ≥ 1+x |
| 2阶 | 1/(1−x) ≥ 1+x+x² |

#### 1/(1+x)（|x|<1，交错级数）
```
1/(1+x) = 1 − x + x² − x³ + ... (|x|<1)
```
| 截断 | 不等式 (x≥0) |
|------|------------|
| 1阶 | 1/(1+x) ≤ 1 （trivial）；1/(1+x) ≥ 1−x |
| 2阶 | 1/(1+x) ≤ 1−x+x² |

#### (1+x)ᵅ（|x|<1，二项展开）
```
(1+x)ᵅ = 1 + αx + α(α−1)x²/2! + α(α−1)(α−2)x³/3! + ...
```
常用特例：
- α=1/2: √(1+x) ≈ 1 + x/2 − x²/8 + ...
- α=−1: 退化为 1/(1+x) 的展开
- α=−1/2: 1/√(1+x) ≈ 1 − x/2 + 3x²/8 − ...

**不等号方向**：取决于 α 和 x 的符号。0<α<1 且 x>0 时，截断到 1 阶给出上界。

### 使用指南

1. **选择截断阶数**：所需精度决定。比大小通常 1-2 阶足够，估值问题可能需要 3-4 阶。
2. **确定不等号方向**：奇偶阶交替则方向交替；单一符号则查凹凸性或余项。
3. **注意收敛域**：ln(1+x) 仅在 −1<x≤1 收敛；1/(1±x) 仅当 |x|<1。

## K10. 原函数-导函数对称性对应

| 定理 | 内容 |
|------|------|
| 定理1 | f 关于 x=a 对称 ⇔ f' 关于 (a,0) 中心对称 ⇔ a 是 f 极值点 |

- f 有一轴一中心 → f 周期=4|a−b|

## K13. 均值不等式族

### 对数均值不等式 (ALG)
若 0 < x₁ < x₂，则：
```
√(x₁x₂) < (x₁−x₂)/(ln x₁ − ln x₂) < (x₁+x₂)/2
```
等号仅当 x₁=x₂。左侧 = 几何平均，右侧 = 算术平均。

**变体**：
- 反向型（加法原理）：不等号反向使用，构造反向约束
- 常数项调整型：引入参数调整到目标形式
- 根号型：√(ALG)，与三角放缩结合用于偏移问题

### 指数均值不等式
```
e^{(x₁+x₂)/2} < (eˣ¹−eˣ²)/(x₁−x₂) < (eˣ¹+eˣ²)/2  (x₁≠x₂)
```

### 阿达玛积分不等式
对凸函数 f，有：
```
f((a+b)/2) ≤ (1/(b−a)) ∫ₐᵇ f(x) dx ≤ (f(a)+f(b))/2
```
在极值点偏移中用于构造积分形式的上下界。

## K17. 比大小规则

### aᵇ vs bᵃ
令 f(x)=ln x/x，f 在 (0,e)↑，(e,+∞)↓。
- a,b > e 时：a>b ⇔ aᵇ < bᵃ（大指小底）
- a,b < e 时：a>b ⇔ aᵇ > bᵃ

### 糖水不等式
a,b,c > 0, a < b → a/b < (a+c)/(b+c)

### (a−x)^(a+x)、a^a、(a+x)^(a−x) 比较
由函数 f(t) = (a−t)^(a+t) 的单调性（通过 ln x/x 分析），三者存在确定的大小序。a 足够小时结论不同，需结合 f(x)=ln x/x 在 (0,e)↑、(e,+∞)↓ 的单调性判断。

## K23. 牛顿迭代法

**公式**：
```
x_{n+1} = x_n − f(x_n)/f'(x_n)
```

**几何意义**：过 (x_n, f(x_n)) 作曲线的切线，切线与 x 轴交点的横坐标即为 x_{n+1}。

**收敛速度**：二次收敛——每步有效数字翻倍（前提：初始值足够接近真根且 f' 在根附近不为零）。

**使用场景**：
- 方程无法解析求解时，用牛顿法逼近数值解
- 高考中通常以"阅读材料+填空"形式考查，给初始值和迭代步骤
- 与放缩取点中的"二分法升级精度"互补：牛顿法收敛快但需要导数，二分法普适但收敛慢

## K24. 根式函数处理技巧

> √x、√(x+1)、√(x²+1) 与 ln x 或 eˣ 的组合，典型的浙江卷风格。不是独立题型——解法落在已有策略中，以下为根式特有的操作技巧。

### 代换降次
```
设 t = √x → x = t² → ln x = 2ln t → 根式消失
设 t = √(x+1) → x = t²−1
```
触发：√x 和 ln x 共现 → 代换后求导表达式大幅简化。

### 根式因式分解
求导后表达式含 √(x+1)，设 u = √(x+1) 作为整体变量进行因式分解。例：`f'(x) = ((2u+1)(u−2))/(4x·u)`，符号仅取决于 u−2。

### √(x²+1) 型有理化
```
(√(x²+1) − x)(√(x²+1) + x) = 1
→ √(x²+1) − x = 1/(√(x²+1) + x)
```
常用于将差式转化为分式，便于求导或放缩。

### 反双曲正弦
```
ln(x + √(x²+1)) = arsh(x)，导数 = 1/√(x²+1)
```
看到 `x + √(x²+1)` 和 ln 组合，直接识别为反双曲函数。

### 根式切线放缩
√(x+1) 也可以做切线放缩（见 K2 根式函数表）。

## K25. 隐点代换体系

当极值点、零点或切点无法显式求出时，把隐点作为变量保留，用 `f'(x0)=0`、`f(x0)=0` 或切线条件建立关系，再消去参数或改写目标式。

| 子标签 | 用途 |
|--------|------|
| K25.1 隐零点代换-消参 | 用隐点方程把参数表示成隐点，再代入目标式化简判号 |
| K25.2 插值放缩法 | 构造中间函数/曲线 `p`，用 `f >= p >= g` 或反向夹逼传递零点、极值或大小关系 |

典型场景：极点效应、隐点探路、整数格点探路、双变量中不可显式求解的极值点比较。

## K28. 代数不等式

主元法、调整法、对称化构造之后的纯代数收尾工具。

常见工具：基本不等式、柯西不等式、Schur 型不等式、轮换对称不等式、多变量平均化/平滑化。

使用边界：只有当核心难点已经被导数、代换或主元降到代数结构时，才标 K28；普通整理不应泛化为 K28。
