# 第一章·第二节 切线函数的基本应用 — 代数结构提取

## 思想定位

切线放缩是导数解题的第二个思想原子（第一个是同构）。它与同构共享同一个底层机制——**代换传播**，但出发点和适用场景不同：

| | 同构 | 切线放缩 |
|---|---|---|
| 起点 | 识别表达式中的 g(e^x)/g(ln x) 对偶 | 识别函数的凹凸性 + 切点 |
| 操作 | 代数变形归约到同一单调函数 | 以切线为界建立不等式 |
| 适用 | 方程/等式 → 单调性比较 | 不等式/范围估计 → 放缩 |

**WHY：切线放缩为什么成立？**

凸函数在其切线上方，凹函数在其切线下方。这是微积分的几何本质，不是技巧。

- e^x 是凸函数 → e^x ≥ 切线（在任意切点）
- ln x 是凹函数 → ln x ≤ 切线（在任意切点）

一条切线不等式通过**变量代换 x → φ(t)** 可以产生无穷多条衍生不等式——这个代换机制与第一节的变换链完全同构。

## 元结构：切线生成 + 代换传播

### 一个不等式，无限衍生

**核心原理**：给定 f(x) 在 x₀ 处的切线 T(x)，若 f 是凸的，则 f(x) ≥ T(x) 对所有 x 成立。对变量 x 做任意保持定义域的代换 x → φ(t)，不等式方向不变。

```
f(x) ≥ T(x)  ──[x → φ(t)]──→  f(φ(t)) ≥ T(φ(t))
```

**例**：e^x ≥ x + 1（切点 x=0），代换 x → x-1 得 e^(x-1) ≥ x，乘以 e 得 e^x ≥ ex（切点 x=1）。

这才有了「两大基本切线式 → 无穷衍生」的格局。所有切线题本质是在考察：**你能不能从题目表达式里认出这是哪个母不等式的哪种代换**。

## 生成器A：指数切线族

### 母不等式
```
eˣ ≥ x + 1    等号当且仅当 x=0
```
几何意义：y = e^x 在点 (0,1) 处的切线为 y = x+1，曲线在切线上方。

### 衍生谱系（切点→斜率→复合）

| 代换 | 结果 | 切点 | 用途 |
|------|------|------|------|
| x → x-1 | eˣ ≥ ex | x=1 | 标准指数放缩 |
| x → x-1, 除以x | eˣ/x ≥ e | x=1 | 分式指数最值 |
| x → x/n-1 | eˣ/xⁿ ≥ (e/n)ⁿ | x=n | eˣ/xⁿ 最值 |
| x → ax-1 | eᵃˣ ≥ ea·x | x=1/a | 含参指数 |
| x → ln x | x ≥ ln x+1 → **ln x ≤ x-1** | x=1 | **→ 生成器B** |

**关键观察**：最后一行说明——对数切线族 ln x ≤ x-1 本身就是指数切线族的一个代换实例。两个生成器并非独立，而是**同源**。

### 指数切线找点：两套体系

**切点构造**（给定切点，推切线方程）：
```
eˣ → 切点 x₀ → 切线 y = eˣ⁰(x - x₀ + 1)
转化为：eˣ ≥ eˣ⁰(x - x₀ + 1)
```
最常用 x₀=0 → eˣ ≥ x+1，x₀=1 → eˣ ≥ ex

**斜率构造**（给定斜率 k，找对应切点和不等式）：
```
eˣ 的切线斜率 = eˣ⁰ = k → x₀ = ln k
切线不等式：eˣ ≥ k(x - ln k + 1)
```
转化为标准形式的关键：识别表达式中的斜率 → 反推切点 → 还原为标准切线不等式。

- 例4-8

## 生成器B：对数切线族

### 母不等式
```
ln x ≤ x - 1    等号当且仅当 x=1
```
几何意义：y = ln x 在点 (1,0) 处的切线为 y = x-1，曲线在切线下方。

**注意**：ln x ≤ x-1 可以从 e^x ≥ x+1 经代换 x → ln x 得到，也可以独立地从 ln x 的凹性直接得到。两条路径等价。

### 衍生谱系

| 代换 | 结果 | 切点 | 用途 |
|------|------|------|------|
| x → x+1 | ln(x+1) ≤ x | x=0 | 平移型 ln 放缩 |
| x → ax | ln(ax) ≤ ax-1 | x=1/a | 含参 ln |
| 除以 x | ln x/x ≤ 1-1/x | — | 分式 ln 上界 |
| x → 1/x | -ln x ≤ 1/x-1 | x=1 | ln 下界 |
| x → e·x | ln x ≤ x-1 变为 ln(ex) ≤ ex-1 | — | 与第一节对接 |

### 对数切线找点：两套体系

**切点构造**：
```
ln x → 切点 x₀ → 切线 y = (x-x₀)/x₀ + ln x₀
转化为：ln x ≤ x/x₀ - 1 + ln x₀
```
最常用 x₀=1 → ln x ≤ x-1

**斜率构造**：
```
ln x 的切线斜率 = 1/x₀ = k → x₀ = 1/k
切线不等式：ln x ≤ kx - 1 - ln k
```

- 例12-17

## 生成器C：朗博-切线复合

### 朗博同构是什么

朗博函数：形如 x·e^x 的结构。核心操作是把乘积 "升入" 指数：

```
x·eˣ = e^(ln x + x)
```

然后对指数部分应用切线不等式。

### 与切线放缩的复合

```
a·e^(ax) ≥ ???  →  ln(a·e^(ax)) = ln a + ax
                 →  需要 ≥ 某个线性表达式
                 →  用 eˣ ≥ ex （即 x → ?? 代换）
```

典型路径：
1. 将 a·e^(ax) 变形为 e^(ax + ln a)
2. 使用 eˣ ≥ x+1 或 eˣ ≥ ex
3. 还原回 a·e^(ax) 的不等式形式

**关键识别特征**：题目中出现 a·e^(ax) ≥ g(x) 且 g(x) 含有 ln x 或 x 的线性组合 → 朗博+切线双重复合。

- 例9-11

## 与第一节的拓扑关系

### 六大函数模型的切线，本质上是两大基本切线的代换实例

第一节的六大函数模型的极值/最值，用切线放缩可以给出一致的解释：

| 六大函数 | 最值 | 切线来源 | 代换路径 |
|---------|------|---------|---------|
| x·e^x | x=-1, min=-1/e | eˣ ≥ ex → 令 x → x+1 | e^(x+1) ≥ e(x+1) → x·eˣ ≥ -1/e |
| x·ln x | x=1/e, min=-1/e | ln x ≤ x-1 → x → ex | ln(ex) ≤ ex-1 → ... |
| x/e^x | x=1, max=1/e | eˣ ≥ ex → x → -x | e^(-x) ≥ -ex+1 → ... |
| ln x/x | x=e, max=1/e | ln x ≤ x-1 → 除以x | ... |
| e^x/x | x=1, min=e | eˣ ≥ ex → 除以x→ | eˣ/x ≥ e |
| x/ln x | x=e, min=e | 类似推导 | ... |

**这意味着第一节的"特殊代数结构识别"和第二节的"切线放缩"，指向的是同一个数学对象——只是从不同角度切入。**

### 变换链在此的运行方式

第一节的变换链：
```
g(eˣ) ↔ g(x) ↔ g(ln x)
```

第二节的变换链：
```
切线(x₀) ──[变量代换]──→ 衍生切线(φ(x₀))
```

**两者的共同核心是"代换传播"**——一条基本事实，通过系统性代换，覆盖全域。区别仅在于第一节的代换对象是函数 g，第二节的代换对象是切点位置和变量。

## 纯操作模式

### 模式1：切点已知 → 直接写不等式

识别特征：题目给出特定的 x₀（如 x=0, x=1），或通过"在某点处"暗示切点。

操作：写出 f(x₀) 和 f'(x₀)，套用凹凸性得到 f(x) ≥ 或 ≤ 切线。

- 例1-3

### 模式2：斜率已知 → 反推切点

识别特征：题目出现 eˣ ≥ kx + b 或 ln x ≤ kx + b 形式。

操作：
1. 从斜率 k 反推切点（eˣ 的斜率=eˣ⁰=k → x₀=ln k；ln x 的斜率=1/x₀=k → x₀=1/k）
2. 验证 b 是否匹配切线的截距
3. 若不匹配，说明需要代换调整

- 例4-8

### 模式3：含参不等式 → 切线临界值

识别特征：a·eˣ ≥ g(x) 或 ln(ax) ≥ h(x)，参数 a 待定。

操作：找到使得切线刚好"贴上"的最紧参数值——此时等号成立（切点处）。

- 例9-11

### 模式4：找点 → 切线的等号条件

识别特征：需要证明存在某个 x 使 f(x) 在特定范围内。

操作：利用切线不等式 f(x) ≥ T(x)，在切点处 f(x₀)=T(x₀)，构造特殊点。

- 例12-17 中的找点部分
