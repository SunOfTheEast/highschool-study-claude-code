# 第二章 导数的切线方程 — 四层框架提取

## 定位

第一章教了**切线放缩**（用切线做不等式）。第二章教**切线的几何与代数体系**——切线的计算、切线条数的判定、公切线的分类。第一章的切线是"工具"，第二章的切线是"研究对象"。

**与第一章的关键连接**：第二章第三节明确指出——"不同构，无导数"。公切线问题最终会归约到六大同构函数。这意味着第二章是第一章武器在切线专题上的集中应用。

## 策略层（新增）

### 策略F：切线计数 — 区域分类法

**路径**：找到拐点（f''=0）→ 作拐点处切线 → 找到渐近线（如果有）→ 切线+渐近线将平面分为若干区域 → 每个区域的切线条数是固定的

**为什么能工作**：凹凸性决定了从一点出发能向曲线作几条切线。拐点是凹凸性的分界点，拐点处的切线是"内外弧"的分界线。渐近线切割了部分"远切线"的存在性。

**适用范围**：三次函数（只有拐点，无渐近线）、含渐近线的函数（如 eˣ/x 类，渐近线 x=0 和 y 方向）

**下属知识**：
- 三次函数4区域表（3/1/1/3）
- 含渐近线函数7区域表

### 策略G：公切线 — 双轨分析

**路径A（代数轨）**：设两个切点 → 斜率相等 → 截距相等 → 两方程联立 → 解的个数 = 公切线条数

**路径B（几何轨）**：判断两曲线的凹凸性是否相同 → 看交点个数 → 类比圆的内/外公切线 → 直接得到公切线条数

**为什么有两条路径**：代数路径是通解但计算量大，几何路径快速但只适用于凹凸性明确的函数对。

**几何类比表**（核心知识）：
| 两曲线凹凸性 | 交点情况 | 类比 | 公切线条数 |
|------------|---------|------|----------|
| 同凹凸 | 无交点（内含） | 小圆内含于大圆 | 0 |
| 同凹凸 | 1个交点（内切） | 两圆内切 | 1（外公切线） |
| 同凹凸 | 2个交点（相交） | 两圆相交 | 2（外公切线） |
| 异凹凸 | 2个交点（相交） | 两圆相交 | 0 |
| 异凹凸 | 1个交点（外切） | 两圆外切 | 1（内公切线） |
| 异凹凸 | 无交点（外离） | 两圆相离 | 2（内公切线） |

**与第一章的桥接**：同凹凸的两曲线，若它们的表达式可以通过同构关联（如 eˣ 与 ln x），公切线问题直接归约到六大同构函数的性质。

## 方法层（新增）

### 方法组5：切线计算与迭代

| 方法 | 步骤 |
|------|------|
| 在某点处的切线 | 1. 计算 f(x₀), f'(x₀) 2. 写出 y = f'(x₀)(x-x₀) + f(x₀) |
| 过某点外的切线 | 1. 设切点 (t, f(t)) 2. 写出切线方程 3. 代入给定点 4. 解出 t（t 的个数 = 切线条数） |
| 牛顿迭代 | 1. 初始值 x₀ 2. 迭代 x_{n+1} = x_n - f(x_n)/f'(x_n) 3. 重复至收敛 |

### 方法组6：公切线求法

| 方法 | 步骤 |
|------|------|
| 代数法 | 1. 设 f 在 x₁ 处切线、g 在 x₂ 处切线 2. 令斜率相等: f'(x₁)=g'(x₂) 3. 令截距相等: f(x₁)-x₁f'(x₁)=g(x₂)-x₂g'(x₂) 4. 联立求解 |
| 平行曲线法 | 若 g(x)=f(x-a)-b，则公切线斜率 = b/a |
| 几何判定法 | 1. 判断两函数凹凸性 2. 求交点个数 3. 查表得公切线条数 |

### 方法组7：包络线判定

| 方法 | 步骤 |
|------|------|
| 包络线判定 | 1. 设点 P(x₀, y₀) 2. 写出过 P 的切线方程（以切点 t 为参数） 3. 看关于 t 的方程是否有实数解 4. 有解 → P 在包络区域内；无解 → P 在包络区域外 |

### 方法组8：指对公切线

| 方法 | 步骤 |
|------|------|
| aˣ 与 log_a x 公切线 | 1. 分析 a 的范围 2. 利用对称性：若存在两条公切线，斜率之积为1 3. 切点满足: x₁ = y₂（基于同构对称） |
| eˣ 与 ln x 公切线 | 切点满足特殊数据关系（利用同构的 x₁ = ln x₂ 性质） |

## 知识层（新增）

### 知识组7：三次函数切线条数区域表

拐点切线将平面分为四个区域：

| 区域 | 位置 | 切线条数 |
|------|------|---------|
| 区域 I, IV | 拐点两侧外弧区域（双外弧） | 3 |
| 区域 II, III | 一内弧一外弧区域 | 1 |
| 拐点 | 对称中心 | 1 |
| 拐点切线上（除拐点） | — | 2 |
| 曲线上（除拐点） | — | 2 |

### 知识组8：含渐近线函数切线条数区域表

拐点切线 + 渐近线将平面分为七个区域：

| 区域 | 位置 | 切线条数 |
|------|------|---------|
| 区域 I, IV | 双外弧 | 3 |
| 区域 II, III | 一内弧一外弧 | 1 |
| 区域 V, VII | 双外弧（被渐近线截断一侧） | 2 |
| 区域 VI | 一内弧一外弧（远切线缺失） | 0 |
| 拐点 | — | 1 |
| 拐点切线上的点 | — | 1（唯一拐点切线） |
| 曲线上（除拐点） | — | 1 |

### 知识组9：公切线条数判定表

见策略G中的几何类比表。

### 知识组10：牛顿迭代

```
x_{n+1} = x_n - f(x_n)/f'(x_n)
```

几何意义：过 (x_n, f(x_n)) 作曲线的切线，切线与 x 轴交点的横坐标即为 x_{n+1}。

二次收敛速度：每步有效数字翻倍。

### 知识组11：aˣ 与 log_a x 的公切线

| a 的范围 | 交点个数 | 公切线条数 |
|---------|---------|----------|
| a > e^(1/e) | 0 | 2（斜率之积为1） |
| a = e^(1/e) | 1（相切） | 1（共切点公切线） |
| 1 < a < e^(1/e) | 3 | 3 |
