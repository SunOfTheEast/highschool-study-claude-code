# 第十/十一章 数列综合 & 三角综合 — 四层框架提取

## 定位

两章都是**应用章**——不引入新思想或新策略，而是将前九章的工具应用于特定领域：
- 第十章：将导数不等式作为放缩工具，应用于数列递推、求和、通项估计
- 第十一章：将导数方法应用于含三角函数的复合题型

---

## 第十章 导数不等式与数列综合

### 核心逻辑

```
导数不等式（前九章武器）
    ↓ 令 x = 1/n, x = n, x = n/(n+1) 等代换
数列不等式
    ↓ 裂项/累加/累乘
数列求和/通项的不等式证明
```

### 四种标准路径

| 路径 | 代换方式 | 典型型 |
|------|---------|--------|
| 切线放缩→求和 | ln(1+1/n) 用切线不等式夹逼 | 1/(n+1) < ln(1+1/n) < 1/n |
| 裂项相消 | 放缩后构造成可裂项的形式 | 接龙型、隔项相消型 |
| 等比放缩 | 放缩后构造成等比数列 | e^(1-n) ≥ (1/n)^n 型 |
| 飘带/帕德→高精度 | 使用飘带或帕德逼近获得更紧的界 | ln n! 的斯特林型估计 |

### 调用关系

```
Ch10 数列综合
  ├── 调用 Ch1 S2 切线不等式（ln(1+x) ≤ x, eˣ ≥ x+1）
  ├── 调用 Ch1 S6 帕德逼近 + 飘带函数（高精度界）
  ├── 调用 Ch6 S1 放缩公式体系
  └── 新增：数列代换技巧（x → 1/n, x → n/(n+1) 等）
```

### 新增内容

全在**方法层**——数列代换的具体操作模式（何时用 1/n，何时用 n/(n+1)，何时用接龙型裂项）。不新增策略或知识。

## 第十一章 三角与导数综合

### 核心逻辑

```
三角函数 + 导数 = 两个"振荡源"的叠加
    ├── 三角函数：周期性、有界性（|sin|≤1, |cos|≤1）
    └── 导数工具：单调性、极值、放缩
```

### 四种场景

| 场景 | 核心挑战 | 应对 |
|------|---------|------|
| 三角+零点 | 周期性导致多零点 | 分区间讨论 + 逐段单调性分析 |
| 三角+恒成立 | 有界性简化参数范围 | 端点/极点效应 + 三角放缩 |
| 三角+数列 | 三角不等式代入数列 | sin(1/n) 的泰勒放缩 |
| 三角+双变量 | 和差化积 + 双变量技巧结合 | 三角恒等式 + 主元法/代换 |

### 关键三角放缩（复用 Ch6）

```
sin x ≤ x ≤ tan x (x ≥ 0)
sin x ≥ x - x³/6
cos x ≥ 1 - x²/2
cos x ≤ 1
```

### 调用关系

```
Ch11 三角综合
  ├── 调用 Ch6 S1 三角放缩公式
  ├── 调用 Ch7/Ch8 端点/极点/隐点效应
  ├── 调用 Ch9 双变量代换策略
  └── 新增：三角恒等式（和差化积、弦切互化）与导数方法的配合
```

### 新增内容

全在**知识层**——三角恒等式在导数语境下的使用方式（和差化积用于双变量、弦切互化用于放缩）。不新增策略。
