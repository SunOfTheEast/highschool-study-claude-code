## 方法层（新增）

### 比大小方法谱系（按精度递增）

| 方法 | 适用场景 | 精度 |
|------|---------|------|
| 同底/同幂 + 中间变量 | 可归一化的幂/对数 | 粗 |
| a^b vs b^a (ln x/x) | 指数位置互换 | 中 |
| 二项式展开 | 接近整数的幂 | 中 |
| 糖水不等式 | 分式型对数 | 中 |
| 六大同构函数 | 可归约到六大函数的值 | 较精 |
| 直线与指数和差交点 | 含 e^x 和 ax+b 的混合 | 较精 |
| 泰勒展开估值 | 接近展开点的值 | 精 |
| 帕德+飘带双侧锁定 | 需要上下界的情况 | 最精 |

**选用逻辑**：先用粗方法排除明显的大小关系，粗方法失效时升级到同构，同构失效时升级到泰勒/帕德夹逼。

## 知识层（新增）

### a^b 与 b^a 比较

```
令 f(x) = ln x / x
f 在 (0,e)↑, (e,+∞)↓
→ 当 a,b > e 时: a > b ⇔ a^b < b^a
→ 当 a,b < e 时: a > b ⇔ a^b > b^a
口诀: 大指小底（大于e看指数，小于e看底数）
```

### 糖水不等式

```
若 a,b,c > 0 且 a < b，则 a/b < (a+c)/(b+c)
通俗: 不饱和糖水加糖后更甜
```

### (a-x)^(a+x)、a^a、(a+x)^(a-x) 比较

由函数 f(t) = (a-t)^(a+t) 的单调性（通过 ln x/x 分析）得到三者的大小序。
