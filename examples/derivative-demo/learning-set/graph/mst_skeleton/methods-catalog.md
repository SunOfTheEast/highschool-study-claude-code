## 方法组A：同构构造（策略：同构归约）

### A1. 变换链操作
```
1. 识别表达式中的 g(eˣ) 或 g(ln x) 结构
2. 将一侧变量代换为另一侧（eˣ→x 或 x→ln x）
3. 利用 g 的单调性比较大小
```

### A2. 乘积型构造（xeˣ 族）
```
1. 将表达式变形为 x·eˣ 或 x·ln x 形式
2. 利用 f(x)=x·eˣ 的单调区间判断
3. 代换 x→ln x 得到对偶形式
```

### A3. 和差型构造（eˣ±x 族）
```
1. 将表达式变形为 eˣ±x 或 x±ln x 形式
2. 利用 h(x)=eˣ±x 的单调性
```

### A4. 双曲型构造（sh/ch 族）
```
1. 识别 eˣ 和 e⁻ˣ 共现
2. 转化为 sh(x)=(eˣ−e⁻ˣ)/2 或 ch(x)=(eˣ+e⁻ˣ)/2
```

### A5. 不完全对称夹逼
```
1. 向对称结构补项（使两侧表达式共用同一母函数）
2. 用单调性+不等式界定补项范围
3. 完成比较
```

### A6. 朗博-切线复合
```
1. 将 a·eᵃˣ 改写为 eᵃˣ⁺ˡⁿᵃ（朗博同构）
2. 应用指数切线不等式（eˣ≥ex）
3. 还原为原参数的不等式
```

## 方法组B：切线操作（策略：切线放缩、公切线双轨、切线计数）

### B1. 切点构造法
```
1. 确定函数凹凸性
2. 选定切点 x₀
3. 写出切线: y = f'(x₀)(x−x₀) + f(x₀)
4. 确定不等号方向（凸↑则 f≥切线，凹↓则 f≤切线）
```

### B2. 斜率构造法
```
1. 从给定斜率 k 反推切点
   - eˣ: x₀ = ln k
   - ln x: x₀ = 1/k
2. 写出对应切线不等式
3. 验证截距是否匹配，不匹配则需要代换调整
```

### B3. 基本切线计算
```
在某点处: 计算 f(x₀), f'(x₀) → y = f'(x₀)(x−x₀) + f(x₀)
过某点外: 设切点(t, f(t)) → 写切线 → 代入给定点 → 解出 t
```

### B4. 公切线代数求法
```
1. 设 f 在 x₁ 处切线，g 在 x₂ 处切线
2. 斜率相等: f'(x₁) = g'(x₂)
3. 截距相等: f(x₁)−x₁f'(x₁) = g(x₂)−x₂g'(x₂)
4. 联立求解 → 解的个数 = 公切线条数
```

### B5. 公切线几何判定法
```
1. 判断两函数凹凸性是否相同
2. 求交点个数
3. 查表（凹凸性×交点个数→公切线条数）
```

### B6. 平行曲线公切线法
```
若 g(x) = f(x−a)−b，则公切线斜率 = b/a
```

### B7. 切线条数区域判定法
```
1. 找到拐点（f''=0）
2. 作拐点处切线
3. 找到渐近线（若有）
4. 切线+渐近线将平面分区 → 查表得每区域切线条数
```

### B8. 包络线判别法
```
1. 设点 P(x₀, y₀)
2. 写出过 P 的切线方程（以切点 t 为参数）
3. 看关于 t 的方程是否有实数解
4. 有解→P 在包络区域内，无解→P 在包络区域外
```

### B9. 切线零点比大小法
```
条件: kx+b ≤ f(x) 恒成立，求 b/k
1. 识别 f 的凹凸性（f''>0=凹=切线在下方）
2. 找到切点 x₀: f'(x₀)=k
3. 写出切线 → b = f(x₀)−k·x₀
4. 比较零点: f 的零点 x₁ 与切线截距 −b/k
```

## 方法组C：表达式清洁（策略：表达式清洁）

### C1. 对数单身狗
```
1. 识别 g(x)·ln x 结构（g(x) 非平凡）
2. 提出 g(x): g(x) [ln x + h(x)/g(x)]
3. 对括号内部分求导分析
```

### C2. 指对找基友
```
1. 识别 g(x)·eˣ 或 g(x)/eˣ 结构
2. 利用 (g/eˣ)' = (g'−g)/eˣ 简化
3. 选择配对函数 g 使 g'±g 简单
```

## 方法组D：逼近与估值（策略：逼近替代、放缩）

### D1. 泰勒估值法
```
1. 选定展开阶数
2. 写出展开式 + 余项
3. 余项符号→不等式方向
4. 截断计算数值/比较大小
```

### D2. 帕德夹逼法
```
1. 写出泰勒界（一侧）
2. 写出帕德界（另一侧，通常与泰勒反向）
3. 形成双侧夹逼
```

### D3. 飘带夹逼法
```
用飘带不等式 ln x < (x−1/x)/2 与帕德 ln x > 2(x−1)/(x+1) 形成双侧界
```

## 方法组E：比大小（策略：同构归约、逼近替代的应用）

### E1. 同底/同幂化
```
优先将幂/对数转化为同底或同幂 → 利用单调性直接比较
```

### E2. 中间变量传递法
```
找一个介于两者之间的可计算中间值 → 分别比较
```

### E3. aᵇ vs bᵃ 比较法
```
取对数 → 比较 ln a / a 与 ln b / b → 利用 f(x)=lnx/x 的单调性
```

### E4. 二项式展开法
```
对接近整数的幂（如 1.01¹⁰⁰）用二项式定理展开取前几项
```

### E5. 糖水不等式法
```
对分式型对数比较，用 a/b < (a+c)/(b+c)
```

### E6. 直线与指数和差交点法
```
利用 aˣ+bˣ 与 cˣ 在特定 x 处有交点的性质（a+b=c→x=1; a²+b²=c²→x=2）
```

## 方法组F：抽象函数构造（策略：反向构造、对称锁定）

### F1. 四基底构造法
```
看见 f'(x) ± kf(x) → 乘积分因子:

幂基底: f'(x) ± (n/x)f(x) → 乘 x^±n → F(x)=x^±n·f(x)
指基底: f'(x) ± nf(x) → 乘 e^±nx → F(x)=e^±nx·f(x)
三角基底: f'(x)sin x ± f(x)cos x → F(x)=f(x)·sin x 或 f(x)/sin x
对基底: f'(x) + f(x)/(x ln x) → F(x)=f(x)·ln x
```

### F2. 分式反向构造
```
识别表达式是哪个求导公式的产物:
f(x)/(x^m+x^n) → 来自 (f(x)/x^k)'
f'g−fg' → 来自 (f/g)'
f'g+fg' → 来自 (f·g)'
```

### F3. 奇偶性锁定法
```
f' 奇且 f 过某点 → f 偶
f' 偶且 f 过原点 → f 奇
f'(x) + f'(−x) = 0 → f' 奇 → f 偶
```

### F4. 对称-周期互推法
```
f 有两条对称轴 → f 周期 = 2|a₁−a₂|
f 有两个对称中心 → f 周期函数
f 有一轴一中心 → f 周期 = 4|a−b|
```

## 方法组G：图像分析（策略：交点法、位置法、距离几何化）

### G1. 参变分离法
```
1. 改写 f(x,a)=0 为 g(x)=h(a)
2. 画 y=g(x) 图像
3. 看与水平线 y=h(a) 的交点个数
```

### G2. 参变半分离法
```
1. 改写为 g₁(x)=g₂(x,a)
2. 画两条曲线
3. 数交点
```

### G3. 嵌套函数零点法
```
口诀: 内函数横着走，外函数竖着走
1. 令 t=g(x)，分析 y=f(t) 的零点 t₁,t₂,...
2. 将 t₁,t₂,... 作为水平线，看与 y=g(x) 的交点
```

### G4. 包裹性分析法
```
1. 翻译量词为最值条件（查K15表格）
2. 分别求两个函数的最值
3. 比较
```

### G5. 平行切线距离法
```
1. 在曲线上找与直线斜率相同的点（切点）
2. 计算切点到直线的距离
3. 此即最小距离
```

### G6. 反函数水平距离法
```
条件: f(a)=g(b) 求 a−b 最值
1. 取反函数: a = f⁻¹(t), b = g⁻¹(t)
2. a−b = f⁻¹(t)−g⁻¹(t) → 单变量求最值
```

### G7. 乘积型探路法
```
条件: f(x)g(x) ≥ 0 恒成立
1. 两因式必须同号
2. 若两者均单调递增 → 必须有相同的零点
3. 联立零点方程 → 解出参数关系
```

## 方法组H：放缩与找点（策略：分而治之、放缩取点、保值性分解）

### H1. 保值性余量分析法
```
1. f(x) = h(p(x)) + h(q(x)) + m·φ(x)
2. h(t) ≥ 0 且 h(0)=0
3. φ(x) 与 h(p(x)),h(q(x)) 共零点 → m 必须 = 0
4. 否则 f(x) 在零点附近变号
```

### H2. 上下函数选取法
```
要证 f(x) ≥ g(x):
1. 拆分 f = f₁·f₂·..., g = g₁·g₂·...
2. 分别求 min 和 max
3. 若 f₁_min·f₂_min·... ≥ g₁_max·g₂_max·... 则得证

常见匹配:
eˣ/x ≥ e, ln x/x ≤ 1/e, x·eˣ ≥ −1/e, x·ln x ≥ −1/e
```

### H3. 放缩取点标准链
```
1. f'(x)=0 → 确定极值点 x₀
2. 验证 f(x₀) < 0（必要条件）
3. 左侧: 找 m < x₀ 使 f(m) > 0（放缩为可解方程）
4. 右侧: 找 n > x₀ 使 f(n) > 0（同样放缩）
5. f(m)·f(n) < 0 → 两个零点存在
```

### H4. 等效零点法
```
口诀: 主题留一半，客体被吊打
1. 提取公因式（如 e^{x/2}）
2. 将剩余部分中"客体"（增长慢的项）放缩为常数
3. 求解放缩后的可解方程
```

### H5. 主客体分析法
```
1. 识别"主体"（增长最快的项，主导正负）
2. 识别"客体"（增长慢的项，被放缩控制）
3. 在主体主导的区间，用客体放缩来找点
```

### H6. 极值点偏移取点法
```
1. 利用三阶导符号判定偏移方向
2. 若极值点右偏 → x₂ > 2x₀−x₁ → 用 2x₀−x₁ 作为 x₂ 的界
3. 结合这个界进行放缩取点
```

### H7. 二分法升级精度
```
取点后若精度不够 → 在已找到的区间内再用二分法收紧界
```

## 方法组I：探路（策略：端点效应、极点效应、隐点代换）

### I1. 端点效应标准流程
```
1. f(x) ≥ 0 在 [a,b] 恒成立 → 代入 x=a, x=b 得必要条件
2. 假设参数超出必要条件范围 → 找反例点（矛盾取点）
3. 在必要条件范围内验证充分性
```

### I2. 端点探路+矛盾取点
```
1. 端点代入 → 参数候选范围
2. 取参数超出范围 → 找一个具体 x₁ 使 f(x₁) < 0
3. 因此参数必须在候选范围内
```

### I3. 极点效应流程
```
1. f(x) ≥ 0 且 f(x₀)=0 → x₀ 是最小点 → f'(x₀)=0
2. f'(x₀)=0 → 解出参数候选值
3. 代入验证充分性
```

### I4. 双参数极点效应
```
1. f(x₀)=0 且 f'(x₀)=0 → 两个方程
2. 若有两个参数 → 联合求解
3. 若有一个参数 → 一个方程确定参数，另一个用于验证
```

### I5. 极点效应失效分析
```
f'(x₀)=0 但 f''(x₀)=0:
→ 分析 f'''(x₀): ≠0 → 拐点（失效），=0 → 继续到四阶
替代: 转端点效应 / 分区间讨论 / 泰勒局部近似
```

### I6. 高阶导数判定极值
```
逐阶求导直到第一个非零导数:
偶数阶 → 极值（>0极小，<0极大）
奇数阶 → 拐点
```

### I7. 隐零点代换 — 初高分流
```
1. 证明隐零点 x₀ 存在（介值定理+放缩取点）
2. f'(x₀)=0 → eˣ⁰ = φ(x₀) 等关系
3. 将超越项替换为代数项 → 消去超越函数
4. 继续分析
```

### I8. 隐零点代换 — 参变分离
```
1. f'(x₀)=0 → a = ψ(x₀)
2. 参数 a 表达为 x₀ 的函数
3. 在 x₀ 的值域上求 a 的范围
```

### I9. 插值放缩法
```
当两个隐零点需要比较大小时:
1. 分别放缩两个隐零点到可计算的值
2. 在两者之间插入中间值
3. 完成比较
```

## 方法组J：双变量处理（策略：比值/差值代换、对称化构造、切割线夹、拟合替代、主元法）

### J1. 比值代换法
```
1. 设 t = x₁/x₂（通常 0<t<1 或 t>1）
2. 用 f(x₁)=f(x₂) 消去 x₁（或 x₂），表达为 t 的函数
3. 对 t 的单变量函数求导分析
```

### J2. 差值代换法
```
1. 设 d = x₁−x₂
2. 用 f(x₁)=f(x₂) 消去一个变量
3. 转化为 d 的函数分析
```

### J3. 对称化构造法（极值点偏移）
```
1. 构造 F(x) = f(x) − f(2x₀−x)
2. 分析 F(x) 在 x₀ 两侧的符号
3. 若 F(x₂) > 0 → f(x₂) > f(2x₀−x₂)
4. 利用单调性: x₁ > 2x₀−x₂ → x₁+x₂ > 2x₀
```

### J4. ALG 不等式应用
```
1. 由 f(x₁)=f(x₂) 导出等式关系
2. 代入 ALG: √(x₁x₂) < (x₁−x₂)/(ln x₁−ln x₂) < (x₁+x₂)/2
3. 变形为目标不等式
```

### J5. 切割线夹法
```
1. 在零点处作切线 → 切线交水平线于 x₃, x₄
2. |x₂−x₁| < |x₄−x₃|（切线夹，上界）
   或 |x₂−x₁| > |x₄−x₃|（割线夹，下界）
3. x₃, x₄ 可精确计算（线性/二次方程的根）
```

### J6. 拟合替代法
```
1. 构造拟合函数 g(x)（二次/飘带/帕德），与 f(x) 在某点处匹配
2. 用 g 的零点/极值近似 f 的零点/极值
3. 利用 g 的简单形式直接计算
```

### J7. 主元选择法
```
1. 判断哪个变量地位简单（求导后表达式简化）
2. 以该变量为主元，另一变量视为参数
3. 对主元求导 → 得出关于主元的结果
4. 再对参数讨论（或交换主元重复）
```

## 方法组K：数列代换（策略：同构归约、切线放缩在数列中的应用）

### K1. 数列代换法
```
根据不等式形式选择合适的代换:
x = 1/n        →  标准切线放缩型
x = n/(n+1)    →  接龙型裂项
x = (2n+1)/(2n−1) → 帕德逼近型
x = 1+1/n      →  飘带放缩型
```

### K2. 接龙型裂项法
```
1. 用切线/飘带不等式对通项放缩
2. 构造可裂项的形式: a_n − a_{n+1}
3. 累加（正负抵消）求和
```

### K3. 隔项相消法
```
1. 放缩后构造隔项可消的形式
2. 累加后只剩首尾项
```

### K4. 等比放缩构造法
```
1. 用指数不等式构造等比形式的放缩
2. 等比求和 → 得到最终上/下界
```

## 方法组L：三角处理（策略：各种策略在三角函数上的适配）

### L1. 分区间讨论法
```
1. 利用三角函数的周期性/有界性划分区间
2. 在每个子区间上逐段分析单调性/符号
3. 汇总得到全局结论
```

### L2. 三角放缩代入法
```
1. 根据精度需求选择三角放缩式（sin x ≤ x, sin x ≥ x−x³/6 等）
2. 代入原表达式替代三角函数
3. 对替代后的代数表达式分析
```

### L3. 和差化积+双变量法
```
1. 对三角双变量表达式用和差化积
2. 乘积形式分离变量 → 转化为单变量问题
3. 或结合主元法处理
```
