# 第七章 显点探路 — 四层框架提取

## 定位

第七章引入一种新的策略：**利用可计算的特殊点反推参数范围**。"显点"指的是端点、极值点、已知零点——这些点的函数值或导数值可以直接计算，提供参数的**必要条件**。必要条件锁定参数候选范围后，再验证**充分性**。

这不是新思想（底层是"必要+充分"的逻辑框架），这是新策略。

## 策略层（新增）

### 策略S：端点效应

**路径**：

```
f(x) ≥ 0 在 [a,b] 上恒成立，求参数
    ↓
Step 1: 代入端点 x=a 和 x=b → f(a) ≥ 0, f(b) ≥ 0
        → 得到参数的必要条件（不等式约束）
    ↓
Step 2: 在必要条件限定的参数范围内，验证充分性
        → 证明在此范围内 f(x) ≥ 0 确实对所有 x ∈ [a,b] 成立
```

**为什么端点提供必要条件**：如果 f(x) ≥ 0 对所有 x 成立，那么特例 x=a 和 x=b 也必须成立。这是逻辑必然，不是近似。

**包裹的结构识别**：

| 信号 | 解释 |
|------|------|
| 题目给"在区间上恒成立" | 立即代入端点 |
| f(x) 的表达式中参数可分离 | 端点代入后参数约束直接可解 |
| 端点代入后参数未完全确定 | 需要第二层探路（结合单调性） |

**子策略**：
- **端点探路+矛盾取点**：先由端点得必要条件，再在参数超出此范围时找一个具体的反例点证明矛盾
- **端点探路+指对清洁**：端点代入后表达式含 eˣ/ln x，用 Ch1 §3 的方法清洁后再分析
- **双端点效应**：区间两端都提供约束，结合中间零点模型锁定参数

### 策略T：极点效应

**路径**：

```
f(x) ≥ 0 恒成立，且能找到 x₀ 使 f(x₀) = 0
    ↓
x₀ 是 f 的最小值点 → f'(x₀) = 0
    ↓
f'(x₀) = 0 给出参数方程 → 解出参数候选值
    ↓
代入验证：候选参数下 f(x) ≥ 0 是否确实恒成立
```

**为什么极点提供必要条件**：f(x₀) = 0 且 f(x) ≥ 0 对所有 x 成立，意味着 x₀ 是全局最小值点。可导函数在最小值点的导数为零。

**包裹的结构识别**：

| 信号 | 解释 |
|------|------|
| f(x) ≥ 0 恒成立，且表达式在某个明显的 x₀ 处为零 | x₀ 就是最小点 |
| 常见的 "明显零点"：x=0（因为 e⁰-1=0），x=1（因为 ln 1=0） | 直接令 f'(x₀)=0 |
| 双参数问题 | 极点效应给出两个参数的一个方程，还需第二个条件 |
| 参数在指数/对数里面 | 需要朗博同构辅助化简后才能应用 |

**极点效应失效分析**：
- 当 f'(x₀)=0 但 f''(x₀)=0 时，不能直接判定极值类型 → 需要高阶导数分析
- 当 x₀ 不在定义域内部而在边界时 → 转为端点效应
- 当 f(x₀)=0 但 f'(x₀)≠0（x₀ 穿过而非相切）→ 极点效应不适用

---

### 策略U：极值显点探路

**路径**：

```
函数有多个零点/极值点 → 逐个分析
    ↓
已知一个特殊点（设为 x=1 或 x=a）是极值点
    ↓
在这个点上 f'(1)=0 → 参数关系确定
    ↓
利用这个确定的关系，分析其余零点的位置
```

**关键识别**：题目给"f(x) 有 N 个极值点"，且 f'(x) 可以因式分解出 (x-1) 等显式因子 → 一个极值点是显式的，其余的是隐式的 → 先搞定显式的，再分析隐式的。

## 方法层（新增）

### 端点效应 + 矛盾取点的完整流程

```
1. 令 f(x) ≥ 0，代入端点得必要条件: p ∈ S
2. 假设 p ∉ S，找一个具体 x₁ 使 f(x₁) < 0（矛盾）
3. 证明 p ∈ S 时 f(x) ≥ 0 恒成立（充分性）
```

### 极点效应失效时的应对

```
f'(x₀) = 0 但 f''(x₀) = 0:
  → 分析三阶导 f'''(x₀)
  → 若 f'''(x₀) ≠ 0，x₀ 是拐点而非极值点 → 极点效应失效
  → 若 f'''(x₀) = 0，继续到四阶导...

替代方案:
  → 转向端点效应
  → 转向分区间讨论
  → 用泰勒展开局部近似判断
```

## 知识层（新增）

### 高阶导数与极值判定

| 条件 | 结论 |
|------|------|
| f'(x₀)=0, f''(x₀)>0 | x₀ 是极小值点 |
| f'(x₀)=0, f''(x₀)<0 | x₀ 是极大值点 |
| f'(x₀)=0, f''(x₀)=0, f'''(x₀)≠0 | x₀ 是拐点（无极值） |
| f'(x₀)=0, f''(x₀)=0, f'''(x₀)=0, f⁽⁴⁾(x₀)>0 | x₀ 是极小值点 |

推广：第一个非零导数阶数为偶数 → 极值；为奇数 → 拐点。
