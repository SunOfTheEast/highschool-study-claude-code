# 第一章·第一节 同构函数 — 代数结构提取

## 同构：思想原子

### 定义
同构是将复杂表达式通过代数变形，归约到**同一个单调函数的不同自变量**上，从而将不等式/方程问题转化为单调性比较问题。

### WHY：为什么必须走向同构？—— 阶差原理

当 ln x、x、e^x 三者同时出现在表达式中时：
- 求导一次：ln x → 1/x（仍含超越函数）
- 求导两次：1/x → -1/x²（仍含超越函数）
- **求导永远无法消去超越函数**

e^x、x、ln x 两两之间存在"一阶差"：
- e^x 与 x 之间：e^x 求导仍是 e^x，x 求导后是 1（阶差=1）
- x 与 ln x 之间：x 求导后是 1，ln x 求导后是 1/x（阶差=1）
- e^x、x、ln x 三者共现时阶差为 2，恰好可两两配对

**同构的本质是用代数变形代替求导来消去超越函数**——把 e^x 和 ln x 通过变量代换（x → ln x 或 x → e^x）转化为同一函数的不同输入，利用单调性一步到位。这不是技巧选择，是**结构决定的必然**。

### 全章定位
第一章所有内容围绕**特殊代数结构的识别**展开。同构是其中最大的思想原子，后续各章的综合策略（放缩、分治、找点、显/隐点探路）都建立在对结构的熟练识别之上。

## 元结构：g(e^x) ↔ g(x) ↔ g(ln x) 变换链

这是第一节所有内容的**最底层原理**。任何单调函数 g，在定义域允许的范围内，都存在：

```
g(e^x)  ←→  g(x)  ←→  g(ln x)
```

**若 g 单调递增**，则 g(e^x₁) ≥ g(ln x₂) ⇔ e^x₁ ≥ ln x₂ ⇔ x₁ ≥ ln(ln x₂)。

下面所有代数模式都是这个变换链在不同 g 上的实例化：

| g(x) | g(e^x) | g(ln x) |
|------|--------|---------|
| x·e^x | e^x·e^(e^x) | x·ln x |
| e^x + x | e^(e^x) + e^x | x + ln x |
| e^x - x | e^(e^x) - e^x | x - ln x |
| x·(e^x+1) | 复杂 | (ln x+1)·x |
| (e^x±e^(-x))/2 | 复杂 | 飘带型不等式 |

**这解释了为什么模式A、B、C虽然函数形式不同，但解题逻辑完全一致**——它们共享同一个元结构。

## 纯代数模式

### 模式A：乘积型 (x·e^x 族)

**可识别的视觉特征**：表达式中出现 x·e^(kx) 或 x·ln x 的组合。

母函数：f(x) = x·e^x

#### A1. 基础对偶
```
f(x) = x·e^x     ←→  f(ln x) = x·ln x
```
- f(x)：(-∞,-1)↓ (-1,+∞)↑，x=-1 取极小 -1/e
- f(ln x)：(0,1/e)↓ (1/e,+∞)↑，x=1/e 取极小 -1/e
- 核心恒等式：x·ln x = e^(ln x)·ln x = f(ln x)
- 例1、例2

#### A2. 原点对称型
```
y = x/e^x = x·e^(-x) = -f(-x)   —— f(x) 关于原点对称
对偶：y = ln x / x = -f(-ln x)
```
- x/e^x：x=1 取极大 1/e
- ln x/x：x=e 取极大 1/e
- 例8、例9、例13

#### A3. 分式倒数型
```
y = e^x/x = -1/f(-x)，(x>0)   —— f(x) 的倒数取负后关于原点对称
对偶：y = x/ln x = -1/f(-ln x)，(x>1)
```
- e^x/x：x=1 取极小 e
- x/ln x：x=e 取极小 e
- 例11、例17

#### A4. 幂次推广
```
e^x/x^n = (e^(x/n)/(x/n))^n · (1/n)^n ≥ (e/n)^n   （x=n 取等）
x^n·e^x = (x/n · e^(x/n))^n · n^n
```

---

### 模式B：和差型 (e^x ± x 族)

**可识别的视觉特征**：表达式中出现 e^x 与 x 的加减，或 x 与 ln x 的加减。

#### B1. 和型
```
h(x) = e^x + x  —— 全局单调递增
h(ln x) = x + ln x  —— 同样全局单调递增
```
- 例15、例16

#### B2. 差型
```
h(x) = e^x - x ≥ 1  —— (-∞,0)↓ (0,+∞)↑，x=0 取最小1
h(ln x) = x - ln x ≥ 1  —— (0,1)↓ (1,+∞)↑，x=1 取最小1
```
- 例9、例12

#### B3. 差型的倒数变体
```
1/x + ln x = 1/x - ln(1/x) = h(ln(1/x))
```
在 (0,1)↓，(1,+∞)↑

---

### 模式C：双曲型 ((e^x ± e^(-x))/2 族)

**可识别的视觉特征**：表达式同时包含 e^x 和 e^(-x)，或出现 (x - 1/x) 类结构。

```
sh(x) = (e^x - e^(-x))/2  （双曲正弦，奇函数，单调递增）
ch(x) = (e^x + e^(-x))/2  （双曲余弦，偶函数，(0,+∞)单调递增）
```

**飘带函数是双曲正弦在 ln 下的投影**：
```
ln x < (1/2)(x - 1/x)，x > 1
     = sh(ln x)
```
这意味着飘带不等式本质上是对 sh(x) 在 x = ln t 处的应用——再次印证元结构 `g(e^x) ↔ g(ln x)`。

## 导出性质：零点关联

这是**元结构施加于特定 g 时自然产生的推论**，不是独立的结构。

### 核心机制

当 h(x) 与 h(ln x) 取相同函数值时：
```
h(x₁) = h(ln x₂)  →  x₁ = ln x₂  （在各自单调区间内）
```
这是元结构 `x₁ ↔ ln x₂` 的直接后果。

### 差值函数 → 等差
```
取 h(x) = e^x - x
h(x) 与 h(ln x) = x - ln x 的四条交点 x₁,x₂,x₃,x₄ 满足：
x₁ + x₄ = x₂ + x₃
```
- 例21（2022新高考1 — 三交点成等差数列）

### 比值函数 → 等比
```
取 h(x) = e^x/x
h(x) 与 h(ln x) = x/ln x 的四条交点满足：
x₁·x₄ = x₂·x₃
```
- 例19（三零点：x₁·x₃ = x₂²）
- 例22（上海嘉定2024 — 三交点成等比数列）

## 非对称情形：不完全对称 + 夹逼

当表达式在 e^x 侧和 ln x 侧**不完全对称**时——这是广泛存在的常态而非特例。

**典型模式**：
```
要证：A(e^x) ≥ B(ln x)
写成：C(e^x, x) ≥ D(ln x, x)
其中 C 和 D 共用同一个母函数 g，但自变量的位置/数量不对称
→ 利用 g 的单调性 + 不等式夹逼补全对称缺口
```

这种非对称不是"缺陷"，而是命题时**刻意制造的结构张力**——解题者需要识别出母函数 g，然后通过添加项或不等式放缩将不对称转化为可比较形式。

## 扩展：平移与缩放衍生

以上所有模式通过平移、缩放、变量代换可以产生**无穷变体**。关键在于识别这些变换并将表达式还原到基本模式：

| 衍生表达式 | 变换操作 | 还原为 |
|-----------|---------|--------|
| (x-1)·e^x | 右移1 + 纵向缩放e倍 | e·f(x-1)，f=x·e^x |
| e^x/(x+1) | 左移1 + 纵向缩放1/e | (1/e)·(e^(x+1)/(x+1)) |
| (ln x+1)/x | 自变量缩放e倍 | e·(ln(ex)/(ex)) |
| ln x/x² | x→x² 代换 | (1/2)·(ln(x²)/x²) |

**识别口诀**：看到 x-a、ln(ax)、x² 这类结构，第一时间尝试变量代换回到基本模式。

- 例7：f(x)=(a+lnx)/x → e^a·(ln(e^a x)/(e^a x))
- 例14：g(x)=(lnx+1)/x = e·h(ex)，h(x)=lnx/x
