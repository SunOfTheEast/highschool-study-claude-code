# 数学学习路线

## Overview

从学生真实的数学目标、已有经验和当前困惑出发，共同形成可调整的学习路线。

## Long-term Goal

学生能够在自己关心的数学任务中说明目标、选择可尝试的路线、检验结果，并把有效策略迁移到相近的新情境。

## Observable Capability Standard

面对一个新任务时，学生能说出已知与未知，提出或比较下一步，完成一次可检查的尝试，并根据证据解释是否需要调整。

## Test

选取与学生目标相关、但表面形式有所变化的任务，观察其解释、尝试、检查与调整，而不只看答案是否正确。
