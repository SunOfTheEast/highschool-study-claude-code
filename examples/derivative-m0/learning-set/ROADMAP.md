# 高阶导数结构学习路线

## Overview

围绕真实导数综合题，逐步建立“看结构、选路线、做检验”的完整能力。学习方向会
根据学生的目标和课堂表现继续调整，不预设一个陌生学生的薄弱点。

## Long-term Goal

面对陌生的高阶导数综合题时，能够识别关键结构，比较可行路线，完成严谨推导，
并在原路线受阻时作出有理由的调整。

## Observable Capability Standard

在多种不同外壳的综合题中，能独立说明关键结构与选路依据，完成主要推导并检查
必要条件；遇到受阻时，能指出停点并比较下一条可行路线。

## Test

使用一组未见过的混合题，观察学生的口头判断、完整书写、条件检查和受阻后的
调整。具体题型与数量在各 Plan 中根据阶段目标确定。
