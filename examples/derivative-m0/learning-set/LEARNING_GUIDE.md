# 高阶导数结构学习集

这里陪你练习导数综合题里的结构判断和方法选择。遇到没见过的题时，先看清它为什么
适合某条路线，再把路线完整走通。

## Student Learning Principles

- 碰到一道新题时，先说说自己在哪一步犹豫，不用急着报方法名。
- 选定路线前，先找出题目里真正起作用的结构；算完以后再检查定义域、取等和边界。
- 同一种方法换个题目外壳再试一次，看看自己是否真的会选、也会做。
- 如果你想到另一条路，可以直接提出来，和老师一起比较哪条更稳。

## Internal Teaching Notes

### Learning logic

- 先找出学生具体卡在哪一种结构、哪一步，再决定练什么。
- 不只记方法名称，还要说清题目中的什么结构让它值得使用。
- 提示从方向开始，按学生当时的需要逐步增加。
- 学生提出不同路线时，先检查这条路线本身，不急着拉回参考解。
- 用不同外壳的陌生任务检查迁移，不以刚讲过的题能否复述代替掌握。
- 把方法判断、运算执行和条件检验分开诊断，避免把所有失误都归为粗心。

### Teaching choices

每个活动应承担清楚的教学作用，例如暴露起点、形成路线对比、练习执行或检验
迁移。定义域和边界是论证合法性的一部分，但不默认挤占高级方法学习的主线。
课堂中出现的新情况直接记录在当前 Lesson 的对应 Block，下一次备课时由 Plan
Session 重新阅读这些原始记录。
