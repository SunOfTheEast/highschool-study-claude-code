# 高阶导数结构学习集

这个学习集面向已经掌握高中导数基础、希望系统提升综合题结构识别与方法选择的
学生。它保留了 500 余张真实题卡和一棵按主方法、辅助方法组织的方法图谱，可用于
同构变形、切线与公切线、参变量分离、数形结合、局部逼近等方向的连续学习。

## Learning Principles

- 先找出学生具体卡在哪一种结构、哪一步，再决定练什么。
- 不只记方法名称，还要说清题目中的什么结构让它值得使用。
- 提示从方向开始，按学生当时的需要逐步增加。
- 学生提出不同路线时，先检查这条路线本身，不急着拉回参考解。
- 用不同外壳的陌生任务检查迁移，不以刚讲过的题能否复述代替掌握。
- 把方法判断、运算执行和条件检验分开诊断，避免把所有失误都归为粗心。

## Teaching Notes

每个活动应承担清楚的教学作用，例如暴露起点、形成路线对比、练习执行或检验
迁移。定义域和边界是论证合法性的一部分，但不默认挤占高级方法学习的主线。
课堂中出现的新情况直接记录在当前 Lesson 的对应 Block，下一次备课时由 Plan
Session 重新阅读这些原始记录。
