# Plan 001：建立真实学习起点

## Stage Goal

通过具体问题和真实经历，确定学生当前最值得强化的导数结构、真实停点与期望变化，
再据此安排后续课程。

## Observable Capability Standard

学生与学习顾问能够共同说清一个具体问题类型、当前停点、已有尝试和下一阶段想要
达到的变化，并把它写成可由真实课堂检验的目标。

## Test

学生用一道最近遇到或印象深刻的导数综合题说明自己的起点；学习顾问据此提出一份
具体的下一课安排，学生能够判断它是否切中问题。
