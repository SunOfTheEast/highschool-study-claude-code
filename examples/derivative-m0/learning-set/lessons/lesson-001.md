# Lesson 001：找到真正的停点

## Lesson Goal

让学生从真实做题经历出发，说清最棘手的导数结构、已经尝试过的路线和真正停止
推进的位置，为下一节正式训练课留下足够具体的课堂记录。

## Block block-001：从具体经历开始

### Node State

- Kind: dialogue
- Required: true
- Status: pending
- Depends on:
- Uses:

### Student View

最近哪一道或哪一类导数综合题最让你犹豫？可以先说题目的结构，也可以直接说你
通常做到哪里会停下来。

### Teacher Control

先听具体经历。若回答仍是宽泛标签，追问题目结构、已经尝试的入口和真实停点；
一次只追问一个会改变后续备课的问题。

### Classroom Log

## Block block-002：确认下一步值得改变什么

### Node State

- Kind: reflection
- Required: true
- Status: pending
- Depends on: block-001
- Uses:

### Student View

回看刚才说的经历，你最希望下一阶段先改变什么：更快看见入口、比较路线、把一条
路线算到底，还是在受阻时知道如何换路？也可以用自己的话描述。

### Teacher Control

用学生自己的表述复述工作判断并请其修正。只确认下一阶段的真实需求，不在本节
临时塞入一道未经准备的训练题。
