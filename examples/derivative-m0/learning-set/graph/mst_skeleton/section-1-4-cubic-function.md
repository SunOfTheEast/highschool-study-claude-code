# 第一章·第四节 三次函数的基本理论 — 结构提取

## 定位：具体函数的性质体系

前三节教的是**通用方法**（同构、切线放缩、指对处理），第四节研究一个**具体对象**——三次函数。性质是结论性的、可记忆的，不需要每次重新推导。

但这不意味着第四节没有思想。它隐含了一个重要的认知框架：**完整的函数分析 = 导数判别 + 对称性 + 图像分段**。这个框架是通用的，只不过三次函数恰好是它最完美的展示对象。

## 性质体系

### 层次一：导数判别（继承自二次函数）

```
f(x) = ax³ + bx² + cx + d
f'(x) = 3ax² + 2bx + c   —— 二次函数！
f''(x) = 6ax + 2b         —— 一次函数
```

三次函数被其导函数（二次函数）完全控制：
- f' 的判别式 Δ = 4b² - 12ac 决定单调性和极值
- f'' 的零点决定拐点（对称中心）

| a | Δ | 单调性 | 极值点个数 |
|---|----|--------|----------|
| >0 | >0 | ↑↓↑ | 2 |
| >0 | ≤0 | 单调↑ | 0 |
| <0 | >0 | ↓↑↓ | 2 |
| <0 | ≤0 | 单调↓ | 0 |

**结构要点**：三次函数的复杂度完全降维到二次函数——你不需要直接分析三次函数，分析它的导数（二次）就够了。

---

### 层次二：对称中心（拐点）

```
对称中心横坐标：x₀ = -b/(3a)
     = f''(x)=0 的解（拐点）
     = f'(x) 对称轴横坐标（导函数对称轴）
     = 两个极值点的中点（当 Δ>0 时）
```

**三重身份合一**：
1. 拐点（二阶导为零）
2. 导函数的对称轴
3. 两极值点中点

这不是巧合，是三次函数的代数结构决定的。`f(x) = a(x-x₀)³ + p(x-x₀) + q` —— 三次函数在拐点展开后，二次项系数为零。

**推论链**：
```
f''(x₀)=0 → f 在 x₀ 两侧凹凸反转
         → f 关于 (x₀, f(x₀)) 中心对称
         → f'(x) 关于 x=x₀ 轴对称
         → 若有两个极值点，它们关于 x₀ 对称
```

---

### 层次三：四段论

基于对称中心和极值点，将定义域分为四段（a>0 且 Δ>0 时）：

```
   x₁        x₀        x₂
  极小      中心      极大
   ↓         ↓         ↓
───●─────────●─────────●───→
段1  段2  段3  段4
```

| 段 | 区间 | f' | f'' | f |
|---|------|-----|------|---|
| 段1 | (-∞, x₁) | + | - | 凹增 |
| 段2 | (x₁, x₀) | - | - | 凹减 |
| 段3 | (x₀, x₂) | - | + | 凸减 |
| 段4 | (x₂, +∞) | + | + | 凸增 |

**关键定量关系**（a>0, Δ>0）：
- 极大值点到对称中心距离 = 极小值点到对称中心距离
- 极小值等值点到极大值点距离 = 对称中心到极值点距离的两倍
- 区间被中心和极值点三等分（等距性）

**四段论的意义**：不是记结论，而是建立"由导数信息还原函数图像全貌"的分析习惯。这个习惯对所有函数都适用——三次函数恰好是最佳训练场。

---

### 层次四：三次方程根的判别

由极值符号判定实根个数（a>0）：

| f(x₁)·f(x₂) | 实根个数 |
|-------------|---------|
| < 0 | 3 |
| = 0 | 2（一个重根） |
| > 0 | 1 |

## 这一节的"结构"是什么

第四节和前两节提取"代数结构"的逻辑不同。这里没有可识别的表达式模式，也没有不等式生成器。这里的"结构"是**函数分析的一般框架**：

```
导函数 → 单调性 + 极值
二阶导 → 拐点 + 对称性  
极值符号 → 零点个数
图像分段 → 全局性质
```

这个框架不只属于三次函数——它在第五节（泰勒展开）和第六节（帕德逼近）中以更一般的形式重现。
