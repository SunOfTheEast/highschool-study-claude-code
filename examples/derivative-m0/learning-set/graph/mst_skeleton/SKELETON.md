## 问题域

```
题型一  恒成立求参数范围
        ├─ 端点效应
        ├─ 极点效应
        ├─ 隐点代换 ←── 前置: 放缩取点(题型三)
        ├─ 保值性分解  (加法型 0+0=0 / 乘法型 0×0=0)
        ├─ 分而治之
        ├─ 图像位置法 (包裹性)
        └─ 切线零点比大小

题型二  不等式证明
        ├─ 同构归约
        │   └─ 方法触发: x·eˣ→乘积型 / eˣ±x→和差型 / eˣ+e⁻ˣ→双曲型 / 不对称→夹逼
        ├─ 切线放缩
        ├─ 逼近替代 (泰勒/帕德/双曲型放缩)
        ├─ 分而治之
        └─ 表达式清洁 (对数项孤立化 / 指数项配对化简)

题型三  零点个数与存在性
        ├─ 图像交点法
        │   └─ 触发: 参可分离→参变法 / 不可全分离→半分离 / 绝对值→模块 / 嵌套→内横外竖
        └─ 放缩取点
            └─ 触发: 标准→取点链 / 不对称增长→等效零点 / 指多混合→主客体 / 偏移场景→偏移取点

题型四  对称中心偏移
        ├─ 极值点偏移 (一阶导零点)
        ├─ 拐点偏移 (二阶导零点)
        ├─ 对数均值不等式策略
        └─ 拟合替代

题型五  数值比较 (比大小)
        └─ 精度递进: 初级比较→同构归约→图像交点→逼近替代

题型六  距离最值
        ├─ 平行切线距离法
        ├─ 反函数水平距离法
        └─ 乘积指数化+切线放缩

题型七  切线几何问题
        ├─ 7a. 基本切线计算
        ├─ 7b. 切线条数判定 (区域分类法)
        ├─ 7c. 公切线问题 (代数/几何双轨)
        ├─ 7d. 包络线判定
        └─ 7e. 牛顿迭代

题型九  抽象函数性质推断
        ├─ 对称性锁定 (f↔f')
        └─ 积分因子构造 (看到 f'+pf → 乘 e^∫p)

题型十  双变量不等式
        └─ 触发: x₁/x₂→比值 / x₁−x₂→差值 / 有对称中心→偏移 / 不对称→主元 / 需数值界→切割线 / 精度不够→拟合

题型十一 数列不等式
        ├─ 11a. 切线放缩型求和
        ├─ 11b. 裂项相消型
        ├─ 11c. 等比放缩型
        ├─ 11d. 双曲型放缩/帕德高精度型
        └─ 11e. 累乘估计型

题型十二 三角-导数综合
        ├─ 12a. 三角+零点 (周期分段讨论)
        ├─ 12b. 三角+恒成立 (有界性压参)
        ├─ 12c. 三角+数列
        └─ 12d. 三角+双变量 (和差化积+主元)

知识模块  三次函数性质体系
        └─ 判别式·拐点·四段论·实根判别·切线条数区域表 (全部预推导, 直接调用)
```
