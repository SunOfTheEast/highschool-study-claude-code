# 第一章·第五/六节 泰勒展开与帕德逼近 — 结构提取

## 定位：两个特定的逼近知识体系

第五节和第六节性质相同——都是**知识节点**。不是教你怎么想、怎么操作，而是告诉你"有这些工具，记住它们"。

它们的真正价值出现在后续章节：第四章比大小、第六章放缩、第九章拟合——那时它们会作为"弹药"被反复调用。

## 第五节：泰勒展开

### 是什么

用多项式在某个点附近逼近任意光滑函数。在 x₀=0 时称为麦克劳林公式。

```
f(x) = f(0) + f'(0)x + f''(0)x²/2! + ... + f⁽ⁿ⁾(0)xⁿ/n! + Rₙ(x)
```

Rₙ(x) 是余项（佩亚诺型：比 xⁿ 更高阶的无穷小）。

### 需要记住的展开式（弹药库）

| 函数 | 展开式 | 常用不等式 | 不等号方向 |
|------|--------|-----------|-----------|
| eˣ | 1 + x + x²/2! + x³/3! + ... | eˣ ≥ 1 + x | 凸函数，≥ |
| | | eˣ ≥ 1 + x + x²/2 | 加强型 |
| ln(1+x) | x − x²/2 + x³/3 − ... | ln(1+x) ≤ x | 凹函数，≤ |
| | | ln(1+x) ≥ x − x²/2 | 下界 |
| sin x | x − x³/6 + x⁵/120 − ... | sin x ≤ x | |
| cos x | 1 − x²/2 + x⁴/24 − ... | cos x ≥ 1 − x²/2 | |
| 1/(1−x) | 1 + x + x² + x³ + ... | — | 等比级数 |
| 1/(1+x) | 1 − x + x² − x³ + ... | — | 等比级数 |
| (1+x)ᵅ | 1 + αx + α(α−1)x²/2 + ... | — | 二项展开 |

### 与第一节（同构）的连接

双曲函数是泰勒展开视角下对同构的重新理解：

```
ch(x) = (eˣ + e⁻ˣ)/2 = 1 + x²/2! + x⁴/4! + ...  （只含偶次项，偶函数）
sh(x) = (eˣ − e⁻ˣ)/2 = x + x³/3! + x⁵/5! + ...  （只含奇次项，奇函数）
```

飘带函数是双曲正弦在 ln 下的投影：
```
ln x < (x − 1/x)/2, x > 1
     = sh(ln x)
```

这说明：**第一节的"构造双曲正余弦同构函数"，本质上是在用泰勒展开的结论——只是当时没点破。**

### 泰勒展开与估值

展开式截断前几项 → 得到近似值 + 误差界 → 用于比大小、估计范围。

**核心用法**：不等号方向由剩余项（拉格朗日余项）的符号决定。

## 第六节：帕德逼近

### 是什么

用有理函数（分子 m 次 ÷ 分母 n 次）逼近任意函数。泰勒展开是它的特例（分母=常数）。

```
f(x) ≈ (a₀ + a₁x + ... + aₘxᵐ) / (1 + b₁x + ... + bₙxⁿ)
```

记为 [m/n] 阶帕德逼近。在 x₀ 处误差最小。

### 与泰勒展开的关键区别

| | 泰勒展开 | 帕德逼近 |
|---|---|---|
| 形式 | 多项式 | 有理函数（分式） |
| 不等号方向 | 固定（取决于凹凸性） | 可能与泰勒相反 |
| 合起来 | 提供单侧界 | 提供反向界 → **夹逼** |

**这是帕德逼近在高考中的核心价值**：泰勒给出上界（或下界），帕德给出反向界，两者合起来就形成了对函数值的**双侧夹逼**。估值题目正是依赖这一点。

### 常见帕德逼近

| 函数 | 帕德逼近 | 不等号方向 |
|------|---------|-----------|
| ln(1+x) | 2x/(2+x) | 与泰勒 ln(1+x)≤x 可能反向 |
| eˣ | (2+x)/(2−x) | 低阶近似 |

**与飘带函数的配合**：
- 飘带: ln x < (x−1/x)/2
- 帕德: ln x > 2(x−1)/(x+1)

两者合体 → ln x 的双侧夹逼。

### 高阶帕德逼近与极值偏移

更高阶的帕德逼近提供更紧的界 → 可用于极值偏移题型中的精细不等式证明。

```
    ├── S5 泰勒展开 ────────→ 多项式逼近：记住展开式 + 不等式方向

```

**关键桥接**：
- 切线放缩是泰勒展开退化到一阶的特例。`eˣ ≥ x+1` 就是泰勒展开截断第一项。
- 这就解释了为什么切线不等式方向固定（取决于凹凸性）——凹凸性决定了泰勒余项的符号。
- 帕德逼近是因为泰勒的方向性太强、精度不够才引入的——它提供了反向不等式。
