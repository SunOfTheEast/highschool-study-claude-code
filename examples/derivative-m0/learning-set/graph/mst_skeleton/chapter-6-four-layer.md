## 策略层（新增）

### 策略P：保值性分解

**路径**：

```
f(x) ≥ 0 恒成立，求参数
    ↓
将 f(x) 拆分为: h(p(x)) + h(q(x)) + m·φ(x)
    ↓
其中 h(t) ≥ 0 (且 h(0)=0)，φ(x) 与 h(p(x)), h(q(x)) 共零点
    ↓
若 m > 0 → φ(x) 项在零点附近决定符号 → 可推出 m 必须 = 0
    ↓
参数确定
```

**核心思想**：把一个复杂函数拆成几个**已知非负性**的子函数的和。h(x) = eˣ - x - 1（保底非负函数）是最常用的"积木块"。

**包裹的结构识别**：

| 信号 | 解释 |
|------|------|
| 表达式中出现 eˣ 和 ln x 的混合 | 尝试进行 eˣ - x - 1 或 x - ln x - 1 的分解 |
| 题目问"f(x) ≥ 0 恒成立，求参数" | 如果极值点处 f = 0 且参数恰好消去，触发保值性 |
| f(x) ≥ 0 且在 x₀ 处取等 | x₀ 是分解后各子函数共同的零点 |

**关键识别**：看到 eˣ - x - 1、x - ln x - 1，或它们的变形 (e^{x+ln x} - (x+ln x) - 1 等)，立即想到保值性分解。

**极点效应条件**：当余量函数 φ(x) 在共同零点 x₀ 附近单调且 φ(x₀)=0，则 m 必须 = 0，否则 f(x) 在 x₀ 附近变号。

### 策略Q：分而治之

**路径**：

```
要证: f(x) ≥ g(x) 对所有 x 成立
    ↓
拆分为: f(x) = f₁(x) · f₂(x) ...  和  g(x) = g₁(x) · g₂(x) ...
    ↓
分别求出 f 每部分的 min 和 g 每部分的 max
    ↓
若 f₁_min · f₂_min · ... ≥ g₁_max · g₂_max · ...，则原不等式成立
```

**本质**：把单个复杂函数的分析降维为多个**已知最值的基本函数**的分析。

**包裹的结构识别 — 上下函数选取**：

| 场景 | 上函数（取 min） | 下函数（取 max） |
|------|-----------------|-----------------|
| 含 eˣ/x 型 | eˣ/x ≥ e (x=1) | — |
| 含 ln x/x 型 | — | ln x/x ≤ 1/e (x=e) |
| 含 x·eˣ 型 | x·eˣ ≥ -1/e (x=-1) | — |
| 含 x·ln x 型 | x·ln x ≥ -1/e (x=1/e) | — |
| 含 x/eˣ 型 | — | x/eˣ ≤ 1/e (x=1) |

**关键识别**：

```
看到 eˣ/x ≥ ???   → 上函数，min=e (x=1)
看到 ln x/x ≤ ???  → 下函数，max=1/e (x=e)
看到 eˣ 放缩       → 上函数: eˣ ≥ ex, eˣ ≥ x+1, eˣ ≥ ex+(x-1)²
看到 ln 放缩       → 下函数: ln x ≤ x-1, ln x ≤ x/e
看到三角放缩      → sin x ≤ x, cos x ≥ 1-x²/2, tan x ≥ x
```

**函数变形后的分而治之**：当原始形式无法直接拆分时，通过乘除变形（同乘以 x、同除以 x²等）重新构造上下函数。关键在于让两边都出现可求最值的六大函数形式。

### 策略R：放缩取点

**路径**：

```
需要证明 f(x) 在区间 (a,b) 内有零点
    ↓
找到 m, n 使 f(m)·f(n) < 0
    ↓
但 f(m) 和 f(n) 包含不可解的超越方程
    ↓
将 f(x) 放缩为一个更大的函数 g(x) ≥ f(x)
    ↓
求解 g(x) = 0 → 得到可计算的 m, n
    ↓
验证 f(m) < 0, f(n) > 0 → 零点存在
```

**"灵魂三问"的框架**：

1. **什么是放缩取点？** — 把不可解方程转化为可解方程，通过放缩找到零点区间的端点。
2. **哪些方程是可解的？** — 一次方程 ax+b=0、二次方程、简单指数/对数方程。
3. **如何转化？** — 通过熟知的不等式（eˣ ≥ x+1, ln x ≤ x-1 等）将超越项替换为多项式项。

**关键技巧**：
- **等效零点法**："主题留一半，客体被吊打" — 提取公因式 e^{x/2} 或类似结构，将不可解部分放缩为简单的代数表达式
- **主客体分析**：区分"主体"（增长最快的项）和"客体"（被放缩控制的项）

## 方法层（新增）

### 方法组12：放缩公式体系

#### 指数放缩
| 不等式 | 取等条件 | 精度 |
|--------|---------|------|
| eˣ ≥ x+1 | x=0 | 1阶泰勒 |
| eˣ ≥ ex | x=1 | 切点平移 |
| eˣ ≥ ex + (x-1)² | x=0, x=1 | 2阶精度 |
| eˣ ≥ (e/2)x² + e/2 | x=1, x≥1 | 二次下界 |

#### 对数放缩
| 不等式 | 取等条件 |
|--------|---------|
| ln x ≤ x-1 | x=1 |
| ln x ≥ 1 - 1/x | x=1 |
| ln(x+1) ≤ x | x=0 |

#### 三角放缩
| 不等式 | 取等条件 |
|--------|---------|
| sin x ≤ x ≤ tan x | x=0 |
| sin x ≥ x - x³/6 | x=0 |
| cos x ≥ 1 - x²/2 | x=0 |
| cos x ≤ 1 | x=2kπ |
| tan x ≥ x + x³/3 | x=0 |

### 方法组13：放缩取点步骤链

```
1. 用 f'(x)=0 确定极值点 x₀
2. 验证 f(x₀) < 0（必要条件）
3. 在 x₀ 左侧: 找一个 m < x₀ 使 f(m) > 0
   → 用放缩: f(x) > g(x), 解 g(x)=0 得 m
4. 在 x₀ 右侧: 找一个 n > x₀ 使 f(n) > 0
   → 用放缩: f(x) > h(x), 解 h(x)=0 得 n
5. 验证 f(m)·f(n) < 0 → 两个零点
```

## 知识层（新增）

### 可解方程清单（找点可用）

| 方程类型 | 示例 |
|---------|------|
| 一次方程 | ax+b=0 |
| 二次方程 | ax²+bx+c=0 |
| 简单指数/对数 | eˣ=a → x=ln a; ln x=a → x=eᵃ |
| 可因式分解的高次 | 提出公因式后降次 |

### 放缩方向原则

- 要证明 f(x) > 0：需要放缩出 f(x) 的下界 → 对正项放小、对负项放大
- 要找 f(m) > 0 的点：把 f(x) 替换为一个更小的函数 g(x)，使 g(x)=0 可解
- 要找 f(m) < 0 的点：把 f(x) 替换为一个更大的函数 g(x)，使 g(x)=0 可解
