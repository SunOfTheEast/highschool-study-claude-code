# 第九章 导数与双变量 — 四层框架提取

## 定位

第九章处理导数中最困难的问题类型——涉及两个变量的综合题。核心挑战是**降维**——把双变量问题转化为单变量问题。

本章不引入新思想（降维思想在 Ch1 已出现），贡献全在策略层和方法层。

## 策略层（新增）

### 策略X：比值/差值代换

**路径**：

```
双变量问题（x₁, x₂ 满足某种等式约束）
    ↓
设 t = x₁/x₂（比值） 或  d = x₁ - x₂（差值）
    ↓
原问题转化为关于 t（或 d）的单变量函数问题
    ↓
对单变量函数求导分析
```

**包裹的结构识别**：

| 触发信号 | 代换选择 |
|---------|---------|
| f(x₁) = f(x₂) 型 | 两个等式相减/相除得 x₁, x₂ 的比值或差值关系 |
| x₁·x₂ 出现在结论中 | 比值代换 t = x₁/x₂ |
| x₁+x₂ 出现在结论中 | 差值代换或直接利用 x₁+x₂ 的表达式 |
| 六大同构函数场景 | 比值代换归约到已知函数 |

**关键**：代换的本质是利用等式约束消去一个变量。x₁ 和 x₂ 不独立——它们通过 f(x₁)=f(x₂) 或 x₁+x₂=a 关联——代换正是利用这个关联。

### 策略Y：对称化构造（极值点偏移）

**路径**：

```
f(x₁) = f(x₂) = 0, x₁ < x₂, 极值点在 x₀
要证: x₁ + x₂ > 2x₀（或 <）
    ↓
构造 F(x) = f(x) - f(2x₀ - x)
    ↓
分析 F(x) 在 x₀ 两侧的符号
    ↓
若 F(x₂) > 0 → f(x₂) > f(2x₀ - x₂) → f(x₁) > f(2x₀ - x₂)
    ↓
利用 f 的单调性: x₁ > 2x₀ - x₂ → x₁ + x₂ > 2x₀
```

**本质**：把"零点不对称"转化为"对称化构造函数"的符号分析。

**极值点偏移的判定**：三阶导的符号决定偏移方向。

### 策略Z：ALG 不等式策略

**路径**：

```
已知 f(x₁) = f(x₂) 且需要证 x₁, x₂ 满足的不等式
    ↓
由 f(x₁) = f(x₂) 导出 x₁, x₂ 的函数关系
    ↓
利用 ALG: √(x₁x₂) < (x₁-x₂)/(ln x₁ - ln x₂) < (x₁+x₂)/2
    ↓
直接得证或结合代换
```

**ALG 变体**：
- 常规型：对数均值不等式
- 反向型（加法原理）：用 ALG 的不等号反向构造
- 常数项调整型：引入参数调整不等式到目标形式
- 根号型：√(ALG)，结合三角放缩

### 策略AA：切割线夹（零点差）

**路径**：

```
函数有两个零点 x₁, x₂，需要估计 |x₁-x₂| 的范围
    ↓
在 x₁ 或 x₂ 处作切线 → 切线交水平线 y=m 于 x₃, x₄
    ↓
|x₁-x₂| < |x₃-x₄|（切线夹）或 > (割线夹)
    ↓
x₃, x₄ 是线性方程的解（可精确计算）
```

**为什么有效**：切线和割线是可精确求解的线性/二次函数，用它们替代原函数得到零点差的显式界。

---

### 策略AB：拟合替代

**路径**：

```
需要分析 f(x) 在局部的行为，但 f 太复杂
    ↓
构造一个较简单的拟合函数 g(x)（二次、对勾、飘带等）
    ↓
g(x) 与 f(x) 在某点处具有相同函数值+导数值（甚至二阶导）
    ↓
用 g 的零点/极值近似 f 的零点/极值
```

**常见拟合对**：

| 原函数 | 拟合函数 |
|--------|---------|
| x·eˣ 在 x=-1 附近 | 二次函数 |
| x/eˣ 在 x=1 附近 | 二次函数 |
| ln x 在 x=1 附近 | 飘带函数 (x-1/x)/2 |
| 一般指对混合 | 帕德逼近有理函数 |

---

### 策略AC：主元法

**路径**：

```
双变量问题中，两个变量地位不对称
    ↓
选择一个变量作为"主元"，另一个视为参数
    ↓
以主元为自变量求导分析 → 得到关于主元的结果
    ↓
再对参数进行讨论（或交换主元重复）
```

**关键**：主元选择 = 选择求导对象。选得好，表达式大幅简化。对称式中常选 x₁ 为主元（x₁ < x₂），不对称式中选系数较简单的那个。

## 知识层（新增）

### 对数均值不等式 (ALG)

```
若 0 < x₁ < x₂，则:
√(x₁x₂) < (x₁-x₂)/(ln x₁ - ln x₂) < (x₁+x₂)/2
```

等号仅在 x₁ = x₂ 时成立。左侧 = 几何平均，右侧 = 算术平均。

### 极值点偏移方向判定

三阶导 f'''(x₀) 的符号 → 偏移方向。f'''(x₀) > 0 → 极小值左偏、极大值右偏（对勾函数型）。

### 拐点偏移

类似极值点偏移，但以二阶导零点（拐点）为对称中心。x₁ + x₂ 与 2x₀ 比较。
