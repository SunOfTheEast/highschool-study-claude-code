# 第一章·第三节 指对处理的基本方法 — 结构与定位

## 定位：不是思想原子，是操作层

第三节不引入新的思想原子。它是**操作层**——架在"一团乱麻的表达式"和"可识别的代数结构"之间的桥梁。

```
一团乱麻 ──[第三节]──→ 干净表达式 ──→ 识别出第一节/第二节的结构 → 解出
```

具体分工：
- **对数单身狗**：清理 ln x 侧的噪音，露出底层结构
- **指对找基友**：清理 e^x 侧的噪音，露出底层结构
- **切线与最值等效转化**：视角切换器，让第一节和第二节互译

**WHY：为什么需要这些操作？——回到阶差原理**

第一节的阶差分析指出：ln x、e^x 无法通过求导消去。第三节的两大操作——单身狗和找基友——是**对这一不可消除性的务实应对**：

> 既然消不掉，那就孤立它。把 ln x（或 e^x）从乘积中剥离出来，让它成为独立项，然后对剩余部分求导分析。

这不是新思想，是**阶差原理的工程应用**。

## 操作模式A：对数单身狗

### 触发条件

表达式中出现 g(x)·ln x 且 g(x) 不是常数。直接求导会导致 ln x 残留，需要多次求导。

### 操作

```
f(x) = g(x)·ln x + h(x)
     = g(x) · [ln x + h(x)/g(x)]
```

将 ln x 孤立为单独项（"单身"），对括号内剩余部分独立分析。

### 本质

这是**阶差原理的直接应对**：ln x 求导后变成 1/x，乘积中的 ln x 会让求导结果中 ln x 和 1/x 共存，形成递归。提前把 ln x 提出去，相当于**阻断递归**。

### 关键识别特征

- 题目表达式含 ln x 乘以一个非平凡函数
- 需要分析单调性或最值
- 直接求导会导致表达式越来越复杂

### 与模式A（乘积型同构）的关系

第一节模式A的核心是对 x·ln x 的同构处理。而"对数单身狗"处理的场景更广：不限于 x·ln x，任何 g(x)·ln x 都适用。可以说，**同构是特解，单身狗是通解**——当 g(x) 恰好构成同构条件时走同构，否则走单身狗。

## 操作模式B：指对找基友

### 触发条件

表达式中出现 g(x)·e^x 或 e^x / g(x)，且需要证明不等式或求最值。直接处理 e^x 会让求导/放缩困难。

### 操作

**核心技巧**：将 e^x 移到分母——形式为 g(x)/e^x 或 e^x/g(x)，利用：

```
(g(x)/e^x)' = (g'(x) - g(x)) / e^x
(g(x)·e^x)' = (g'(x) + g(x)) · e^x
```

"基友"就是让 g'(x) ± g(x) 简化的那个 g(x)。

### 本质

这是**利用 e^x 求导不变性**来构造简化。e^x 求导后还是 e^x，这意味着如果你精心选择配对函数 φ，使得 φ' ± φ 简单，整个表达式的导数就简单了。

相比 ln x（求导后降阶为 1/x），e^x 的处理更容易——因为它**不求导降阶**，只需要找到对的配对。

### 关键识别特征

- 题目含 e^x·g(x) 或 g(x)/e^x
- 需要证明不等式恒成立
- 涉及三角时尤其有效（避免讨论）

### 与第二节（切线放缩）的关系

找基友处理后的表达式往往可以直接应用切线放缩。典型路径：

```
g(x)·eˣ ≥ h(x)  ──[找基友]──→  g(x)/eˣ ≥ ???  ──→  用 eˣ ≥ ex 放缩
```

## 视角切换：切线与最值等效转化

### 核心等价关系

```
f(x) ≥ 0 恒成立，且在 x₀ 处取等
        ⇕
f(x) 在 x₀ 处取最小值 0
        ⇕
y = f(x) 在 x₀ 处的切线是 y = 0，且 f 是凸的（切线在下方）
```

换句话说：**切线不等式就是最值陈述的几何表达**。

### 为什么需要这个切换

| 视角 | 适用场景 | 弱点 |
|------|---------|------|
| 最值视角（第一节） | 单个函数，求导方便 | 两个函数比较时变量增多 |
| 切线视角（第二节） | 不等式放缩，构造临界条件 | 需要选择切点 |

第三节告诉你：**不需要二选一，它们是同一个东西。**

- e^x ≥ x+1 = min(e^x - x - 1) = 0 at x=0
- ln x ≤ x-1 = max(ln x - x + 1) = 0 at x=1

### 六级函数模型的双面解释

第一节的六大函数，用切线视角重新审视：

| 函数 | 极值（第一节视角） | 切线来源（第二节视角） |
|------|-------------------|----------------------|
| x·e^x, min=-1/e at x=-1 | 求导得极值 | e^x ≥ ex → x→x+1 → e^(x+1) ≥ e(x+1) → x·e^x ≥ -1/e |
| x·ln x, min=-1/e at x=1/e | 求导得极值 | ln x ≤ x-1 → x→ex → ... |
| x/e^x, max=1/e at x=1 | 求导得极值 | e^x ≥ ex → x→-x → ... |
| e^x/x, min=e at x=1 | 求导得极值 | e^x ≥ ex → /x → e^x/x ≥ e |
| ln x/x, max=1/e at x=e | 求导得极值 | ln x ≤ x-1 → /x → ... |
| x/ln x, min=e at x=e | 求导得极值 | 类似推导 |

**这意味着第一节和第二节不是两个独立工具，而是同一个数学事实的两种语言。** 第三节的"等效转化"就是这两种语言之间的翻译器。

- 例10-13

## 三个操作的选用逻辑

```
拿到一道题
    │
    ├── 表达式含 ln x·g(x) 且 g(x) 复杂？
    │       → 对数单身狗：孤立 ln x，分析剩余部分
    │
    ├── 表达式含 eˣ·g(x) 或 g(x)/eˣ？
    │       → 指对找基友：商化/积化，利用 (g/eˣ)' = (g'-g)/eˣ
    │
    ├── 在"求最值"和"放缩"之间犹豫？
    │       → 等效转化：两者等价，选计算量小的那个
    │
    └── 清理完毕后
            → 识别第一节的代数结构（同构模式A/B/C）
            → 或应用第二节的切线生成器（A/B/C）
```

## 在知识图谱中的挂载

第三节的定位决定了它不是独立的知识节点，而是**操作边**——连接"原始表达式"到"可识别结构"的转换路径。

```
操作: 对数单身狗
  触发: [ln x 乘以非平凡 g(x)]
  动作: 因式分解，孤立 ln x
  输出: 干净的表达式 → 送入同构或切线放缩
  为何有效: 阶差原理——消不掉就孤立

操作: 指对找基友
  触发: [eˣ 乘以非平凡 g(x)]
  动作: 构造商 g/eˣ 或积 g·eˣ，使导数简化
  输出: 可放缩/可比较的表达式
  为何有效: eˣ 求导不变性

操作: 切线与最值等效
  触发: [需要在最值视角和切线视角间切换]
  动作: 识别 f(x) ≥ 0 且在某点取等 ⇔ 切线为0
  输出: 选择计算量更小的视角
  为何有效: 凹凸性的几何本质
```

每道例题挂载到触发它的操作模式上，同时挂载到操作最终导向的目标结构（同构模式或切线生成器）。
