# 第三章 抽象函数的构造 — 四层框架提取

## 定位

第一章教了**表达式变形**（同构、切线放缩），第二章教了**切线几何**。第三章进入新领域：**从导函数关系反推原函数结构**。

这不是变形，是**重构**——你不知道 f(x) 具体长什么样，只知道 f'(x) 满足某种关系，你需要构造一个辅助函数来揭示 f(x) 的性质（周期、对称、单调）。

**与第一章 S3（指对处理）的关系**：第一章 S3 的"指对找基友"是正向操作（清洗表达式），第三章是把这操作倒过来——从清洗后的形式反推原来的结构。两者互为逆运算。

## 策略层（新增）

### 策略H：抽象函数构造 — 反向产品法则

**核心思路**：看到 f'(x) + p(x)f(x) 的形式 → 两边乘以积分因子 e^(∫p(x)dx) → 左边变成 (f·e^(∫p))' → 右边可积分 → 得到 f 的性质。

```
f'(x) + p(x)f(x) = h(x)
     × e^(∫p(x)dx)
→ (f(x)·e^(∫p(x)dx))' = h(x)·e^(∫p(x)dx)
→ 积分得到 f(x)·e^(∫p(x)dx) 的表达式
→ 分析单调性/对称性/周期性
```

**为什么不是第三章独有的思想**：这是微积分基本定理（求导与积分为逆运算）的应用，属于通用数学思想，不是本书独创。但本书把它系统化成了可操作的策略。

**触发条件**：题目给出 f'(x) ± kf(x)、f'(x) ± f(x)/x、f'(x)sin x ± f(x)cos x 等形式。

---

### 策略I：对称性锁定

**核心思路**：已知 f 的对称性 → 推 f' 的对称性（或反过来）。

**双向锁定表**：
```
f 关于 x=a 对称  ←→  f' 关于 (a,0) 中心对称
f 关于 (a,b) 中心对称 ←→ f' 关于 x=a 轴对称
f 周期为 T  ←→  f' 周期为 T
f 为偶函数  →  f' 为奇函数（过原点）
f 为奇函数  →  f' 为偶函数
```

**为什么有用**：很多抽象函数题不直接给 f 的信息，而是给 f' 的对称性。用这套锁定规则可以直接转化为 f 的对称性，配合单调性构造即可解题。

## 方法层（新增）

### 方法组9：四基底构造法

看到 f'(x) ± kf(x) 形式，乘以对应的积分因子：

| 基底类型 | 出现形式 | 积分因子（乘上去） | 构造的辅助函数 |
|---------|---------|-----------------|-------------|
| 幂函数 | f'(x) ± (n/x)f(x) | x^±n | F(x) = x^±n · f(x) |
| 指数函数 | f'(x) ± nf(x) | e^±nx | F(x) = e^±nx · f(x) |
| 三角函数 | f'(x)sin x ± f(x)cos x 等 | sin x/cos x 组合 | F(x) = f(x)·sin x 等 |
| 对数函数 | f'(x) + f(x)/(x ln x) 等 | ln x 或 (ln x)^k | F(x) = f(x)·ln x 等 |

**关键识别**：
- 看到 f'(x) + nf(x) → 乘 e^nx，左边变成 (f·e^nx)'
- 看到 f'(x) + f(x)/x → 乘 x，左边变成 (xf(x))'
- 看到 f'(x)cos x - f(x)sin x → 乘 cos²x 或识别为 (f/cos x 或 f·cos x)'

---

### 方法组10：分式反向构造

当出现 f(x)/(x^m + x^n) 或类似分式求导的逆向形式：

| 出现形式 | 逆向识别 | 原函数 |
|---------|---------|--------|
| f(x)/(x^m + x^n) | 分母是幂和 → 分子来自分式求导 | 设 F(x) = f(x)/x^k |
| (f'/g - fg')/g² | 商的求导公式 | F(x) = f(x)/g(x) |
| f'g + fg' | 积的求导公式 | F(x) = f(x)g(x) |

**关键**：逆向构造=识别出表达式是哪个求导公式的产物。幂函数型、指数型、对数型、分式型各有暴露破绽的关键系数。

---

### 方法组11：奇偶性锁定

- 已知 f' 为奇函数 + f 过某点 → f 为偶函数（确定积分常数）
- 已知 f' 为偶函数 + f 过原点 → f 为奇函数
- 已知 f'(x) + f'(-x) = 0 → f' 奇 → f 偶（条件同上）

## 知识层（新增）

### 知识组12：原函数-导函数对称性对应

| 定理 | 内容 |
|------|------|
| 定理1 | f 关于 x=a 对称 ⇔ f' 关于 (a,0) 中心对称 ⇔ x=a 是 f 的极值点 |
| 定理2 | f 关于 (a,b) 中心对称 ⇔ f' 关于 x=a 轴对称 |
| 定理3 | f 周期为 T ⇔ f' 周期为 T |

**推论链**：
- 偶函数 f → f' 奇函数（过原点）
- 奇函数 f → f' 偶函数
- f 有两条对称轴 → f 是周期函数，周期=2|a₁-a₂|
- f 有两个对称中心 → f 是周期函数
- f 有一轴一中心 → f 是周期函数，周期=4|a-b|

### 知识组13：四类基底构造模板

| 模板 | 构造 | 单调性条件 |
|------|------|-----------|
| 幂: xf'(x) + nf(x) | F(x)=x^n·f(x) | F'>0 ⇔ F↑ |
| 指: f'(x) + nf(x) | F(x)=e^nx·f(x) | F'>0 ⇔ F↑ |
| 三角: f'(x)sin x - f(x)cos x | F(x)=f(x)·sin x 或 f(x)/sin x | 取决于构造 |
| 对: f'(x) + f(x)/(x ln x) | F(x)=f(x)·ln x | F'>0 ⇔ F↑ |

### 知识组14：逆向积分构造表

| 类型 | 给出形式 | 逆向得到 |
|------|---------|---------|
| 1. 幂函数型 | f(x)/x^(m+n) | (f(x)/x^m)' = ... |
| 2. 1/x型 | f(x)/x | 逆向 → ln|x| + C |
| 3. ln x + 1 | 含 ln x + 1 | 逆向 → x ln x + C |
| 4. ln x / x | 含 (ln x)/x | 逆向 → (1/2)(ln x)² + C |
| 5. f·f' | f(x)f'(x) | 逆向 → (1/2)f(x)² + C |
| 6. x e^x | 含 x e^x | 逆向 → (x-1)e^x + C |
| 7. 整体代换 | 复杂组合 | 设 u = g(x), 链式法则反推 |
