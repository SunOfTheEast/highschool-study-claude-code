# 第八章 隐点探路 — 四层框架提取

## 定位

第八章是第七章的镜像——显点探路处理"特殊点可直接计算"的情况，隐点探路处理"特殊点不可显式求解"的情况。两者的逻辑框架相同（必要条件探路+充分性验证），但第八章多了一个关键操作：**隐零点代换**——用隐零点满足的条件（如 f'(x₀)=0）消去表达式中的超越项。

## 策略层（新增）

### 策略V：隐点效应

**路径**：

```
f(x) ≥ 0 恒成立，但极值点 x₀ 无法显式求解
    ↓
Step 1: 证明 x₀ 存在（介值定理 + 放缩取点）
    ↓
Step 2: 在 x₀ 处，f'(x₀) = 0 → 得到关系式（如 eˣ⁰ = a/(x₀+1)）
    ↓
Step 3: 利用这个关系进行代换:
    ├── 初高分流: 将超越项替换为代数项
    │   eˣ⁰ = a/(x₀+1) → 直接代入
    │   -ln(x₀+1) = x₀ - ln a → 消去对数
    └── 参变分离: a = φ(x₀)，在 x₀ 的取值范围内求 a 的范围
    ↓
Step 4: 利用隐零点的不等式界（而非精确值）完成证明
```

**包裹的结构识别**：

| 信号 | 方向选择 |
|------|---------|
| 恒成立求参数范围 | → 参变分离：a = φ(x₀)，求 φ 的值域 |
| 定值计算 / 不等式证明 | → 初高分流：消去超越项 |
| 端点取等但端点效应失效 | → 极点效应 + 隐点代换 |
| 端点不取等、无显零点 | → 直接从隐极值点入手 |

**关键操作 — 两种代换方向**：

**初高分流**：导函数零点条件 eˣ⁰ = a/(x₀+1) → 把 eˣ⁰（高等）替换为 a/(x₀+1)（初等），消去超越函数。

**参变分离**：导函数零点条件 → a = (x₀+1)eˣ⁰ → 参数 a 表示为 x₀ 的函数 → 在 x₀ 的值域上求 a 的范围。

### 策略W：最大整数解探路

**路径**：

```
"求 a 的最大整数解" 或 "求整数 k 使不等式成立"
    ↓
Step 1: 找必要条件 — 代入一个特殊值（如 x=e）得到 a 的范围
    ↓
Step 2: 在整数范围内试探
    ↓
Step 3: 对最大候选值验证充分性
```

**识别**：题目出现"最大整数"、"整数解" → 不需要精确不等式，只需在整数格点上验证。

## 方法层（新增）

### 隐零点代换的完整流程

```
1. 证明隐零点 x₀ 存在: 用 f'(x) 的单调性 + 两端异号
2. 写出 f'(x₀) = 0 → 得到 x₀ 满足的关系式
3. 选择代换方向:
   - 证不等式 → 初高分流
   - 求参数范围 → 参变分离
4. 代换后:
   - 初高分流后，原函数的极值表达式中不再含超越函数
   - 参变分离后，参数范围 = φ(x₀) 在 x₀ 取值域上的值域
5. 验证（必要时找点确认）
```

### 插值放缩

当两个不同的隐零点需要比较大小时：在两者之间找一个可计算的中间值，通过放缩确定位置关系。

## 与第七章的对比

| | 第七章 显点探路 | 第八章 隐点探路 |
|---|---|---|
| 特殊点 | 可显式计算（端点、已知零点） | 不可显式计算（需放缩证明存在） |
| 必要条件来源 | f(端点)=0, f'(极点)=0 直接代入 | f'(x₀)=0 → 关系式 → 代换 |
| 核心技巧 | 代入+求解 | 代换+消元 |
| 典型场景 | 参数在多项式项中 | 参数在指数/对数项中 |

两者共用同一个逻辑框架：**必要探路 → 充分验证**。
